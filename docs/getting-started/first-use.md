# clouddrive 首次使用与验收

1. 启动脚本完成数据库迁移后，访问 http://127.0.0.1:4173/setup，使用本地设置令牌创建管理员。
2. 在用户、角色、权限目录中创建角色并分配权限；用户与角色关系复用 IAM。
3. 在部门、岗位、组织分配中创建组织关系；组织关系本身不授予业务权限。
4. 创建字典及字典项，在个人工作区创建、完成待办；刷新页面确认数据持久化。
5. 在账户页面管理密码和会话，在安全设置管理 MFA/注销，在 API 令牌页面管理机器凭据。
6. 在运行状态页读取健康状态、诊断和真实指标；管理接口继续校验权限。
7. API 工作台先建立项目、集合、请求并保存，再执行真实 HTTP(S) 请求或创建定时任务。

公开注册默认关闭。管理员启用注册前必须指定可公开授予的默认角色；所有者、管理权限及高风险执行权限不能作为公开注册默认权限。首次管理员受到最后管理员保护。

真实验收脚本为 scripts/Test-Integration.ps1；接口和重启测试见 internal/composition/console_e2e_test.go。完整检查结果见 [架构决策记录](../architecture/adr/README.md)，未通过的检查不视为完成。
