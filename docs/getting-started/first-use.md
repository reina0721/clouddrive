# clouddrive 首次使用与验收

先按[本地启动](local-development.md)运行独立的 Web 与 Go 服务。默认网页地址为 http://127.0.0.1:4173；使用其他端口或已部署实例时，以实际地址为准。已有账户直接登录；新实例访问 `/setup`，使用本地设置令牌创建首位管理员。

## 从文件开始

1. 登录后进入 `/home` 的“我的文件”。创建一个验收目录，上传小文件或新建文本文件；刷新页面，确认名称、内容和目录位置仍然存在。
2. 打开文件阅读，编辑支持的文本格式并保存，再关闭、重新打开检查内容。通过文件“属性”查看逻辑路径和版本历史；编辑整理信息后刷新，确认保存结果。
3. 按名称搜索验收文件，尝试高级条件，刷新及前进后退检查检索位置。将验收目录固定到侧边栏，再从固定项返回目录。
4. 为验收文件创建分享，检查允许的访问者、密码、到期时间与操作能力。用独立访客窗口打开链接，确认实际权限；撤销分享后再次打开，确认无法继续访问。
5. 在登录窗口保存本实例分享链接为快捷方式，到“与我共享”按别名搜索。确认它是引用而非文件副本，原分享失效后快捷方式也显示失效。
6. 把自己创建的验收文件移入回收站，再恢复并重新打开。只对明确准备丢弃的验收内容执行永久删除。

完整能力、权限、格式与预算只在[文件与分享说明](../operations/file-management.md)维护。真实 Go 文件预览及对应浏览器用例也从该说明进入；演示数据不能证明文件已保存到服务端。

## 账户与管理

在账户页面管理资料、密码和有效会话；安全设置管理认证器、恢复码和注销，API 令牌页面管理机器凭据。验证改密、退出或注销时使用独立验收账户，保留仍需使用的管理入口。

管理员从 `/workspace` 进入管理工作区，按需要创建角色、分配用户与权限。部门、岗位和组织分配本身不授予业务权限。可用个人工作区待办验证刷新后的持久状态，再在运行状态页检查健康、诊断与指标。API 工作台先保存项目、集合和请求，再执行 HTTP(S) 请求或创建定时任务；这些能力仍受各自权限控制。

公开注册默认关闭。管理员启用注册前必须指定可公开授予的默认角色；所有者、管理权限及高风险执行权限不能作为公开注册默认权限。首次管理员受到最后管理员保护。
