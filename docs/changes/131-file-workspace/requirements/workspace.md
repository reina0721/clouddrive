# 工作区行为

客户在浏览文件、共享入口、分享管理、连接、传输和离线下载之间切换时，不应丢失文件导航、账户入口或正在运行的上传队列。

F221 六页保留同一文件工作区；F222 任意页进入图片/视频/音频/文档；F223 任意页进入回收站；F224 任意页访问和管理固定项目；F225 分类与当前页正确标记，链接可在新标签打开；F226 移动导航可打开、关闭并恢复焦点；F227 桌面侧栏可折叠且记住本账号选择。

F228 任意页向明确目标创建文件夹；F229 创建文本；F230 创建Markdown；F231 多文件上传；F232 目录上传。创建/上传前可以选择自有目标文件夹，默认当前实际文件夹或自有根目录，不能写到回收站、分类或别人的分享。失败保留输入并说明原因，取消不开始上传。

F233 任意页提交文件名搜索；F234 `/`聚焦搜索，输入法、表单和浮层内不抢键；F235 任意页看到真实已用空间/配额，失败显示未知和重试；F236 任意页打开账户资料、设置、退出及已有客户端锁屏；F237 切换明暗/系统主题；F238 切换中英文；F239 显示当前已载入上传队列的活动数量；F240 在任意页打开队列并执行已有暂停、继续、取消。

搜索在文件列表内保留现有目录、分类、回收站与高级条件；在其他页面搜索自己的全部文件。折叠状态按账号隔离。所有行为维持已有授权和容量限制，不新增公共访问。验收使用隔离数据，既有120条预览文件保持。非目标：绘图编辑器、账户直接协作ACL、BT/magnet、多节点、Office与所有Cloudreve差异的一次性交付。


当前真实部署锁屏恢复需退出并重新登录，不提供原地密码解锁。锁屏只遮挡当前标签页内容。
