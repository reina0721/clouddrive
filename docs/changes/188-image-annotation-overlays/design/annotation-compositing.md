# 标注位图合成

图片标注记录源像素中的中心点、基础尺寸、缩放比例、旋转角与既有透明度，使用 `ImageBitmap` 引用。导入时用当前裁剪区域等比放置，现有画布矩阵负责整体裁剪、旋转、镜像和缩放。命中将点反向旋转至图片矩形，选择边框随图层旋转。透明区可用于选择图层。排序与形状共用标注数组，位图对象可被多个标注或快照引用。

本机文件复用图片水印的签名、尺寸和解码边界。读取中的操作使用 AbortSignal，工具卸载、历史切换或关闭时取消，已解码但未移交的位图即时关闭。编辑器保留有效历史和水印草稿的引用，在分支淘汰及关闭时释放失效位图。最多 12 个不同标注位图可跨历史保留。复制只创建新的标注引用，不重新解码。状态随编辑器关闭而结束，无新接口、数据库迁移和后端进程。

验收对真实浏览器使用透明 PNG、JPEG、WebP 与无效输入。检查交互、导出像素、版本内容、尺寸和窄屏。实现文件为图片编辑工作区、标注模型、覆盖层解码和文件流程测试。
