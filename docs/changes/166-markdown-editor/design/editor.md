# 编辑器与图片边界

本人文件页把 Markdown 正常打开交给现有文本对话框的预览视图，编辑菜单和新建入口进入编辑视图。共享文件编辑对话框继续拥有文本、保存结果及原始 revision，Markdown 专用视图负责格式工具、实时预览与自适应布局。关闭时检测 Markdown 草稿，成功保存才跳过离开确认。现有文本和其他预览入口保留原契约。

惰性加载 react-markdown 和 remark-gfm。渲染限于独立面板，采用延后文本更新和单独上限。渲染仅接受明确的 HTTP(S) 点击链接。图片限于当前 Markdown 文件所在目录的直接同名文件，受控检索范围与数量。图片按现有 FileMedia 生命周期取消，并用经过签名验证的私有栅格 Blob 地址显示，渲染源码从不直接作为图片地址。加载失败显示替代文字和状态。仓库无迁移或接口变更。

真实浏览器场景验证创建、编辑、格式渲染、同目录图片、拒绝外链加载、未保存离开、大小与并发冲突。沿用现有工作区定向回归，验收后重启三套预览。
