# 连接与挂载

客户目标：将自己的网盘目录接入标准WebDAV客户端，独立管理每个设备的访问凭据和范围，同时在网页看到同一份真实文件。连接被撤销、账号失效或目录进入回收站后，旧凭据不能继续访问。

| ID | 可验收行为 |
| --- | --- |
| F61 | 文件导航可进入连接与挂载页面，加载、失败和没有连接分别呈现。 |
| F62 | 创建具名独立WebDAV账号，不使用或修改网页登录密码。 |
| F63 | 选择本账号有效目录作为根，客户端只能访问该根及其有效子项。 |
| F64 | 可创建只读连接，所有写入方法都明确拒绝，读取照常工作。 |
| F65 | 可阻止上传点开头的系统文件，普通文件不受影响。 |
| F66 | 新密码只在创建或轮换成功时展示，可复制连接地址、用户名和密码；列表不能再次取回密码。 |
| F67 | 连接列表真实持久化，显示备注、目标目录、权限、状态和创建时间；重启后仍可使用。 |
| F68 | 修改连接备注并进行版本冲突检查，失败不覆盖最新值。 |
| F69 | 暂停和重新启用连接；暂停期间原凭据不能操作文件。 |
| F70 | 撤销独立连接，旧凭据立即失效，原文件仍保留。 |
| F71 | 轮换连接密码，新密码生效，旧密码不再可用，其他连接不受影响。 |
| F72 | 提供实际端点和通用/Windows/iOS接入参数，明确当前传输代理状态，不展示无效开关或虚构已完成OS挂载。 |
| F73 | 客户端可查询目录、名称、类型、大小、修改时间和内容标识，中文及特殊字符路径正确。 |
| F74 | 客户端可真实下载，支持HEAD、合法范围和条件请求，越界范围明确拒绝。 |
| F75 | 客户端可创建目录，随后网页与客户端均能看到。 |
| F76 | 客户端可流式上传至512MiB上限并安全替换文件；失败或旧版本条件不符不破坏现有内容，仍执行账号配额。 |
| F77 | 客户端可重命名和移动文件/目录，不越出限定根，不制造目录环。 |
| F78 | 客户端可复制文件/目录，按真实副本计逻辑配额，失败不损坏目标。 |
| F79 | 客户端删除进入同一网页回收站，原内容可从网页恢复，不永久清空。 |
| F80 | 到期、目录失效、权限撤销或账号禁用后拒绝旧连接；跨账号、路径穿越和跨连接目标不能绕过限制。 |

约束：独立密码只授权文件协议，不可作为登录密码或普通API Bearer凭据。默认每账号最多20个未撤销连接；期限有明确上界，凭据不进入日志和教程链接。操作共用现有文件和账号空间，不向用户暴露服务器本地路径。

本批支持目录/文件操作，不承诺任意WebDAV扩展、协同锁、CalDAV/CardDAV、多机暂存或所有OS驱动完全兼容；不支持的方法明确拒绝。客户端指南需使用HTTPS正式地址；本机开发可使用回环地址，不引导用户关闭操作系统安全校验。

验收方式：全部20项实现后，使用真实账号、HTTP客户端及浏览器集中验证成功与失败；实际OS驱动未运行时如实说明，不用一张教程截图当作挂载成功。
