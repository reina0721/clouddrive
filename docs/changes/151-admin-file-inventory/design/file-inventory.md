# 跨账号元数据投影

文件模块声明独立 `files:inventory:read`，复用操作门禁、会话和 IAM 默认所有者权限。新增 GET 列表和详情。HTTP 只序列化窄响应，禁用缓存，诊断记录操作结果，不记录筛选值、条目名或访问凭据。

数据库在已有租约中从 files_entries 只投影清单字段和分页条目的历史摘要，链接状态通过现有分享及直链表确定。范围、参数、页长和排序列白名单在服务层声明。筛选值绑定参数，通配符作为文字。明细按主键读取。保持三种数据库共用的 SQL 语义，不迁移或写入文件数据。

管理面板使用既有 Route/Shell、分页、筛选、详情 Dialog 和权限可见性。浏览器按真实访问权限验证入口及窄屏。SQLite 集成验证权限、排序、筛选和稳定投影。
