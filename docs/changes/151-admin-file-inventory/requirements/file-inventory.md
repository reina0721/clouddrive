# 查阅跨账号文件

持有文件清单权限的人可从管理面板读取跨账号元数据，按所有者 ID、名称、类型、直接回收标记、关联分享和直链过滤。列表显示 ID、名称、所有者、当前大小、逻辑占用和创建时间。排序与分页由服务器执行。刷新保留已应用的过滤条件，重置回到默认列表。

详情显示父目录 ID、当前版本、历史数量、创建和更新时间、直接回收及到期时间。逻辑占用为单条当前内容和历史的合计，目录行不归集后代。账号需独立授权才能查看，清单不给予内容下载、编辑、删除或访问凭据的能力。上传仍通过既有传输流程，导入、存储策略迁移和 Blob 管理独立处理。

## F601–F620

1. F601 管理面板显示“文件清单”入口。
2. F602 未获独立权限的账号看不到入口。
3. F603 直接访问页面及接口同样受权限约束。
4. F604 授权后可查阅真实的多个账号条目。
5. F605 清单授权不扩张文件内容权限。
6. F606 支持精确所有者筛选。
7. F607 支持文件名子串与字面通配符查询。
8. F608 可筛选文件、目录和快捷方式类型。
9. F609 可筛选直接回收标记。
10. F610 可筛选关联分享。
11. F611 可筛选已有直链并与其他条件组合。
12. F612 按白名单排序，支持升降序。
13. F613 查询返回稳定的服务端分页和总数。
14. F614 空结果给出明确提示。
15. F615 刷新保留条件，重置回到默认范围。
16. F616 当前大小与逻辑占用分别显示。
17. F617 详情显示 ID、父目录、内容版本与历史数量。
18. F618 详情显示真实时间、回收期限和链接标记。
19. F619 响应无对象键、摘要、令牌或完整历史。
20. F620 320px 可从清单打开只读详情。
