# 默认存储策略

F781–F800 覆盖以下使用行为。

1. 管理区有独立的存储策略入口。
2. 显示真实的默认发布后端。
3. 区分本机、S3 兼容、MinIO 和已禁用状态。
4. 刷新读取当前部署代。
5. 按需加载去重后的已引用 Blob 数量。
6. 显示去重后的已引用字节数。
7. 分别显示当前与历史引用数量。
8. 显示已登记待回收数量。
9. 显示已登记待回收字节数。
10. 显示查询时间并可刷新统计。
11. 能保存单文件大小限制。
12. 能保存上传分片大小限制。
13. 任一限额可以单独恢复部署默认值。
14. 输入明确单位并阻止超出部署上限。
15. 区分部署、保存及生效值。
16. 保存后明确提示待生效，重启后执行新限制。
17. 旧的暂存会话仍可读取和续传，续传使用新的分片限制。
18. 过期编辑版本报告冲突。
19. 独立读取与写入权限，响应不披露存储位置或凭据。
20. 320 像素宽布局仍可查看、编辑并确认。

本批覆盖项目当前单一发布位置。多策略分配、迁移、上传扩展名与正则规则、CDN 和加密为后续范围。
