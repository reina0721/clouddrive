# 策略持久化和统计

在既有设置表中使用独立的 `storage-policy` 键。修订号从零开始，提交整组可空字段，并在已有存储锁内比较版本。部署定义硬上限，读取历史保存值时在生效配置中钳制到新硬上限。新应用代装配时一次读取并同步用于普通写入、WebDAV、分片、分享和离线下载。tusd 暂存读取及协议识别仍用部署硬上限，允许已预留会话续传；分片请求使用当前应用代大小。已有文件、对象路径及原设置行不改写。无需 schema 迁移。

管理接口用独立读取和写入权限，通过类型受限的后端描述显示真实发布位置类别。统计在一次五秒有界 SQL 读取中对当前和历史引用去重，并单独汇总登记的回收候选；这两类数字来自元数据。通过持久化版本、防缓存响应和独立统计请求避免并发编辑覆盖与旧统计被当作实时。
