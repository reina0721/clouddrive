# R160-001 默认存储策略

实地参考界面显示默认策略的后端类型，按需加载已登记 Blob 个数与字节数，并提供单文件和分片大小设置。官方文档说明多存储策略可分配到不同提供方，能力因驱动不同而变化。当前项目只有一个发布位置，混合驱动的 Primary 选择对象后端，`files_storage` 阻止有内容时直接改变位置。Blob 查询通过现有 GORM 方言层展开当前和历史引用。

技术选择保留当前对象客户端、IAM、tusd、数据库事务与应用代治理。设置沿用原有修订号及存储锁，以独立键和 DTO 避免既有“文件系统”设置的严格 JSON 与整包保存语义相互覆盖。统计复用现有关系查询，不增加文件扫描、定时缓存、服务或依赖。较小的单文件限制应用于新文件准入，tusd 沿用部署硬上限以保留已分配的暂存会话。
