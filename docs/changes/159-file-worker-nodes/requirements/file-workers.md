# 节点管理与诊断

目标是在管理区看清文件任务由谁执行、节点能否通信，并从节点回到对应任务。以下为本批 F761–F780 的验收行为。

1. 独立节点管理入口。
2. 主机卡片始终可见。
3. 显示 ZIP 创建和解压的生效状态。
4. 显示主机 HTTP 下载的生效状态。
5. 显示回收站与 Blob 维护职责。
6. 列出部署已接入的 BT 节点。
7. 显示节点名称与稳定 ID。
8. 区分启用分派与关闭分派。
9. 显示每节点任务并发上限。
10. 显示节点暂存预算。
11. 刷新列表反映本代配置。
12. 未配置 BT 节点时显示明确空态。
13. 对已配置节点手动检查连接。
14. 显示兼容版本和检查时间。
15. 显示节点下载、上传速率。
16. 显示进行中、等待和已停止数量。
17. 检查失败可重试并呈现受控故障。
18. 从节点打开带筛选条件的后台任务管理。
19. 有独立查看权限并保护凭据和节点位置。
20. 窄屏仍可查看卡片及诊断字段。

部署仍负责配置节点连接和共享工作区。Cloudreve 从机注册、远程压缩及从机存储为后续范围。
