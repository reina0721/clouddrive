# R159-001 文件任务节点

参考站“节点”在独立卡片区显示 Master、启用状态及压缩、解压、离线下载职责。官方说明节点详情可测试通信，Cloudreve 从机可分配更多职责。本地应用当前已有主机内的 ZIP、解压、HTTP、维护调度，且文件模块从受控配置创建最多四个独立 aria2 客户端。任务管理投影已能显示 BT 节点 ID。

现有 Go 标准库 HTTP、JSON、取消机制以及 aria2 adapter 已实现受控 RPC、重定向限制、超时和明确准入。aria2 官方手册提供只读全局速率与数量，不必另选 SDK 或建立客户端。项目特有逻辑是本代能力摘要和任务关联。复用已存在的客户端，运维检查不扩展任务工作区所有权，不添加新的外部地址入口。

真实观察只证明参考站节点入口和主机卡片。本批用现有共享目录 BT 边界实现查看与诊断。没有证据支持把 aria2 直接当成 Cloudreve 从机。
