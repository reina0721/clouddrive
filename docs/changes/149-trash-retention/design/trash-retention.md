# 期限快照与定期移除

files v20 为目录项加两个空列并添加账号策略表。期限和下次可尝试时间分离；既有行保持空期限。策略使用本人读取/写入接口和修订号 CAS，复用认证、CSRF 和写锁。进入或离开回收站时在同一写入事务设置或取消期限。

每分钟扫描有索引的候选，单次最多 32 条。按账号在已有事务中对比精确回收快照，复用目录闭包和移除操作。独立回收后仍受规则保护的后代使上级候选延迟。失败和延迟通过条件更新重排，较早的失败不应持续阻塞别的账号。调度器负责取消、超时和结果诊断。不存在后台物理删除。

仅更改文件模块、绑定、文件工作区和对应生成契约。数据库验证覆盖升级、到期和并发状态，浏览器验证覆盖用户设置、校验、期限展示和窄屏。既有可运行预览以备份和向前迁移方式更新。
