# 文件回收保留

本人可选择手动清理或保留 1 至 365 天。启用会在下次移入回收站时确定截止时间。修改规则保留已有条目的期限，恢复可取消期限。重新移入时按当时规则计算。

回收站在到期前显示截止时间。到期后后台清理该账号的回收条目和可安全移除的子树。独立回收且仍有保留权的子项继续保留。原手动恢复、移除和清空入口继续可用。配置冲突要告知用户重新读取设置。后台清理释放逻辑占用，物理对象仍由存储生命周期独立处理。

## F561–F580

1. F561 回收站提供“保留规则”入口。
2. F562 保留规则与一键清空同处工具栏。
3. F563 默认使用手动清理。
4. F564 接受 0 至 365 的整数天数。
5. F565 无效输入提示范围并保留输入。
6. F566 策略写入受现有跨站请求防护保护。
7. F567 保存的设置在重新打开或刷新后可读。
8. F568 并发写入拒绝旧修订，可重新读取后保存。
9. F569 每个账号独立使用本人规则。
10. F570 升级后的旧回收项仍可手动管理。
11. F571 后续回收按当时规则计算并记录截止时间。
12. F572 后续修改或关闭规则保留已记录的截止时间。
13. F573 新回收项在列表或网格中显示到期时间。
14. F574 恢复会取消到期时间。
15. F575 再次回收使用当时的规则。
16. F576 后台在截止时间之后清理条目及可安全移除的后代。
17. F577 较晚到期或无期限的独立后代使上级延迟清理。
18. F578 释放逻辑配额，独立副本仍然有效。
19. F579 后台单轮有界，失败项可重试，其他账号继续处理。
20. F580 320px 窄屏可查看与保存设置。
