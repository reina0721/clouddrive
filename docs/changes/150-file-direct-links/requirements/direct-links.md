# 直链获取和撤销

拥有者可以从文件菜单或文件多选工具栏为每个选中项获取单独的链接，一次最多十个文件。界面说明持有链接即可读取，并提供复制单条和复制全部。再次获取同一文件复用既有地址。持有者直接打开内容，支持预览或强制下载；链接不提供目录浏览或编辑能力。

拥有者可在“我的分享”管理当前直链和撤销访问。文件改名、移动或覆盖后，地址继续解析同一文件的当前内容；回收文件或其祖先暂停访问，恢复后恢复访问，永久移除后不可用。撤销后即使重新生成，旧地址也不能恢复。目录直链和直通对象存储地址独立规划。

## F581–F600

1. F581 本人文件菜单提供获取直链。
2. F582 多选工具栏可一次生成多条直链。
3. F583 显式说明持有链接即可读取并要求生成操作。
4. F584 单文件重复获取返回原地址。
5. F585 请求最多十项并拒绝重复项。
6. F586 不可用条目单独报告，其他合法项正常获取。
7. F587 可复制单条下载地址或全部直链。
8. F588 我的分享提供本人直链管理。
9. F589 其他账号不能查找、获取或撤销本人直链。
10. F590 写入受既有跨站请求防护保护。
11. F591 匿名请求可读取同一文件，进程重启后地址仍可用。
12. F592 HEAD 仅返回元数据。
13. F593 Range 响应正确字节和范围错误。
14. F594 条件请求识别内容版本。
15. F595 可强制下载，活动网页内容按附件返回。
16. F596 改名或覆盖保留地址，读取当前内容。
17. F597 文件及其祖先回收时停用，恢复时恢复访问。
18. F598 撤销即时失效，重新获取不复活旧地址。
19. F599 永久移除会清理该文件的关联直链。
20. F600 320px 窄屏可以管理和确认撤销。
