# 本人直链与匿名内容路由

files v21 新增独立直链表，以 owner 和 entry 限定一条活动链接。保存加密随机 256-bit token 和索引摘要，管理读取需本人认证；API 和访问日志不得输出除本人直链响应外的凭据。生成和撤销在 storage/owner 事务内，使用独立 ID 防止旧撤销请求影响新链接。永久移除同事务删除关联链接。

匿名 GET/HEAD 重用受控内容租约、传输准入、条件响应及 Range。每次先后检查凭据、拥有者账号权限、可见性和当前对象。附件为安全默认，预览仅允许明确的安全媒体类型，并使用无嗅探、禁止缓存和沙箱响应。授权拒绝返回统一的不可用结果。没有匿名写入或目录权限。

前端在文件操作、多选及我的分享中懒加载对话框；复制 URL 由 Host 生成，避免将令牌发往其它来源。按完整业务流程验证 SQLite 迁移、权限、下载、范围、撤销、前端窄屏和预览数据保留。
