# 授权、解析和播放器生命周期

私有 Host 组合字幕来源适配器，按当前视频详情获取父目录。复用现有文件搜索的当前目录、后缀过滤和本人可见性，最多取 200 个字幕候选，超出显式失败。选定时重新校验字幕 ID、父目录、文件名、大小及内容版本；读取时实际最多 256 KiB，读取后复验。账号撤销沿用既有文件运行时围栏。无需 Go API、配置或迁移。

字幕选择和状态仅出现在当前私有视频预览，按需加载。自动匹配 Unicode NFC 和不区分大小写的基本名，优先 VTT、SRT、ASS。手动可选同目录其余字幕或关闭。已打开视频元素不重挂载。宽播放器用剩余高度容纳视频，下载及关闭入口留在视口内。每次仅创建一个解析 Worker，UTF-8 严格解码、字幕纯文本、上限 5000 条，3 秒超时可强制终止。主线程使用浏览器 TextTrack 的时间语义，清理旧 cue、关闭预览及切换账号时释放请求和 Worker。字幕失败单独反馈，播放器保持可用。

先完成全部行为，再运行前端类型、依赖及生产构建和 Chromium，覆盖三格式、异常字节、同名自动选择、手动切换、键盘及桌面和窄屏视觉。
