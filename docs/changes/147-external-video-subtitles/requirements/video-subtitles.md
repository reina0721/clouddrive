# 本人视频的外挂字幕

用户从文件列表打开自己的视频时，可以播放配套字幕并在预览中切换。下面 20 项作为一批集中验证。

1. F521 本人视频预览提供字幕选择，保留浏览器播放控制。
2. F522 自动加载同目录同基本名的字幕。
3. F523 基本名匹配忽略大小写并兼容 Unicode 规范化。
4. F524 读取 VTT 字幕。
5. F525 读取 SRT 字幕。
6. F526 读取 ASS 时间和文本。
7. F527 同名候选多个时，选择顺序稳定。
8. F528 手动选择同目录不同名的字幕。
9. F529 关闭字幕。
10. F530 切换字幕保持当前视频及播放位置。
11. F531 播放和跳转按实际时间显示字幕。
12. F532 支持 UTF-8 及 UTF-8 BOM。
13. F533 显示多行及非拉丁字符。
14. F534 文件内容以纯文本显示，不激活脚本、样式和远程请求。
15. F535 文件体积超过限制时明确提示。
16. F536 字幕条数和处理时间受限。
17. F537 读取或解析失败可以重试，视频继续可用。
18. F538 更换、关闭预览或离开账号可中止旧加载。
19. F539 本人同目录的可见文件才可选，分享、旧版本和音频保持既有范围。
20. F540 窄屏和键盘可使用字幕选择及关闭。
