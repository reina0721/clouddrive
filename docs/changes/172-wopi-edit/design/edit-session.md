# 编辑会话与发布

同一应用配置追加每格式编辑动作与管理员开关。导入和更新沿用策略修订。用户单独确认编辑，票据包含初始内容版本、策略修订、会话 ID 和限时用途；协议回调重验拥有者写权限。查看票据沿用此前的只读行为。

files v27 在同一写锁表增设 WOPI 字段，WebDAV 旧行默认保持空字段。WOPI 变更、普通写入与设置保存共用 storage 写序列。原始锁值只在协议响应中可见。写入最多 8 MiB，复用传输并发名额和对象补偿。提交事务复核活跃锁、会话、当前内容修订、设置修订、名称、配额与既有传输预留，将新对象、历史和锁版本一起发布。失败保留原文件，清理候选。

三个预览迁移仅执行向上迁移，先做 SQLite 一致备份和版本检查。测试验证现有数据库锁保留、WebDAV 与普通写入互斥、重复保存以及受控编辑器浏览器回调。
