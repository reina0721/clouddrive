# 浏览器编辑器

私有 Host 为当前预览注入 PNG/JPEG 工具入口。缩略图、历史与公开预览沿用原装配。编辑器延迟加载，使用预览已验证的 Blob，先用原图的自然尺寸核验预算，再创建并校验尊重 EXIF 方向的 ImageBitmap。每边最多 8192 像素且总像素最多 16 Mi；画布预览每边至多 1200 像素。关闭后释放位图，编码用短生命周期画布，关闭后丢弃尚未入队的产物。

预览打开时获取文件和当前媒体字节预算。上传完成触发列表刷新时保留正在打开的预览与编辑状态。

裁剪坐标使用解码后的原图方向，允许从全图调整。旋转和镜像作用于输出方向，尺寸以最终输出为准。历史只保存最多 24 步参数，连续拖动提交一次。新改动清除重做分支。裁剪或尺寸调整须先应用再保存。保存按格式显式编码，PNG 保留透明度，JPEG 使用白底。输出不得超过当前媒体字节预算。上传使用现有候选注册及队列接口，冲突保留到传输中心并由现有规则处理，无协议、配置或数据库迁移。
