# 文件读取与播放器生命周期

内置视频应用默认增加 M3U8，原管理员自定义关联规则保持有效。文件插件只传递打开类型。浏览器 Host 保留原生 video 与现有外挂字幕，并按需加载 hls.js。Surface 不接触媒体引擎对象。

引擎全部资源请求由自定义加载器处理。虚拟 URL 仅作为账号文件路径，逐级查找可见目录和精确文件，之后由同源内容版本接口交付字节。根文件打开时校验身份、内容修订与路径。切片按修订读取，更新中的媒体清单每次重新解析当前可见版本。字节范围由既有 Range 响应提供。HLS 引擎负责解析、容器转换、AES-128、缓存和自适应，应用提供资源种类、大小与超时限制，限制外部网络与 DRM 请求。

清晰度菜单置于视频下方右侧，展示自动/手动与当前分辨率。正常关闭、重试和退出时销毁引擎并取消读取。错误保留在既有文件错误语义内，用户可重试或下载源清单。无需新增数据库迁移。
