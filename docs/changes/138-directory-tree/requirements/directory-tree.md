# 私有目录树行为

范围：本人目录，复用原文件权限与回收规则；分类、搜索、上传及管理入口继续可用。默认关闭根树以保持简洁；进入目录且开启自动跟随时展开当前路径。跟随和侧栏折叠只保存于本设备、按账号隔离。

20项验收行为：

1. F341：根导航可以展开真实一级目录，不列出文件、快捷方式或已回收目录。
2. F342：可收起根目录树，后续重新展开不重复无效读取。
3. F343：逐层按需展开子目录，不预先遍历整棵树。
4. F344：收起子目录隐藏后代并保留已读缓存。
5. F345：点击树中目录进入该真实目录，上传队列仍属于当前标签。
6. F346：方向键、Home/End与焦点操作由成熟树组件主持。
7. F347：Enter/Space可激活目录或载入动作，无鼠标也可导航。
8. F348：从列表、面包屑或固定项进入目录后，可自动展示并标记当前路径。
9. F349：可关闭自动跟随，手动探索不因当前目录变化被强制展开。
10. F350：跟随和折叠设置刷新后保留；不同账号隔离，旧账号请求不覆盖新状态。
11. F351：超过一页的子目录有明确的继续载入入口，实际页码推进且不重复项目。
12. F352：已读取的空目录不呈现虚假的子目录，可直接打开。
13. F353：加载中有可理解状态，同一分支不并发重复读取。
14. F354：分支读取失败准确显示错误，并能单独重试；不冒充空目录。
15. F355：可刷新树，重新读取真实状态且重置分页缓存。
16. F356：创建、改名、移动、回收以及上传完成后的工作区刷新不长期保留失效节点。
17. F357：在共享、分享、连接、传输和离线页也能通过树进入本人目录。
18. F358：折叠侧栏与移动抽屉共享树状态，移动目录导航后关闭抽屉并恢复合理焦点。
19. F359：长名称、中英文、深色、窄屏保持可访问，不把页面撑出横向滚动。
20. F360：节点与自动加载有明确上限，取消、切换账号及离开工作区停止请求；原本机折叠设置安全迁移且原文件数据保留。

树行是层级集合动作；现有分类及路径链接保留原生链接行为。侧栏不宣称离线文件镜像、无限目录量、公开分享目录树、拖拽改位置或账号协作挂载能力。服务端现有元数据预算导致的失败必须如实显示。
