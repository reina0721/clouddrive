# 本人回收站

1. F541 回收站工具栏用“清空回收站”取代新建。
2. F542 单个已回收文件有永久删除入口。
3. F543 单个已回收目录有永久删除入口。
4. F544 所选项可以一起永久删除。
5. F545 恢复入口继续可用。
6. F546 清空涵盖本人整个回收站及分页。
7. F547 搜索或筛选不缩小清空范围，确认时明确提示。
8. F548 确认窗口列出影响项数。
9. F549 确认窗口展示可释放的逻辑空间。
10. F550 用户取消时保留全部条目。
11. F551 目录清理包含仍在其下的后代。
12. F552 目录与已单独回收的后代同时选中时只计算一次。
13. F553 永久移除后不能恢复或读取。
14. F554 计入原文件及历史引用的逻辑空间被释放。
15. F555 其余副本及其历史仍可读取。
16. F556 已移除目录或快捷方式的固定项同步清理。
17. F557 账号与写入权限边界继续生效。
18. F558 旧确认拒绝新增、恢复或再次回收造成的范围变化。
19. F559 失败不提交部分删除，重试前重新核对实际范围。
20. F560 窄屏可确认、取消，空回收站给出明确状态。
