# 事务及交互

本人文件 API 新增两个 CSRF 保护的写权限入口。预览按选择或整个回收站返回明确根数、条目数、逻辑字节、快照摘要。执行在存储及账号写锁内读同一有界树，重新生成摘要，匹配后一次事务移除完整子树及对应固定项，递增固定项版本。请求最多选择现有批量预算内的条目；整树按既有搜索树上限拒绝截断。API 拒绝活动条目、别的账号、无效身份和重复选择。已回收后代仍属于原目录的，随目录清理。无迁移或外部存储写入。

界面在回收站工具栏、单项菜单和选择栏提供入口，确认前读取实际范围。取消或离开页面取消预览请求，确认失败给出重载入口，旧摘要不重放。完成后刷新文件、目录和配额。物理内容对象仍由同一 Storage 保存，后续单独引入完整的引用校验与回收机制。关联历史记录保留并经现有权限和可见性检查失效。
