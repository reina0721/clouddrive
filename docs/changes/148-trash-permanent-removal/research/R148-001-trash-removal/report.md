# R148-001 回收站删除范围和现有存储边界

参考站左上方“清空回收站”替代“新建”，账号回收站为空，未执行任何删除。截图已保存在本地忽略目录。官方发布记录明确一键清空，文件能力定义包含永久删除。[回收站变更](https://github.com/cloudreve/cloudreve/issues/3473) · [文件能力](https://docs.cloudreve.org/en/api/boolset#file-system-capabilities)

项目目前仅回收和恢复普通文件，分享快捷方式可永久移除引用。复制树、WebDAV 复制、历史另存会复用不可变对象；历史关联存于条目 JSON 中。没有覆盖历史和副本的全局引用账本，也没有运行中的通用文件对象收集器。当前逻辑配额由目录项当前内容和历史引用相加，删除目录项即释放该逻辑用量。

采用项目已有数据库事务和存储/账号写入顺序，使用 Go 标准库计算确认快照的摘要，无新依赖或数据库迁移。客户端先获取精确范围和逻辑用量，确认时在同一写事务内校验；发生并发恢复、再次回收或清空范围变化时拒绝旧确认。无需引入事务框架、额外队列或新文件树。对象收集需要独立研究全部生产者、跨条目引用、历史及已开始的读取，本批保留物理对象。现有审计、下载与连接历史继续保留；访问已移除条目遵循原有可见性检查。
