# 编辑状态与原始编码

文件应用调度复用现有文本对话框及写入事务。私有详情新增可编辑标记，按媒体类型和内置代码后缀确定。已有分享的编辑规则独立保留。文本编辑器按需加载 CodeMirror 6，组件管理编辑实例、语言加载、选择、快捷键和卸载。应用只接收字符串和现有写入回调，语言 SDK 类型留在编辑组件。

Host 一次读取确定修订的有界文件字节，在本次会话内用浏览器编码标准严格解码。自动识别 UTF-8、UTF-8 BOM 和 UTF-16 BOM。手动重解码仅在没有草稿修改时执行，失败保持此前内容。保存使用 UTF-8，保留统一的 CRLF、LF 或 CR 换行，混合换行按 LF。二进制、超限、冲突及读写权限错误沿用文件错误约定。无数据迁移和远程语言服务。
