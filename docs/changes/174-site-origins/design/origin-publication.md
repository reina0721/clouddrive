# 站点地址发布

站点信息可选保存主 Origin 和最多八个不同的备选 Origin。Console 新增独立部署参数 `console.siteOrigins`。规范化后，PUT 仅接受许可名单的成员，使用既有 CSRF、权限及修订。管理视图展示保存值和当前许可名单。公开视图只发布仍受许可的有效配置，主地址失效则停止发布整组。缺少地址的旧记录可直接读取，无迁移。

地址为根站点 Origin，去除结尾斜杠并标准化主机和默认端口。HTTPS 用于外部站点，HTTP 只允许明确配置的回环地址。服务器不请求配置地址。部署许可仅用于发布，Cookie、CORS、认证、原生接口及反向代理分别按既有规则工作。

浏览器按页面加载时读取的配置生成分享或直链，当前 Origin 若匹配主或备选地址便沿用，否则选主地址。未配置时沿用当前地址。快捷方式仅对当前或已发布的地址解析令牌，并通过原来同源的 API 存入；绝不向粘贴的地址主动请求。外部阅读器和 WOPI 在用户授权后重新读取有效地址，再用主地址生成回调，并拒绝将应用配置成当前或回调自身。WOPI 继续通过独立表单字段传票据。

验证覆盖生产 HTTPS、回环预览、旧数据、配置撤销、跨主机分享、真实回调、越权和代理边界。三个预览按原进程地址升级；部署实际需要让许可的域名转发同一实例。
