# R174-001 站点地址、链接发布和 WOPI 回调

R173-001 在参考环境的桌面参数页看到「主要」地址、添加备选地址和说明。主地址用于外部服务，备选地址根据用户访问站点匹配。官方部署和 WOPI 手册分别要求配置站点 URL，并确保文档服务可访问主要地址。本次重开参考页的浏览器连接超时，继续采用已观察的界面及当前官方文档，未修改参考数据。

`681ff53` 的浏览器 Host 用当前页面 Origin 生成分享和直链，也仅接受当前 Origin 的分享快捷方式。外部阅读器及 WOPI 的源地址由文件应用对话框在用户授权后构造。原生下载、会话、WebDAV、CORS 和反向代理各自已有独立来源规则。站点信息已有持久化、修订号及设置权限，存储格式容纳缺省可选字段。

保留标准库 URL 解析与既有地址构建。站点来源是项目配置，不增加 DNS 探测、网络代理或后台任务。单独的部署许可名单表达「可发布文件链接的站点」，比复用通用 CORS 白名单更贴合职责。浏览器 Host 复用现有文件 Port，通过窄读取函数取最新配置，避免切换地址时重建上传运行域。对跨实例域名误配置的防护以部署许可名单和运营验证为界。
