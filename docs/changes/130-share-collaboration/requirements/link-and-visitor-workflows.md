# 链接与访客工作流

## 目标与范围

在浏览器中创建和管理不同能力的分享链接，访客在获准范围内查看和处理真实文件，拥有者能停止访问。所有更改仍占用拥有者空间，名称冲突不自动覆盖。范围不包含按账号/用户组的独立规则、子目录权限继承、Office同时编辑、WebDAV锁或跨站分享。

## 20项验收行为

- F201 分享权限：创建时选择只读、仅上传、可编辑预设或明确的细分能力；默认只读，后端执行相同限制。
- F202 分享标题：可设置和修改面向访客的标题，不改原文件名。
- F203 修改有效期：在允许时间范围内延长或缩短，过期后无法访问，冲突保留输入。
- F204 修改访问密码：可设置、更换或移除密码；旧解锁凭据失效，不回显已有密码。
- F205 暂停与恢复：可暂时停用链接而不删除内容，恢复仍遵守有效期；撤销仍不可恢复。
- F206 分享详情与访客预览：拥有者查看真实状态、能力和有效期，并以独立访客入口预览实际结果。
- F207 我的分享检索：名称/标题搜索、状态筛选、排序与有界分页，不丢失失败或暂停状态。
- F208 共享目录检索：访客在范围内搜索、排序和分页，面包屑不能返回拥有者的私有上级。
- F209 文字预览：获准访客能安全读取纯文本/Markdown，HTML和脚本仅按文字处理。
- F210 媒体预览：获准访客能预览图片和浏览器原生音视频，关闭后释放资源，超限明确失败。
- F211 创建共享目录：有创建能力的访客可在分享目录内新建子目录，冲突不覆盖。
- F212 创建文本/Markdown：获准访客可在分享目录新建真实文本文件，保存后拥有者和其他访客可见。
- F213 上传文件：获准访客可分块上传真实文件，遵守单文件/空间限制，显示真实进度，可取消并清理；不依赖整文件内存缓存。
- F214 重命名：获准访客能改名分享范围内子项，禁止改名分享根或覆盖同名内容。
- F215 编辑文字：获准访客能编辑文字并检测并发版本冲突，旧版本按原保留策略保存；单文件分享同样可编辑。
- F216 移动子项：获准访客可选择分享内目标目录，禁止移出分享范围或移动分享根。
- F217 复制子项：获准访客可在分享范围内建立独立副本，内容与配额沿用已有规则。
- F218 回收子项：获准访客只能将范围内子项移入拥有者回收站，不能永久删除、访问回收站或删除分享根。
- F219 批量打包下载：有下载能力时可将所选真实文件/目录打成ZIP，范围或读取失败不得返回伪成功包。
- F220 批量整理：所选项目可逐项移动/复制/回收，结果明确，失败项保留，不误报全部成功。

## 约束与失效

权限、密码、有效期或启用状态发生变化后，旧访客凭据及未完成上传不能越过新的保存授权；已保存文件不随链接暂停、撤销或修改而删除。仅上传预设不允许枚举他人已存子项。任何协议端点都不能借文件ID访问分享外内容。链接预览能读取的字节可被浏览器保存，不承诺通过隐藏下载按钮防止复制。
