# 查看和调整文件系统参数

管理员能查阅生效值和部署默认值，也能保存允许的调整或恢复继承。保存之后明确显示待重启状态。新实例接手后使用同一份配置处理文件和回收任务。打开自动 Blob 回收需要具备管理写权限并在页面确认。现有已回收文件、历史版本和存储记录继续保留。

1. F661 管理区可进入文件系统参数。
2. F662 纯查看权限与保存权限分离。
3. F663 普通账号直接访问时被拒绝。
4. F664 显示部署默认值。
5. F665 显示当前生效值。
6. F666 显示待应用值。
7. F667 保存文本编辑上限。
8. F668 保存文件批量上限。
9. F669 开关后续历史版本保留。
10. F670 保存每文件版本上限。
11. F671 保存回收站扫描间隔。
12. F672 保存 Blob 扫描间隔。
13. F673 保存自动 Blob 回收状态。
14. F674 恢复继承部署参数。
15. F675 非法或越过上限的参数被拒绝。
16. F676 两个管理员同时编辑可识别版本冲突。
17. F677 刷新仍能读到已保存值。
18. F678 当前运行实例保持一致，重启后应用新值。
19. F679 生效的文本和批量上限由服务端执行。
20. F680 新设置不改写历史和文件记录，窄屏可查看和保存。
