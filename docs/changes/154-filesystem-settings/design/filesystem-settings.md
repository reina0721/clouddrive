# 文件配置覆盖及生效边界

增量 v23 增加单行强类型文件配置覆盖，空值继承部署配置。写入使用修订号比较并交换，成功后返回同一快照。新增读写独立授权，写入使用现有原生写请求保护。页面区分部署值、当前实例值和待应用值，允许逐项留空或整体重置。

在文件模块装配前读取覆盖值，复用现有文本、批量、版本和调度服务。文本、批量、版本数量和版本开关遵守部署硬上限；存量超出新的部署上限时，投影值有界并显示原保存值。回收时间间隔有独立上下限，部署调度禁用优先。持久化覆盖与已发布实例分别拥有自己的生命周期。进程启动时一致读取所有字段；保存不触发隐式重启或在当前实例部分更新。既有文件、版本、回收候选及存储位置不迁移。数据库错误和配置错误沿现有启动/HTTP 错误边界传播。
