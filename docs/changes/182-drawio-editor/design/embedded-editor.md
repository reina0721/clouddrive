# 编辑协议与文件事务

新增内置应用标识 drawio 与默认扩展名和新建映射。沿用系统工具策略保存，旧配置的省略项继承内置默认，无需数据库迁移。本人文件的严格 UTF-8 原件读取、大小限制、创建与修订比较并交换复用已有文件 Port。后台普通文本应用列表与分享权限继续使用原有规则。

嵌入地址由 Host 配置，默认使用官方独立 HTTPS 域名。前端先显示来源提示，用户操作后才装载 iframe。拒绝相同主机名（即使端口不同）和带用户信息的地址，禁止顶层跳转、弹窗和表单。以当前 frame 的 WindowProxy 和来源同时匹配 JSON 消息，限制消息大小。配置后响应 init 并发送可接受的 mxfile 或 mxGraphModel XML。结构检查拒绝 DTD、实体声明和其他根节点。编辑器只接收 XML 与文件名。

宿主拥有取消、握手超时、异步保存、内容修订及关闭确认。autosave 仅更新当前草稿，save 执行版本提交。保存中拒绝并行写入，保存失败时保留草稿供重试或下载。通过真实嵌入器验证形状和页面操作，使用受控协议用例验证越权消息、错误与冲突。
