# 研究入口

[R134-001](R134-001-pdf-runtime/report.md) 复核PDF缺口、PDF.js当前发布与安全、浏览器资源和现有Host承载。旧R121-001仅复用Host负责媒体资源的原则，其源码快照及匿名策略已有变化，不能直接作为本批PDF依据；R133-001只复用近期预览、保留数据和成熟技术边界原则，不扩展其7Z进程为PDF服务。

[R134-002](R134-002-security-refresh/report.md) 记录集中验证命中的原有production依赖公告、修复下界与同架构定向更新，不能把旧构建证据作为更新后验收。

[R134-003](R134-003-sdk-boundaries/report.md) 修正编辑模式异步就绪与超大图像的实际省略语义；不得将无typed失败回执写为可靠失败。
