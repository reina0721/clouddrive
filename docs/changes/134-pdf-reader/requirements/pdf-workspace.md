# PDF阅读工作区

## 客户目标与场景

用户在网盘里点击自己的PDF，希望在当前页面阅读、多页跳转、查找、查看目录并做临时批注，而不是看到“不支持文字预览”。文档内容不送往第三方预览服务；可以导出带标注的独立PDF副本，原文件不被悄悄覆盖。历史PDF使用明确的旧版内容，同样受归属和读取规则约束。

## 范围、约束与非目标

源文件默认最多32MiB，管理员可收紧。允许页数、像素、目录、缩略图、并发和工作期限有明确预算；源字节、页数及工作期限超限时说明原因并保留原下载入口。SDK省略超过像素预算的图像，阅读窗口必须明示该限制与下载原件的选择，不承诺超限图像完整呈现。取消、关闭、切换账号后停止读取与解析并释放资源。使用当前源版本；文件更新时提示重新打开，不把新字节当成旧内容。

提供中文/英文主要界面、深浅色、键盘可达操作和窄屏内部滚动。文档本身是否包含可访问文字/结构由实际内容决定，不承诺对扫描件自动OCR。临时标注关闭后丢弃，退出前提示未导出状态；明确丢弃只影响内存标注，不删除文件。

本批不包含Office转换/共同编辑、公开分享PDF、OCR、任意大PDF流式远程范围读取、原地保存、服务器渲染或任意嵌入脚本。不会把浏览器Worker称为有硬堆内存限制的进程。其他Cloudreve缺口仍保留在整个goal范围内。
