# 首批文件管理需求

## 客户目标与场景

用户登录后能在自己的网盘上传文件、整理目录、查找和下载文件，并可恢复误删内容。刷新、重新登录和服务重启不丢失已经成功保存的内容。其他用户不能读取、修改或通过猜测编号访问它们。

## 20 项独立能力与验收

| ID | 能力 | 可验收行为 |
| --- | --- | --- |
| F01 | 文件主页 | 默认进入我的文件；参考蓝色选中导航、浅灰画布、白色内容区；桌面和手机无横向溢出，加载/失败/空目录明确 |
| F02 | 目录导航 | 打开子目录、面包屑返回父目录，刷新保留当前目录；文件不作为目录打开 |
| F03 | 创建文件夹 | 当前目录创建后即时出现；非法名称、同名及无权目录明确报错 |
| F04 | 单文件上传 | 上传成功后可刷新读到；失败不出现成功记录；超过限制在发送前及服务端均拒绝 |
| F05 | 多文件上传队列 | 展示每个文件的等待、传输、成功、失败，可取消未完成项，失败可重试 |
| F06 | 拖拽上传 | 文件拖入文件区可启动同一上传流程；不让浏览器导航离开页面 |
| F07 | 文件下载 | 下载字节与原文件一致；未经授权及回收站内容拒绝下载 |
| F08 | 重命名 | 文件/目录名称持久化，发生同名冲突时保留原内容 |
| F09 | 移动 | 可移到本人其他目录；拒绝移动到自身/后代及他人目录 |
| F10 | 移入回收站 | 普通文件区消失，目录内内容一起不可见；不永久删除 |
| F11 | 回收站与恢复 | 显示删除时间，可恢复文件或目录；原位置不可用/同名时明确选择恢复位置 |
| F12 | 文件搜索 | 按名称搜索本人有效文件，支持空结果和清空查询；不返回他人或回收站内容 |
| F13 | 类型分类 | 图片、视频、音乐、文档按一致的类型规则显示，未知类型仍在全部文件中 |
| F14 | 排序 | 名称、大小、修改时间可升降序；刷新保留选项，相同值顺序稳定 |
| F15 | 网格视图 | 显示类型图标、名称、操作入口；键盘可聚焦操作 |
| F16 | 列表视图 | 显示名称、大小、修改时间，可切回网格且不丢当前目录 |
| F17 | 多选操作 | 可选择多项并批量移动/移入回收站；逐项显示失败，不将部分失败显示为全部成功 |
| F18 | 属性详情 | 显示文件名、类型、字节大小、创建/修改时间及路径；信息来自真实已保存内容 |
| F19 | 空间统计 | 显示本人实际占用及配额，回收站仍占空间；并发上传不能突破配额 |
| F20 | 文本预览 | 有界纯文本文件可查看；HTML/脚本按文字显示；二进制或超限文本提示下载 |

## 范围、限制与非目标

首批采用小文件闭环：拟默认单文件上限 32 MiB、服务同时上传 2 个、每用户配额 1 GiB，均须可配置和校验；这些是本项目初始限制，不是参考站的能力或限制。队列允许多项但按上限发送。不支持断点续传、目录上传、Office 协作、媒体转码、公开链接、跨用户共享、WebDAV、离线下载或永久删除；这些列入后续差距，不显示为已实现功能。

沿用现有本地身份；保留管理后台入口。首批不修改参考站数据，不部署参考站，不重置本地数据库，不将参考站密码写入源码、文档、日志或测试。

## 验证节奏

每 20 项实现完成后集中跑功能、权限与失败路径、持久化、视觉和响应式检查；不在每新增一项时启动全量回归。必要静态审查和代码编译不计作提前的逐功能验收。测试通过并审阅后提交、推送；不以点击成功或仅前端状态作为通过依据。
