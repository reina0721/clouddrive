# R181-001 照片查看工作区

Cloudreve 的[官方截图](https://docs.cloudreve.org/assets/file-apps-image-editor.DA9QZGmM.png)左半部为深色独立画布，顶部显示序号，画布两侧可切换，右侧列出曝光、相机、日期和分辨率。官方[媒体信息提取](https://docs.cloudreve.org/zh/usage/media-meta)另包含上传处理。截图未用于推断图片搜索的实现。

在 d321b35，`files-page.tsx` 依据文件应用政策打开普通媒体预览，`media-view.tsx` 读原件并验证栅格签名。本人当前文件 PNG 和 JPEG 接入编辑副本，`music-tags.ts` 已有隔离解析线程实例。历史版本、公开分享及内联图片各有调用范围。源码没有 EXIF 解码器，也没有同目录切图。

浏览器 Canvas 可提供解码尺寸，没有标准 API 能跨格式读 EXIF。Go 标准库无需扩展即可满足现有预览能力，新增服务端解析需要处理存量回填、权限和持久化，超出查看器边界。ExifReader 官方 JavaScript 项目提供类型、浏览器 ESM、按标签过滤与多种栅格格式。4.54.0 修复了资源限制和分段隔离。MPL-2.0 适用于该依赖文件，通过未修改发布包与现有 Worker 隔离接入。官方资料未验证独立生产采用规模。exifr 的公开发行历史和近期安全修复证据弱于该版本。手写 TIFF/EXIF 解析会扩大不可信数据处理和维护负担。现有预览可以承载按需解析，无需更改应用边界。

结论适用于已验证签名且可解码的本人图片。对照站点可以响应 HTTP 请求，但浏览器读取现有会话页面超时，因此本批使用官方截图与文档作视觉基准。上传提取、索引、Live Photo 和 HEIC 需要独立证据。依据上游安全公告、文件应用契约或提取范围变化刷新。
