# 应用边界和解析生命周期

Surface 继续负责文件应用选择、工作区弹窗和下载。从已加载列表按当前排序取同目录、活动、预算内且图片应用仍可选的文件。打开时保留这一批候选快照，切换只更新原件身份。边界禁止环绕；切换时旧内容、定位状态和请求一并释放。

浏览器适配层在已有读取预算和签名检查之后复用 Blob。仅展开信息面板时启动 EXIF Worker。解析上限 12 MiB，运行上限 5 秒。关闭、换图和超时终止 Worker。ExifReader 仅解析所需标签，返回受限字符串及校验过的坐标，坐标需要主动显示。图片通过浏览器独立解码，解析失败不影响原件显示。保持既有认证、下载和编辑版本处理，不增加 HTTP 接口或数据库迁移。由真实 JPEG、无 EXIF PNG 和窄屏浏览器验收，复跑既有编辑器用例及生产性能检查。
