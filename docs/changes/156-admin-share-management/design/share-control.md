# 接口、并发与数据

沿用文件模块、现有数据库和 UI Adapter。`GET /files/admin-shares`、`GET /files/admin-shares/{id}` 以白名单投影读取固定页和详情，按 owner/root 和策略状态过滤，排序列与方向通过枚举限制。管理清单状态按分享本身计算，源文件单独投影，不获取对象键、链接、解锁凭据或用户密码。列表的撤销能力来自当前 IAM 权限。

`POST /files/admin-shares/revoke` 接受最多 20 个去重 ID 与修订号，验证当前权限与 CSRF。使用既有存储锁和事务读取全部目标并比较版本，已撤销目标可按当前版本重试，任何缺失或冲突整批回滚。成功更新撤销时间和修订，复用现有访客和下载票据检查。

v25 为三种方言追加分享浏览与下载授权计数及清单索引。已授权且返回根元数据的请求增加浏览数。单文件下载票据签发成功与计数处于同一事务，Range 读取不增。统计写入不改变策略修订或扩大访问权限。历史数据保留且不推算旧计数。接口验证实际 IAM、状态、页和撤销竞态，生产浏览器验证桌面筛选与窄屏撤销，三套预览先备份再升级。
