# 分享查询与处置

管理者能核对不同用户的分享状态，并在确认范围后撤销需要停止的链接。现有源文件、内容及普通用户分享入口保持可用。计数从功能启用后累计，页面解释统计口径。本批范围不包含积分、付费或跨账号读取文件内容。

1. F701 管理区有独立分享入口。
2. F702 拥有清单权限的用户可跨账号查看。
3. F703 普通文件权限不授予管理清单访问权。
4. F704 按分享者 ID 精确筛选。
5. F705 按源文件 ID 精确筛选，支持组合条件。
6. F706 按启用、暂停、已到期或已撤销筛选。
7. F707 服务端分页、稳定排序及总数。
8. F708 可按 ID 或分享时间正反排序。
9. F709 可按真实浏览计数排序。
10. F710 可按真实下载授权计数排序。
11. F711 行内显示源文件、分享者、到期和分享时间，源文件不存在时仍能核对链接。
12. F712 详情显示名称、状态、密码保护标志与两个计数，不暴露访问凭据。
13. F713 拒绝或未解锁的浏览不计数。
14. F714 已签发的下载票据计一次，重复 Range 读取不重复计数。
15. F715 管理撤销使用独立权限，查看者只读。
16. F716 支持单条确认和本页多选确认。
17. F717 批次有数量上限，旧版本冲突时不部分撤销。
18. F718 已撤销的链接及旧下载凭据失效，保留源文件。
19. F719 应用筛选、刷新、重置与空态有明确反馈。
20. F720 数据与计数重启保留，桌面和窄屏可完成管理流程。
