# 文件检索与视图操作

用户希望在大量自有文件中组合条件、定位目标并高效选择，且返回、刷新及切换视图后不丢失明确的检索条件或显示偏好。界面继续区分读取失败、无结果、加载中和当前页已清空，不假造条目。

| ID   | 可验收行为                                                                |
| ---- | ------------------------------------------------------------------------- |
| F101 | 从文件页顶部进入高级搜索，取消不改已有结果；提交后显示真实结果与条件      |
| F102 | 添加/移除最多8个文件名关键词，不把正则或通配表达式当执行代码              |
| F103 | 可切换忽略大小写；中文及规范化Unicode名称可检索                           |
| F104 | 多词可选择全部包含或任一包含；非法空词明确提示                            |
| F105 | 明确选择当前目录、当前目录及后代或全部自有文件；被回收祖先内容不能漏出    |
| F106 | 按多个文件扩展名检索，大小写统一，不把目录/快捷方式误当文件               |
| F107 | 可以区分普通文件、文件夹及分享快捷方式                                    |
| F108 | 组合最小/最大文件大小，明确单位，0可查空文件，缺失是不限制                |
| F109 | 按创建日期范围筛选，明确UTC及结束日期包含当天                             |
| F110 | 按修改日期范围筛选，拒绝逆序日期                                          |
| F111 | 显示活动条件，可移除单项或清除全部，结果与页码同步                        |
| F112 | 刷新、前进/后退和同实例深链接可恢复检索条件，非法链接显示错误             |
| F113 | 可启用目录优先，仍保留明确升降序和平局顺序                                |
| F114 | 网格和列表支持分页及50/100/200条显示偏好，显示总数/页码；选择全部仅指本页 |
| F115 | 缩略图可开启/关闭，并遵守现有图像预算；关闭后停止使用缩略图资源           |
| F116 | 列表使用对齐的名称/大小/类型/日期列头与行，窄屏可读且不横向溢出           |
| F117 | 可选择显示的附加列，刷新后按当前账号保留；名称列始终可用                  |
| F118 | Shift可连续选择本页范围，范围锚点明确，换页/查询后不借旧集合误选          |
| F119 | 文件名支持方向键及Home/End移动焦点，Shift扩展范围；输入框/对话框内不误触  |
| F120 | Ctrl/⌘点击文件名切换选择，不误打开内容；可与Shift组合，普通打开行为保留   |

数据安全：搜索只作用当前账号已授权的元数据，不搜索或复制别人分享的内容；无新公开入口。回收、权限、分享和传输前100项行为继续有效。没有永久删除、全库重置或自动清理。普通视图分页不增加上传/归档批量上限；画廊仍按服务端现有每屏预算展示。

非目标：标签、媒体分析、任意元数据/自定义属性、全文索引、外部搜索服务和像素级复刻；它们继续属于整体目标中的后续缺口，不能展示假支持。
