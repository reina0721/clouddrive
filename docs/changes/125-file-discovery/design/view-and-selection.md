# 视图、偏好和选择

高级搜索、视图选项、分页和列表列拆为有语义的files组件，文件页顶部收拢搜索入口，减少展开全部控件造成的拥挤。只提供真实支持的条件。现有网格/列表/画廊、排序入口和标签保持可达，避免前100项回归。

私有FileQuery增加可选typed filters及page/pageSize。路由中的filter为有界、严格schema的序列化对象，page独立；刷新/历史恢复使用同一解析器，未知字段、无效枚举或畸形JSON显示invalid，不静默清空后成功。普通搜索与高级条件明确相交；提交、改条件和改分页大小回到第一页；目录/分类导航清除不适用条件。活动条件chip按业务字段移除；不通过分享token检索别人对象。

filter总长度按百分号编码字节限制为4096，防止多字节关键词超过当前Node的16384字节请求头预算；过长保留草稿并提示减少关键词。Host、URL解码与对话框提交共用同一校验。界面日期只编码UTC整日规范时刻，不能把任意时刻取整后伪装为原条件。

ViewPreferences由Surface公开schema和集中默认值拥有view/sort/desc、foldersFirst、thumbnails、pageSize及有限columns。Host按当前owner存取同一份偏好；缺失字段使用已说明的扩展默认值，损坏/越界存储抛出可展示错误，禁止另建全局容器或静默吞失败。名称列始终存在，附加列限大小/类型/修改/创建。普通网格/列表按服务器页展示，画廊保留现有maxGalleryEntries预算及本地翻屏，不叠两套不可理解分页。

缩略图只交给既有Media组件，图像与字节预算继续由Host校验。关闭/换页/卸载会卸载缩略图并取消请求、释放Blob；不创建第二套媒体客户端。列表有列头与行对齐，窄屏使用明确的响应式折叠/换行，名称不被固定宽度挤没。

本页选择保留有限ID集合、焦点与锚点。普通checkbox或Ctrl/⌘名称点击切换单项，Shift选择锚点到当前项的闭区间，Ctrl/⌘+Shift合并范围。改变页码/查询后清空锚点与选择，不根据旧索引选择新文件；批量动作只提交当前页明确ID，选择全部文案指本页。

名称按钮保持打开动作和可访问名称；无修饰点击继续打开文件/目录/原分享。Host扩展语义快捷键与focusEntry(id)，Surface不查document、不直接读location。仅当焦点在文件区域时接收方向/Home/End，输入、浮层和可编辑区内不触发。键盘移动焦点，Shift同时扩展选择；Tab、菜单和checkbox原有操作不被截断。无新的Session持有者；账号变化仍销毁Provider与旧请求。
