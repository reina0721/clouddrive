# 播放器装配与资源

文件 Surface 通过可选 Host 动作发起播放，在既有文件顶部工具区域呈现播放器。Popover 收起不影响它拥有的媒体节点。文件路由离开会卸载播放器，锁屏暂停，账号切换重新装配；已经消费的播放请求不会因返回工作区而自动续播。历史、回收站和公开分享仍按已有单文件入口执行。

播放列表按文件名读取同目录前 100 个音频候选，应用浏览器格式检查、文件状态与读取预算，当前曲目单独保留。只读取选中曲目的 Blob，前后核验目录、可见性和内容修订，切换或停止释放自有 URL。加载、播放和列表失败各自呈现，重试只影响相应操作。浏览器拒绝自动播放时允许手动播放。输入标签仅取受控大小的文本和验证过的内嵌栅格图片，Worker 受时间限制并随曲目切换终止。无数据库或 API 变更。
