# ZIP 创建使用场景

1. F481 单文件菜单可创建 ZIP。
2. F482 目录菜单可创建 ZIP。
3. F483 多选栏可把多个对象打成一个 ZIP。
4. F484 表单预填有意义的 ZIP 文件名。
5. F485 修改文件名并补齐 ZIP 扩展名。
6. F486 选择本人目标目录及根目录。
7. F487 同名目标明确失败，保护原文件。
8. F488 提交成功可立即打开后台任务。
9. F489 后台列表显示压缩类型及独立状态。
10. F490 页面重开仍可查看同一记录。
11. F491 成功后定位真实结果文件并可下载。
12. F492 ZIP 内容使用标准 Deflate 和可校验字节。
13. F493 目录层级、Unicode 文件名和空目录保留。
14. F494 重复的子目录选择只收录一次。
15. F495 明确拒绝快捷方式和相互冲突的包内路径。
16. F496 提交后变更来源时明确失败且无部分结果。
17. F497 本人配额、输入字节和 ZIP 结果字节受限。
18. F498 取消排队任务后无结果，重复提交同一请求返回原任务。
19. F499 账号隔离，排队任务跨重启继续。
20. F500 既有解压记录、后台解压及直接打包下载继续工作。

适用范围为本人文件区和普通 ZIP。
