# 受限 Stamp 导入

宿主通过统一文件选择器和可取消的栅格导入读取 PNG、JPEG 或 WebP。校验原始文件字节、签名、声明尺寸和浏览器解码尺寸。关闭临时 ImageBitmap，向已有会话发送识别后的本机 File 和预期页码，仍验证消息来源、nonce、请求 ID 和工作时限。frame 检查文件元数据和当前页，拒绝不一致的请求。

frame 等待 PDF.js Stamp 模式就绪，使用当前页的 AnnotationEditorLayer 创建居中对象，等图片画布真正可见后才确认。PDF.js 保有图像和对象的撤销、重做和序列化。宿主读取期间允许取消并冻结导航，命令提交后阻止重复导入。单窗口接受 12 次成功导入，包含历史；窗口关闭销毁 SDK 资源。frame 拦截会绕开文件选择校验的外部文件粘贴和拖放。

阅读、导出和权限使用既有契约；导出沿用 saveDocument。无依赖升级、外部上传、后端变更或迁移。最终浏览器测试验证真实像素、不同页、历史、限额、失败提示和新旧文件字节，复核窄屏截图。

回归复现显示后台传输更新目录 revision 时，列表快照短暂为空，原条件渲染会卸载已打开的阅读器并丢失批注。当前文件预览在打开时同时保存文件与读取策略，生命周期由对话框关闭决定。新列表策略从下次打开生效。验收在捕获含已上传条目的目录响应后检查同一个 frame 和实际编辑内容。
