# 策略和打开路径

内置清单由文件服务返回，包含稳定应用 ID 和支持的典型扩展名。启停和平台保存为完整草稿的稀疏规则，未设置项为全平台启用。默认应用按扩展名保存，扩展名归一，拒绝不支持该扩展名的目标、重复项和已停用目标。首次读取和恢复采用 Markdown 的内置默认，同时保留文本打开选项。持久化复用文件设置表及独立 revision，既有数据库无需迁移。

管理读写沿用文件设置权限和 CSRF。活动视图仅提供本人工作区分派所需数据。每次新打开读取最新活动策略，可取消迟到结果。浏览器根据窗口是否小于 768 像素选择平台，并结合现有 MIME/扩展名兼容规则。明确选择优先于默认规则。唯一候选直接打开，多个且无有效默认时由用户选择，没有候选或请求失败时显示原因并可下载。应用可用性控制工作区的打开入口，文件内容权限及现有编辑、下载和原生校验契约继续独立执行。

以真后台和浏览器验证设置、选择、权限及旧版文件，不添加前端依赖或迁移。外部地址模板、WOPI、访客分享和跨系统打开不在本批。
