# R167-001 文件应用管理

参考站 `/admin/filesystem?tab=fileApp` 的应用列表展示应用名称、扩展名、平台和启用状态。Markdown 平台菜单提供 PC、移动及全平台。底部“默认打开方式”的添加菜单只列出关联多个应用的扩展名，说明默认项可跳过选择对话框。检查只展开菜单，未保存设置。官方手册区分内置、嵌入和 WOPI 应用。

`982a2c0` 有 PDF、EPUB、Markdown、文本、图片、音频、视频和归档入口，`FilesPage.showPreview` 以固定顺序分派。Markdown 既可渲染，也可通过原文本读取能力显示源码。文件图标已有独立的文件设置记录、修订比较和交换、读取及设置权限。文件应用选择属于本产品交互，现有 Go 标准库、Huma、GORM、React、Zod 和对话框已能覆盖类型、事务、绑定及交互，不需要新库或新存储。继续复用窄契约可保留现有渲染器的 MIME、内容签名和配额限制。移至插件或外部嵌入需要引入额外文件授权和数据交付模型，本批不引入。

本批采用固定内置清单、平台启停和默认打开方式。仍留有扩展名关联编辑、创建映射和外部应用差距。研究门禁通过。
