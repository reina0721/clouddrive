# 映射与创建

文本和 Markdown 应用的规则追加可选的有序 `newFiles`，字段缺失继承，空列表显式隐藏。有效策略返回映射、来源及应用可创建性。新映射只接受应用关联中的扩展名、受限显示名称和唯一后缀。关联变更会清理不适用的草稿。使用既有设置 revision、权限和 CSRF 原子保存，旧记录与内置应用默认可用性不变，无迁移。

本人工作区每次展开“新建”读取有效策略，按启用与设备选择映射，服务暂不可用时保留其他新建操作并提示。映射选择进入既有目录选择和文本或 Markdown 编辑器，应用预填所选后缀。文件由原权限、名称准入及文本限额约束。内置 Markdown 继续接受既有 `.markdown` 命名。第三方服务、非文本文件创建器及访客映射另行对齐。
