# R169-001 新建文件映射

运行站的文件应用表展示映射数量。Markdown 应用的编辑对话框有映射表，行内选择扩展名和填写菜单名称，可添加、删除并调整顺序。官方手册说明映射会出现在文件工作区的“新建”。观察后取消表单，未修改参考站。

本地 `7940e29` 已有文件应用启用、平台、关联和修订事务。`FileWorkspace` 的文本与 Markdown 创建项写死，`WorkspaceCreate` 复用目录选择和真实文本创建。复用当前文件服务、Go 校验及 React 菜单即可保存配置并落到实际文件，无需新增第三方、存储或发布入口。内置文本与 Markdown 有真实编辑及保存路径，其他应用的内容格式尚无创建器，映射拒绝此类目标。沿用旧菜单名称和已有设置缺失字段的继承语义。

研究门禁通过。外部文件应用、新模板格式和访客创建映射留在后续范围。
