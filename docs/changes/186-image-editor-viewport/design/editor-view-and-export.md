# 视图与编码边界

编辑会话维护独立于历史的缩放、平移模式和原图开关。适配模式沿用有界预览画布，由 ResizeObserver 报告显示比例。固定模式按输出像素换算 CSS 尺寸，100% 使用实际画布像素，超过 100% 只放大显示。源图和输出沿用现有像素上限；绘制由动画帧调度，并在画布卸载时清理。

固定模式使用原生滚动容器并按比例维持视区中心。选择平移时由指针捕获处理横纵拖动，暂停在画布中绘制。非平移状态下裁剪和标注继续用画布实际边界换算坐标。原图显示使用初始快照并暂停画布编辑，原草稿和历史保留。

顶部入口将焦点和滚动位置移到同一副本表单。质量为会话级参数，使用浏览器 Canvas 编码的有损质量选项，PNG 省略该参数；文件名、限额、透明度、上传语义及内容来源维持原契约。无服务端改动和新依赖。
