# R186-001 图片编辑画布与保存设置

对照 Cloudreve 官方图和本地 185 桌面截图。官方图顶栏包含输出尺寸、原图按钮、比例、加减与保存，项目顶栏只包含历史和尺寸，导出设置在弹窗下方。Cloudreve 中文资源和 Filerobot 官方实现说明进一步确认实际尺寸、适配、原始图像与压缩质量。185 已确认现场参考实例的图片列表为空，因此使用官方图与源码校准编辑器，不向参考实例上传。

在 `1abdeef`，四个编辑视图复用 ImageCanvas。浏览器预览使用固定像素预算，没有独立视图缩放或平移；只看原色的开关保留几何及覆盖层。Canvas 已复用照片编码，但质量固定。当前源图、历史与副本所有权可直接承载新增视图参数，无需替换原编辑器。

采用 W3C ResizeObserver、浏览器原生滚动与指针捕获、WHATWG Canvas 编码和已有 UI Adapter。引入 Filerobot 或通用手势库会重复画布、历史和资源所有权；本批不接入第二套。100% 实际尺寸沿用现有编辑像素上限。高倍率只增加 CSS 尺寸，且有上限。验证聚焦真实像素尺寸、输入坐标、草稿恢复和保存文件。
