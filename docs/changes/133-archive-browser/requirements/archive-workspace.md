# 压缩包使用行为

用户从自己的文件操作菜单打开压缩包。F241浏览ZIP；F242浏览7Z；F243进入包内目录；F244通过路径和上一级返回；F245按包内路径搜索；F246按名称或大小正反排序；F247选择文件/目录、全选当前结果和清空；F248预览UTF-8文本；F249预览安全图像；F250下载单个成员；F251把所选内容打包下载。

F252全部解压；F253仅解压所选文件/目录；F254选择自己的保存目录；F255可选新建命名文件夹包裹结果；F256同名时拒绝整次操作并保留选择；F257选择跳过同名；F258选择自动改名；F259通过当前输入密码打开加密7Z；F260查看真实创建/跳过/改名回执并打开结果位置。

目录选择包含可浏览分页、上级和根目录，默认源压缩包所在目录。解压保留包内相对层级，不覆盖已有文件，不修改原压缩包。提取目录与新增文件必须一次完整呈现；配额、源版本或目标变化导致失败时不能留下部分目录项。失败可重试但不自动重放写入；输入/选择保留，密码不保存到浏览器记录。

路径异常、损坏、超预算、密码错误与不支持格式须明确说明；关闭预览释放内容，取消能终止解析，不后台无限继续。大小上限按部署政策展示，不能把加载或解析失败伪装成空包。默认上限沿当前64MiB压缩及展开预算、500项（包含目录），可由管理员收紧。

边界：私有文件、ZIP Store/Deflate和成熟库支持的7Z；不含加密ZIP、分卷、自解压程序、公开分享包浏览、远程Range目录缓存及重启后继续的后台解压。不能以这些边界宣称完整Cloudreve目标完成，后续继续推进。
