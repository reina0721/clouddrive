# 授权路径、持久化与错误

## 唯一授权路径

scope/validateAccess增加当前受众及目标的有效能力，不再用根permissions提前拒绝所有子项；目标为空时显式检查链接根或真实目的地。Browse以当前目录及祖先可达性裁剪树，普通列表/搜索/目标选择共用同一裁剪，total和分页在裁剪之后计算；返回PublicEntry只带有效permissions，不带私有规则。浏览权限为false的目录及其子树不进入可发现集合，不能通过搜索曝光。

Preview/Download按目标能力决定原字节或有界安全预览。Metadata对全零结果只给denied/signInRequired及必要有效期，不泄漏根信息，密码锁与受众拒绝分别表示。ContentTo、CreateDownload、downloadSnapshot、ReadText全部迁移，不能保留旧根位集旁路。ZIP/Copy/Move/Trash检查选中目录实际影响的整个子树；受保护后代导致拒绝，不静默遗漏后再声称整目录成功。Rename只检查实际改名目标。Copy/Move额外检查目的地Create；Create/Upload按目的地能力。共享scoped Repository在事务中复验目标/策略并限制已变更条目；私有Service不受分享ACL限制。

shareScopedContent读取时复核本次意图和真实目标，读取前后保留失败；错误链和清理错误沿用现有契约。SharePublication的admission与最终事务校验同一受众和当前Entry策略，已传完但被收权不能最终发布。清理已知候选仍可在策略撤销后执行，但只允许原share/grant/主体绑定，不获得发布权。

DownloadGrant增加AudienceSubject，新票据签发时绑定真实账号或匿名空值；每个原生/Range请求当前Viewer须同主体且重新求值Download，不缓存角色能力。Transfer同样增加ShareAudienceSubject并在控制/接收/发布/清理校验；幂等key包含主体，两个账号不能撞候选。原密码grant不是IAM身份，继续密码票据约束，与身份并列校验。

## 存储与迁移

追加files v13，不改已应用SQL。SQLite/MySQL/PostgreSQL分别新增files_shares.audience_json，files_entries.access_policy_json和access_policy_revision，grant.audience_subject以及transfer.share_audience_subject。默认受众为空、文件策略null、revision0、主体空；严格JSON解码拒绝损坏/未知字段/尾部值，不能用默认掩盖读取失败。shareRecord改为显式或带独立JSON列的record与model转换，搜索全部直接cast调用迁移，避免GORM把模型结构体误作列。entryRecord与Clone/Copy完整保留策略，发布新条目默认继承；访问规则不进普通Entry JSON、公开分享或WebDAV属性。

Entry权限PUT在Service既有owner事务内校验expectedAccessRevision，单调推进，保持名称/内容/更新时间语义可区分；reset只设nil，不改后代。公开写入不能改变ACL及其revision。Share受众沿用整条share.Revision CAS并使密码grant失效；旧设置UI必须保留受众，不能保存标题时清空规则。

迁移前一致备份两原库，记录全部既有列和行摘要。迁移后只对既有列比对（新增默认列会改变SELECT *形状），另检查新字段默认、原0/120条目和所有分享/票据保留；不删除6条旧grant。旧匿名grant要求匿名主体，已登录用户可新签发。无未终结分享上传；若备份时发现出现新候选，定向复核身份绑定迁移影响，不擅自取消。

## 生命周期、错误、日志

没有新client/goroutine/timer，仍归原请求/DB租约/Transfer锁。上下文取消和DB错误完整返回；策略输入invalid、并发conflict、受众forbidden、会话unauthenticated明确区分，不记原始错误/名称/账号/token/policy快照。HTTP决定协议结果时沿用Handler.Present低敏日志，新增维护成功仅稳定files.access.updated或files.share.policy.updated事件，不逐层重复打日志。权限不足的公开结果不能显示未经授权的文件名/规则。
