# 链接内协作权限

客户目标：同一分享链接能让不同同事拥有不同能力，保护子目录和文件；权限改变后已有下载或上传不能继续越权。不是“知道链接就人人拥有一样的编辑权限”。

范围与可验收行为：

|任务|客户可观察能力|
|---|---|
|F281|分别设置匿名访客权限，支持完全禁止匿名访问|
|F282|设置已登录用户的默认权限，未单独设置时沿用链接默认|
|F283|按完整账号标识找到本实例账号并加入规则，不列出所有账号|
|F284|给予指定账号独立的只读、上传、编辑或自定义权限|
|F285|明确拒绝指定账号并可删除规则恢复默认|
|F286|按角色编码找到本实例角色并加入规则|
|F287|赋予角色独立能力，匹配多个角色时合并允许，任一拒绝角色优先|
|F288|精确账号优先于角色；界面明确展示规则顺序与覆盖关系|
|F289|分享创建时设置受众，只有选定用户可用而匿名无法读取内容|
|F290|分享设置维护受众，冲突保留草稿并允许刷新，不静默覆盖|
|F291|文件菜单维护单个文件的分享内权限|
|F292|目录菜单维护该目录及未独立设置后代的继承策略|
|F293|恢复继承，保留后代自己的独立策略|
|F294|查看最近的继承来源和独立/继承状态|
|F295|在实际相关分享中预览匿名或某账号的最终能力及来源|
|F296|私有复制保留独立策略，移动后继承随新父目录改变|
|F297|访客目录、搜索和目标选择只展示有浏览权的子树，逐项动作与权限一致|
|F298|文字、媒体、原生下载和整目录ZIP按实际文件权限执行，受保护子项不能经打包旁路读取|
|F299|目录创建、修改、改名、移动、复制、回收和批量操作由服务器执行目标及目的地权限；上传最终保存再次验证|
|F300|账号/角色变动后新请求按当前身份生效；下载票据和分享上传绑定访问账号，退出或换账号不能复用他人能力|

约束：匿名和登录都仍需有效链接、密码（如有）及有效期。子项最近一份独立策略替换上级，而链接根使用链接策略，单文件分享不使用该文件自身的子项策略。活跃系统管理员与文件拥有者在有效分享内有全部能力，不能越过撤销或期限。每份策略合计最多32条账号/角色规则，拒绝重复标识。角色是本系统IAM角色，不是外部身份组。

非目标：没有自动向账号发消息或邀请，没有新建“无链接共享盘”、外部组织同步、Office并发编辑、永久删除、公开枚举账号、密码单独解锁或BT/远程节点。预览会把获准字节交给浏览器，不能保证阻止本地保存；已下载的副本不能远程收回。旧文件与分享不丢失，旧策略默认行为保留；升级后登录用户可能需重新点击下载以取得身份绑定票据。
