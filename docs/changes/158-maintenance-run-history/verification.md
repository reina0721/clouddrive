# 验证

- `go test -p 2 ./...` 与文件模块和组合层的 `go vet` 通过。仓储测试覆盖无回填、每类保留 200 条、分页、取消、失败和过期快照。管理接口保留用户任务的查询与清理行为。
- 隔离实例启用一分钟周期的自动 Blob 回收，从空 SQLite 数据库观察到真实的 Blob 回收和回收站到期扫描均写入完成记录。
- 前端 738 项单元测试、架构边界、格式和 ESLint 检查通过。两个生产构建均通过现有性能预算。三项隔离浏览器测试通过，覆盖原有分享与用户任务、系统来源筛选、实际记录详情和历史清理。人工查看桌面和 320 像素宽截图。
- 主预览、开发和 QA 的 SQLite 数据库均在备份后升到 v26，核对了 25 张原文件表的行数和内容哈希。三个预览恢复，主预览与 QA 通过登录及管理接口验证。
- 本批在 SQLite 上执行迁移与行为验证。PostgreSQL 和 MySQL 的迁移已纳入校验清单，当前环境未运行这两种数据库的集成验证。进程突然终止时，尚未写入的执行没有终态历史。
