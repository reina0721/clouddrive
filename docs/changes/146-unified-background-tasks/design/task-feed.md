# 接口与交互

新增本人 `GET /files/background-tasks`。仓储用一条有界查询汇总归档和下载主行，名称关联使用同账号条件，省略原始下载 URL、密钥、上传候选和节点路径。数据仍由原业务模块写入。读取最多为两类任务上限之和加一，超预算显式失败。服务按创建时间及稳定身份排序，按名称、类型、状态过滤并分页。无需数据库迁移。

后台页保留标题、刷新、开关及原归档操作。已知下载总量显示百分比，未知时显示字节。下载精确详情链接在原下载页面打开，跳转身份为任务 UUID，按当前账号读取；结果打开复用已发布文件校验。手动刷新及页面轮询共用已有前台可见性运行时。请求取消、旧响应隔离、分页回收和错误提示在视图状态中处理。
