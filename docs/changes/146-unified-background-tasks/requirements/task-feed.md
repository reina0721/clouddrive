# 任务汇总验收行为

1. F501 从文件侧栏进入同一后台任务页。
2. F502 显示真实 ZIP 创建记录。
3. F503 显示真实解压记录。
4. F504 显示真实 HTTP 离线下载记录。
5. F505 显示真实 BitTorrent 记录。
6. F506 同名记录按身份区分。
7. F507 按任务类型筛选。
8. F508 按状态组筛选。
9. F509 按名称检索，匹配忽略大小写。
10. F510 按创建时间稳定排列。
11. F511 跨类型分页能查看早期任务。
12. F512 筛选重置后恢复全列表。
13. F513 手动刷新读取最新状态。
14. F514 可开启或暂停自动刷新。
15. F515 下载展示真实字节和已知总量。
16. F516 未知总量时展示已收到字节。
17. F517 展示真实错误，刷新失败保留上次内容并提示。
18. F518 进入对应下载的精确详情和管理入口。
19. F519 打开完成结果，权限继续由现有入口检查。
20. F520 他人任务不可见，现有归档控制及下载入口继续可用。
