# R146-001 任务汇总

## 事实

- 参考站后台任务页实际显示标题、手动刷新、默认开启的自动刷新和居中空态。提供账号没有任务记录，未能观察实时进度卡片。当前源码按页读取任务并展开详情。官方发布说明明确统一管理压缩、解压和离线下载。[界面源码](https://github.com/cloudreve/frontend/blob/c7b6fa5288ed0490a5589ddff4f56ea1f96a5315/src/component/Pages/Tasks/TaskList.tsx) · [发布说明](https://github.com/cloudreve/cloudreve/discussions/2522)
- 当前文件模块有持久归档和下载记录、独立生命周期和既有授权入口。归档每账号最多 50 条，下载至多 200 条。下载列表为了详细信息会查询传输子项及 BT 元数据。
- HTTP 显示名来自唯一传输子项。BT 显示名优先用户指定名，再取种子名。已收字节、总字节和速率持久化于下载任务；未知总量可以区分。详情接口继续负责当前结果可见性和授权。

## 方案取舍

只读汇总沿用同一数据库、文件读取权限和账号条件，用标准 SQL 投影同一模块的持久字段。聚合端不持有资源或任务生命周期。浏览器翻遍下载分页会重复读子项和文件树，且刷新时难以保持完整；增加通用队列或搜索引擎没有必要的独立消费场景。沿用现有驱动和 Zod 契约，不升级依赖。

实际参考页只有空态。列表的类型、进度和详情以正式源码及本项目真实数据验证。上传和系统任务的生命周期另行评估。
