# 分享与丰富文件操作

用户可以整理副本、创建和修改文本、上传目录、查看常见媒体，并向持有链接的访客分享指定内容。默认仍为私有；未主动分享的文件不能被匿名读取。

| ID | 能力 | 验收行为 |
| --- | --- | --- |
| F21 | 复制文件 | 可指定目标和名称，原文件保留，新副本独立修改；配额不足或同名不产生半成品 |
| F22 | 复制目录 | 保留有效子树层级，排除回收内容；失败不留下部分新目录，拒绝复制到自身后代 |
| F23 | 新建文本 | 当前目录创建 UTF-8 文本，立即可预览、下载和刷新读取 |
| F24 | 新建 Markdown | 创建 .md 文件，按文字查看和编辑，不执行 HTML/脚本 |
| F25 | 文本编辑 | 有界 UTF-8 文件可保存；另一窗口已修改时提示冲突而不覆盖其结果 |
| F26 | 目录上传 | 用户选择目录，保留非空目录层级并逐项显示结果；取消/冲突不伪报全成功 |
| F27 | 剪贴板上传 | 用户主动粘贴文件/图片进入现有队列，不读取普通剪贴板文字或密码 |
| F28 | 图片预览 | 常见安全图片可查看、关闭和切换；不执行 SVG/HTML 内容 |
| F29 | 音频预览 | 浏览器支持的音频可播放/暂停和调节进度，不支持时提示下载 |
| F30 | 视频预览 | 浏览器支持的视频可播放、暂停和定位，不支持时有明确反馈 |
| F31 | 画廊视图 | 图片以实际缩略图呈现，可打开原图；切换视图保留目录，退出释放预览资源 |
| F32 | 文件操作菜单 | 紧凑菜单替代卡片多排按钮，鼠标与键盘均可打开；不隐藏失败反馈 |
| F33 | 文件快捷键 | 搜索聚焦、刷新、选择全部、取消选择、重命名等可用，编辑输入时不误触发文件操作 |
| F34 | 打包下载 | 多选文件/目录下载 ZIP，保持层级与原始字节；超过打包预算明确拒绝 |
| F35 | 创建分享 | 仅当前用户有效文件/目录可生成只读链接；未分享内容保持私有 |
| F36 | 分享有效期 | 可设置到期时间，到期后所有访客读取立即拒绝；不依赖访客时钟 |
| F37 | 访问密码 | 可选密码保护，错误或缺失密码不能读取文件内容，持续失败受限 |
| F38 | 访客访问下载 | 未登录访客打开分享页可看到授权内容并下载真实字节，无需本地账号 |
| F39 | 我的分享管理 | 列出本人分享、状态和目标，可撤销；撤销后已有访客凭据也失效 |
| F40 | 共享目录浏览 | 访客只可在指定根内浏览/下载；不能猜 ID 跳到同 owner 其他目录，回收内容不可访问 |

约束：沿用当前单文件上限和账号逻辑配额；ZIP、目录复制和文本编辑也有明确总量限制。目录上传不承诺空目录、后台续传或跨设备恢复。分享为只读，不能上传、删除、修改或继承管理员权限。既有文件/数据库和参考站均不得重置或清空。

本批不代表完整对齐：外部挂载、离线下载、版本历史界面、Office、永久删除治理与大文件续传仍在整体目标中，不以占位入口算作完成。
