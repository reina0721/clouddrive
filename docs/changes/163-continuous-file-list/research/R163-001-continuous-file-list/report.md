# R163-001 文件列表连续浏览

Cloudreve `/admin/filesystem` 的模式下拉明确说明传统分页显示总页数并跳转，游标分页在底部自动追加。当前参考站选中游标模式，`/home` 数据为空，行为说明来自菜单，没有对远端写入。

R162-001 的游标、错误恢复和旧页码仍适用。基线 `3d19452` 在 `files-page.tsx` 以同一列表请求替换可见集合，切页会重置选择。`file-workspace.tsx` 的主区域是滚动容器；已有 `viewport-reveal.tsx` 证明运行环境采用浏览器观察器，但其职责是动效并受动效偏好约束，不能用于请求调度。W3C Intersection Observer 规格定义相交回调和 `disconnect()`，原生 API 可独立驱动请求。现有按钮、文本框、Next 查询路由能覆盖传统分页。

定时轮询和监听每次滚动均需自行维护几何和调度。现有请求层提供 AbortSignal，配合一个尾端观察器、明确的首批身份和手动加载入口即可承载功能，无需新增依赖、接口或数据迁移。连续结果仍受文件目录的服务端查询预算约束，不承诺数据库扫描优化。研究门禁通过。
