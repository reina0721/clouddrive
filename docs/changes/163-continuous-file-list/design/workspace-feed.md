# 请求与导航

首批携带查询及刷新版本。追加只在首批仍对应当前查询时可用，组件拥有追加请求及取消信号。文件端口向 Host 注册尾端可见性并清理订阅，Host 管理浏览器观察器，同时保留手动入口。追加以条目 ID 去重，留住顺序及选择，注释随新增行接入。每个成功游标最多消费一次，重复链路与失效锚点提供重回首批入口。传输失败可重试原游标且保留已读内容。切换视图、范围或刷新取消旧请求，忽略迟到结果。继续加载不写历史；显式旧游标仍可打开和回首批。

传统页码继续通过 `page` 查询，按服务端实际页大小算总页数，严格验证十进制正整数和页数上限。跳页仅在用户提交时写入 URL。文件工作区继续使用原权限、渲染与批量限制，浏览器内只累积当前查询结果。

验证真实浏览器的尾端、失败、取消、键盘和页码输入。复用部署数据库，无 schema 变更。
