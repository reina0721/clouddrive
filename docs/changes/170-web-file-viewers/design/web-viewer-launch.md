# 策略与临时预览

现有文件应用 JSON 追加可省略的网页应用列表，延用修订及管理权限。网页应用以独立命名空间的 ID 引用，可和内置应用共同参加默认选择。活动策略只提供名称、关联、平台、大小及可信提示所需的外站源。完整 URL 模板只在管理和授权后的启动响应中出现。客户端仅允许 HTTPS 模板，变量只能放在查询值，替换使用标准 URL 编码。外链和内嵌均去除 Referrer，内嵌按最小权限隔离。

用户在预览打开之前确认外站访问。认证操作复核文件归属、当前内容、扩展名、应用和大小，签发五分钟的只读能力。令牌用 Go AES-GCM 和随文件模块生命周期生成的随机密钥保护，包含所有者、文件 ID、内容版本、应用策略修订及到期时间。匿名 GET/HEAD 沿用传输配额、Range、no-store 和安全附件响应；读取时复核拥有者仍有读取权限、内容仍可见且版本与策略未变。访问令牌、原始 URL 与内容不得写入应用日志。后端不主动联系配置的外站。

验收包括受控测试预览页真实使用地址取得文件、取消时无授权请求、越权和旧版本拒绝、管理恢复、内置回归以及预览重启。
