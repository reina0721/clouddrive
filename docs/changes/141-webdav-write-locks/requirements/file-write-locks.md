# 文件写入占用

用户使用WebDAV编辑文件时，其他应用、网页和分享访客都必须遵守占用；本人能在连接页看到占用范围、来源和到期时间，必要时解除。

|编号|可验收行为|
|---|---|
|F401|可为现有文件取得独占写锁，返回真实令牌和有效期|
|F402|为尚不存在的文件加锁时原子建立空文件，不生成中间目录|
|F403|同一文件的第二次独占申请被拒绝，原锁保持|
|F404|文件夹Depth0锁保护本身和直接成员名称的增删改|
|F405|文件夹Infinity锁保护所有后代内容及名称|
|F406|持锁连接可用If提交令牌完成合法写入|
|F407|If支持资源标签、条件组合、Not和ETag，条件不成立不写入|
|F408|持锁连接能续期；刷新不创建新锁或新文件|
|F409|解锁后允许正常写入，错误令牌不能解除|
|F410|服务重启保留锁，到期自动失效|
|F411|撤销、轮换、只读及到期连接不能继续利用旧锁|
|F412|网页文本编辑和版本恢复、清理不能绕过有效锁|
|F413|上传从准入到最终发布均遵守锁及最新条件|
|F414|分享访客写入、目录整理和元数据修改也遵守锁|
|F415|复制不复制源锁，移动不把原锁带到目标|
|F416|目标已有锁及父目录锁仍保护复制/移动写入|
|F417|协议可查询支持的锁类型及真实有效锁，不泄漏连接根外路径|
|F418|本人连接页能真实列出占用，刷新失败可重试|
|F419|本人确认后可按版本解除占用，过期界面不误解新锁|
|F420|320px英文深色及键盘读屏可用；有界请求和数量限制提供明确失败|

只有上述20项全部接通后开始本批集中测试。客户端实际兼容仅按已验证场景报告。非目标：共享锁、永久锁、Office/WOPI服务、跨账号锁、管理员跨用户解锁、自动覆盖锁或清空用户文件。现有文件、历史版本、配额和原预览必须保留。
