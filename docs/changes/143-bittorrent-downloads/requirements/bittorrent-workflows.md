# BT下载行为目标

客户目标：提交磁力或种子后，由服务端下载，在可恢复的任务中选择所需文件，最终在本人所选目录获得真实文件。浏览器关闭不意味着任务停止，下载器完成也不意味着转存成功。

以下为本批20项验收行为；不得把尚未接通的能力标成完成。

1. F441 明确看到当前实例可用的下载来源与节点能力。
2. F442 提交合法magnet并持久保存真实任务。
3. F443 提交.torrent内容并建立真实任务。
4. F444 无效或超过预算的元数据明确失败，不创建假文件。
5. F445 元数据获取有真实阶段、取消和超时反馈。
6. F446 显示真实多文件路径和大小。
7. F447 全选、清空与选择所需文件，空选择不能开始下载。
8. F448 所选文件计入本人配额与服务器预算。
9. F449 为任务选择本人保存目录，并保留目录层次。
10. F450 下载进度与速度来自实际引擎。
11. F451 暂停后停止当前下载意图并保留可恢复状态。
12. F452 恢复继续既有数据，不重复创建任务或文件。
13. F453 完成后校验内容并真实转存，明确区分下载与转存。
14. F454 转存失败可见，成功后打开实际结果目录。
15. F455 取消及删除任务按明确语义清理候选，保留已发布文件。
16. F456 服务重启后恢复意图与实际任务，不发布两份结果。
17. F457 两个账号提交同一infohash时互不暴露路径或操纵对方任务。
18. F458 节点中断可见，恢复和清理受控，不把旧worker成功当成有效发布。
19. F459 目标目录或权限/写锁变化时明确失败，不能越过当前文件写入规则。
20. F460 中文、英文深色与窄屏的列表、文件选择和失败提示可用。

约束：保留原有HTTP下载和v16数据；不接受任意本地路径或用户RPC凭据，不把第三方错误原文与秘密放入日志。不自研BT协议；支持管理员配置、与本服务共享暂存挂载的受信aria2节点及BT v1来源，不支持无共享目录代理或BT v2。未配置节点时明确不可用；节点网络策略不继承HTTP来源过滤，不能宣称任意远程节点均安全可用。详见R143-002和设计边界。
