# R185-001 栅格水印和 WebP 编辑

以 1573667 为本地基线。成功登录给定 Cloudreve 实例并打开「图片」视图，观察到列表为空。以官方截图确认水印入口与工作区，以实际源码确认 WebP 输入；Cloudreve 使用 Filerobot 默认编辑工具，官方中文资源区分上传水印与添加文字。通过 Filerobot 官方演示和文档复核本机图片水印。现场为空，具体效果以本地浏览器验收为证。

本地画布已有输出坐标文字水印、变换、受限编码、撤销及副本队列；`media-signatures.ts` 已验证 WebP 签名，但编辑入口在 `editableImageType` 排除 WebP。复用画布可直接新增一个局部图像覆盖层；整套 Filerobot（React/Konva/styled-components）会替换已验证的工作区、历史、无障碍与副本集成。决策为保留已有架构和浏览器原生解码、Canvas 合成。

仅用 createImageBitmap 无法在解码前确定尺寸；WebCodecs 解码接口不是现有浏览器共用基线。选择 image-dimensions 2.6.0 的窄数据读取接口，已复核官方源码、类型、MIT 许可证、近期发布、零运行依赖和可用于浏览器的 ESM。该库只读尺寸并通过 Host 局部模块封装，安全裁决由现有文件签名、字节限制和像素限制共同完成。现有 EXIF 库职责为照片信息；image-size 历史版本的解析器已有拒绝服务问题，且有更小、更适合浏览器的维护候选。方案不新建解码器，也不把依赖引入 Go。

结论适用于浏览器可解码的受限本机栅格图像和当前编辑器。线上图库、远端 URL、多图层、动图保真或服务器处理有不同的权限或资源边界，须重新研究。
