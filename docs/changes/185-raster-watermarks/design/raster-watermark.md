# 本地栅格水印与格式边界

本机文件选择通过现有按钮唤起原生文件输入。用已有签名检查限制 PNG、JPEG 和 WebP，在 2 MiB 上限内按需加载 image-dimensions，先读取宽高，再用浏览器 ImageBitmap 解码并复核宽高。读取、解析和解码异常分流为可见反馈；取消或离开后的迟到位图立即关闭。

编辑会话为位图唯一所有者。每次有效导入分配会话内标识，编辑快照只持有资源引用。提交、撤销、分支截断、移除与取消后，根据历史和当前草稿释放无引用位图。窗口关闭时释放其余资源；编码先同步绘制，随后异步保存已经渲染的画布。只有一个导入可进行，导入中暂停应用和导出。

画布按原有次序绘制照片及标注，再绘制图像水印和文字水印。图片水印以输出短边百分比确定最长边，九点锚定留边并保持原纵横比，透明度使用 Canvas 合成；几何变化后锚点仍针对输出画面。小样排除水印。WebP 输入走原有签名与权限边界，导出时同时核对 MIME 类型和扩展名。无服务端接口、配置或迁移。

浏览器集中覆盖真实选择、资源错误、草稿历史、透明像素与多格式副本；桌面和窄屏截图复核水印模式和布局。
