# 水印与 WebP

本人可在图片编辑器的「水印」下切换文字和图片。图片模式可选择本机的 PNG、JPEG 或 WebP，调整九个位置、尺寸和不透明度，并替换或移除。图片和文字可同时显示，设置应用后支持撤销与重做。预览和导出使用相同的比例与定位；透明水印叠加在照片上，源图不被覆盖。

拒绝无法识别或解码的水印、超过 2 MiB 或任一边超过 1024 像素的图片，并保留当前草稿。水印原件只在编辑器中使用，不单独上传。WebP 可像现有 PNG/JPEG 一样编辑、下载副本或将副本排队上传。PNG/WebP 副本保留透明度，JPEG 副本使用白底。导出采用单帧，浏览器无法编码 WebP 时可改用 PNG 或 JPEG。

范围为本人当前图片和编辑器会话内的一张图片水印及一条文字水印；适用权限、原件下载与副本队列沿用文件区契约。
