# R164-001 文件图标规则

Cloudreve `/admin/filesystem?tab=icon` 实际显示文件图标表、扩展名、内置图标、独立浅深色值和图像 URL。页面另有 Emoji 设置，与本项目的每项标记不同，本批单独处理按扩展名的图标规则。远端保持只读。

基线 `4842be1` 的 `icons.tsx` 已使用 Lucide SVG，`file-item.tsx` 实际执行 Emoji、缩略图和文件类型图标的优先级。根主题设置 `color-scheme`，适合标准 `light-dark()`。当前文件系统设置表可用独立记录 ID 与现有事务修订实现持久化，活动读取与管理写入沿用 files 权限分离。

渲染复用现有 SVG 库和浏览器原生图像。将第三方图像交给服务端代理会扩大网络边界，因此采用浏览器 HTTPS 匿名请求并省略 Referer。管理员选择外部地址，失败时显示本地图标。规则作用范围为文件外观。复核来源见元数据。研究门禁通过。
