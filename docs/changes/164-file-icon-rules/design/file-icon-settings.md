# 规则和图片边界

复用文件系统设置表的独立记录及修订锁。保存即生效，已打开文件页在刷新列表后读取。管理员读取与保存沿用设置权限，工作区通过只读端点获取活动规则。默认规则与自定义全集分别表示，空自定义明确表示禁用扩展名覆盖。

每条规则按末尾扩展名精确匹配，点与大小写归一，跨行重复拒绝。外部图标只接收无凭据、查询和片段的 HTTPS 公共域名 URL。浏览器以匿名模式发起请求并省略 Referer。跨源图像必须允许 CORS，失败时显示本地图标。浅深色仅接受六位十六进制。图标只改变本人文件项装饰，优先级为个人 Emoji、已有缩略图、扩展名规则、类型图标。文件夹与快捷方式使用原装饰。

验证权限、修订、持久化、校验及普通用户浏览，在隔离预览对照日间、夜间、窄屏和失败图片。
