DST远期案例用于验证消歧和正确ISO请求，并明确由服务端30天上限拒绝；不称其已持久化。有效范围内的自定义期限则真实创建并读回；keep模式使用带毫秒的真实分享再次保存并比较，另验编辑gap不发送更新且保留输入。
