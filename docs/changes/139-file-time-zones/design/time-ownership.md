# 时间所有权与失败语义

## 模块及数据流

i18n新增纯format入口，提供有效时区验证、系统实际时区、候选和按区域的瞬间日期/时间格式化。保留纯日历formatDateOnly原语义，文件瞬间使用新函数。i18n独立temporal入口封装@internationalized/date3.12.3，公开字符串草稿与typed结果，不导出第三方对象。显式依赖与治理只增加已有版本的允许调用方，无新库或版本升级。

files的useFileTime订阅现有PreferencesPort，返回日期、完整时间及当前区域快照，卸载自动取消订阅。各组件移除toLocale和不带区域的formatDate调用，统一使用该Hook。无效值或不支持时区明确呈现不可用，不静默使用UTC。设置页与账户编辑使用现有ComboField和完整候选；模型在写入/恢复边界验证时区，现有恢复与持久化错误机制保留。

## 分享输入状态

ShareExpiryDraft新增实际IANA时区及重复时刻选择，创建时解析当前偏好auto为当前系统时区。当前到期时刻经成熟库转换成该地日历日期/时分。custom通过parseDateTime及toZoned解析，不使用new Date拼Z。成熟库的earlier/later候选回转日历字段不一致时识别为gap，字段相同但绝对时刻不同则识别为overlap；gap不允许选择绕过，overlap明确选择后才输出ISO瞬间。

保持模式直接返回原字符串，保留秒/毫秒；相对模式使用明确小时常量和当前瞬间，不走日历加减。界面显示草稿时区、转换错误及成功预览，区域设置变化不重解释已打开草稿。有效期错误阻止请求，保留输入；后端权限、未来时间和有效期上限仍最终校验，不放宽协议。

## 生命周期、安全与迁移

本批无Go、数据库、网络客户端或运行任务变更。无全局可变日期缓存、轮询或自行维护时区数据库。Intl仅在i18n边界创建；模型使用该窄契约。UI不写日志中的日期、时区草稿或凭据；转换异常只转为稳定错误类别。原文件及偏好数据不重置；非法旧区域设置通过既有恢复流程处理，不暗中覆盖。
