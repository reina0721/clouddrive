# 文件时间行为

客户希望同一文件在列表、属性和分享中看到一致时间，自定义到期日期不能因浏览器或夏令时而悄悄偏移。存储仍使用真实绝对时刻，显示设置不改文件或分享内容。

1. F361 文件修改列按所选时区显示。
2. F362 文件创建列按所选时区显示。
3. F363 网格短日期遵循日期顺序设置，正确跨日。
4. F364 网格完整提示遵循时区、12/24小时与秒设置。
5. F365 回收项使用真实回收时刻并遵循相同区域设置。
6. F366 属性创建时间与列表一致。
7. F367 属性修改时间与列表一致。
8. F368 历史版本时间遵循相同设置。
9. F369 分享列表到期时间遵循相同设置。
10. F370 新分享回执到期时间遵循相同设置。
11. F371 分享详情的创建及到期时间一致。
12. F372 WebDAV连接创建及到期时间一致。
13. F373 离线任务创建、开始、完成及到期时间一致，缺失仍明确为空。
14. F374 传输显示真实会话到期时间，尚无会话不伪造时间。
15. F375 自定义分享输入以明确显示的时区转换并显示最终时刻。
16. F376 编辑时保留原到期瞬间，选择保持不丢秒；相对小时不变成日历加减。
17. F377 不存在的夏令时时间拒绝，保留用户输入并说明原因。
18. F378 重复的夏令时时间要求明确选择第一次或第二次。
19. F379 可搜索浏览器支持的时区，支持系统跟随、UTC及有效现有别名；非法值被拒绝，既有持久化失败不宣称成功。
20. F380 区域变化即时刷新文件时间；英文、深色、320px和键盘/无障碍可用，自动与固定时区跨浏览器环境的含义正确。

以上20项是使用行为，不是20项独立后端能力。非目标：更改服务端过期判定、重写数据库时间、树拖拽、版本保留、BT与Office。
