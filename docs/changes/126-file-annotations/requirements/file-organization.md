# 文件整理与属性

客户要用标签和自己的属性整理文件，并在网格/列表及搜索中找回这些信息。文件夹可以改变颜色，条目可用Emoji代替图标；复制、内容覆盖和回收恢复不得丢失整理结果。属性面板提供可复制位置和可核验目录统计。

本批F121–F140：

| ID   | 可验收行为                                                           |
| ---- | -------------------------------------------------------------------- |
| F121 | 给自有文件、目录和快捷方式添加命名标签                               |
| F122 | 在属性编辑中重命名既有标签，重复名称明确拒绝                         |
| F123 | 使用六位RGB颜色定制标签，名称保持可读                                |
| F124 | 移除指定标签，不改动其他整理信息                                     |
| F125 | 多选项目批量添加标签，已有不同属性保持，失败整批不写                 |
| F126 | 多选项目批量移除指定标签，不存在时保持其他信息                       |
| F127 | 网格/列表显示标签，点击可在全部自有文件中按该标签查找                |
| F128 | 高级搜索按全部指定标签查找，可和已有条件组合                         |
| F129 | 按任一指定标签查找，URL刷新/历史保持条件                             |
| F130 | 添加私有自定义字符串属性，键和值有明确上限                           |
| F131 | 修改属性值，空字符串区别于属性不存在                                 |
| F132 | 删除指定自定义属性，系统事实不能通过它改写                           |
| F133 | 按属性存在、值相等或包含内容搜索；条件可移除                         |
| F134 | 为条目选择Emoji文字图标，图片缩略图不遮盖该选择                      |
| F135 | 为目录选择图标颜色，非目录不能设置目录颜色                           |
| F136 | 明确清除个性化图标/颜色，恢复默认展示                                |
| F137 | 属性面板复制当前完整名称与位置，失败明确提示                         |
| F138 | 目录显示有效后代文件/目录/引用数和逻辑字节；不把目录自身当零大小文件 |
| F139 | 文件及目录副本保留独立整理信息，修改副本不影响原件；覆盖内容也保留   |
| F140 | 回收后恢复标签、属性和个性化仍在，不清空原文件                       |

最多8标签、8属性、100项批量操作，默认每条注解合计2048字节，可受管理员更低预算约束。错误、超预算、冲突不悄悄清空输入；并发编辑需要重新读取，不能强制覆盖。整理信息仅本人私有，不自动公开到分享或协议客户端；其他账号不能读取或修改。读取与统计超过账号树预算时明确失败。
