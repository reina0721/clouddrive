# 持久规则与准入

规则在既有文件设置表保存为独立 `storage-name-rules` 键及修订号，复用存储锁、比较并交换及当前存储策略权限。重启时按应用代装配。无新依赖和 schema 迁移。

扩展名取文件名最后一段后缀并转换为小写。空列表或正则各自忽略，两项都通过才允许。标准库 RE2 匹配完整名称字符串，可用锚点限制匹配范围。表达式在保存或试测时编译，业务请求复用当前代已编译规则。只向客户端提供稳定拒绝原因。

普通或分享上传检查新会话，已保存会话使用原名续传，重新指定名称时校验。小文件写入先查幂等回执。文本替换、WebDAV PUT 和未映射 LOCK、ZIP、解压、HTTP 来源定名、BT 选择与发布检查实际输出名称。目录、只改元数据的复制改名与历史恢复保持既有行为。
