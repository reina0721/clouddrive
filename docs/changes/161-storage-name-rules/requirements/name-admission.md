# 上传与生成限制

F801–F820 使用行为如下。

1. 在存储策略查看扩展名和文件名规则。
2. 扩展名可用允许列表。
3. 扩展名可用拒绝列表。
4. 扩展名忽略大小写，接受带点输入并去重。
5. 空列表恢复不限。
6. 正则支持允许模式。
7. 正则支持拒绝模式。
8. 空表达式恢复不限。
9. 无效或超预算表达式会被拒绝。
10. 测试文件名显示通过或首项拒绝原因。
11. 只读角色可查阅规则，保存受写权限和版本保护。
12. 显示已保存规则及当前生效状态。
13. 新建私有上传受规则限制。
14. 分享上传和共享文本写入受规则限制。
15. WebDAV 写入与新建空文件受规则限制。
16. HTTP 离线下载检查显式名称和源建议名称。
17. BT 选择和发布检查各文件名。
18. ZIP 创建及解压检查最终发布名称。
19. 既有文件可读取、改名和恢复，旧上传会话可继续。
20. 手机布局可编辑、试测并保存。

规则检查名称，文件内容类型仍按现有流程处理。
