# 版本保留事务与规则

## 数据及接口

model.HistoryPreferences包含revision、enabled、extensions、maxVersions；默认enabled=true、extensions空数组、maxVersions=0，旧账号与原服务策略一致。扩展名最多32，每项1–32位ASCII小写字母数字及内部连字符/下划线；输入可去单个前导点、小写化，存储契约规范且拒绝重复。maxVersions为0–20旧版本数。服务端HistoryEnabled优先，perFile/perOwner仍是硬预算。

新增files_history_preferences表（owner_id/revision/document），v15三驱动增量迁移，已应用migration不改。PreferencesRepository增加ReadHistoryPreferences/SaveHistoryPreferences，复用既有Preferences用例和Handler；GET/PUT /preferences/history使用现有files:read/write、会话和CSRF，独立CAS不与本机视图模式混杂。没有策略记录以明确默认返回；损坏文档返回错误，无隐藏回退。

## 原子内容替换

Repository新增ChangeContent窄契约，回调携带目录事实和HistoryPreferences，均在storage/owner事务中读取；ReplaceText使用它。分享scopedRepository复用已授权ShareSnapshot增加的策略字段并维持所有子树校验。TransferSnapshot、ConnectionFileSnapshot各增加HistoryPreferences，repo在同一owner锁内加载。没有服务层反向导入repo或从上下文查找隐藏状态。

统一prepareReplacement(entries,entry,prefs)返回候选entry；不开启或扩展不匹配则保留既有历史不新增。匹配时先按revision保留最多maxVersions-1个最近旧关联，再append当前为新历史，增量historyRevision一次；0不主动淘汰。用裁剪后总数检查全局/单文件硬预算与JSON大小。函数不修改输入slice，失败不产生外部副作用。

逻辑replacementUsed为原model.Used减原当前及原历史字节，再加候选历史字节；发布还加新内容字节。admission按同一目标的实际候选历史计算净增长，抵扣将被替换的旧当前及被裁剪关联，负增长按0预留，不向其他目标预支尚未释放的容量。同目标并行会话以内容CAS保证至多一个可发布；设置或内容变化后最终事务重新计算，不能使用旧准入决定绕过配额。最终事务重读规则并重新计算，若规则变化使配额不足，仍保持原候选可重试，不能用旧规则绕过预算。

stream_ingest与tus admission通过同一候选规则检查是否可保留；最终Transfers提交重新prepareReplacement。WebDAV COPY按目标名匹配，tus/name CAS保证覆盖目标未被并行更改；分享文字按owner规则。恢复保持现有等量关联提升，不调用自动裁剪；复制保留独立关联，不立即套用新策略。策略写入只变策略表，不操作文件。

## 前端及错误

Surface新增HistoryPreferences严格模型与FilesPort异步load/save方法，Host通过现有会话HTTP client调用。独立设置弹窗由文件全局菜单入口打开，busy禁重入，失败保留草稿，409显示明确读取最新动作。无localStorage策略副本，不以网络失败回退。版本页返回账号规则以说明当前file是否适用、0和服务端预算；显示文案不暴露内部类名。

复用UI Adapter字段、Switch/Action/Dialog及现有i18n，非法表单本地阻止请求。保存前持续提示后续覆盖会淘汰最早关联且不会立即清理已有历史。只展示业务可理解的限制，不输出对象键或凭据。加载/保存日志边界沿HTTP稳定低敏事件，异常保留链，取消由请求ctx及前端卸载保护管理。
