# 版本保留行为

目标：用户可控制未来哪些文件保留历史以及保留最近多少个旧版本，跨设备生效并明确影响。以下20项是使用行为，非20项独立功能。

1. F381 本人文件设置中可读取真实服务器保留规则。
2. F382 可启停未来版本保留，保存后刷新不丢。
3. F383 扩展名留空适用于全部文件。
4. F384 可配置多个扩展名并规范大小写及前导点。
5. F385 拒绝非法、重复或超量扩展名，不发送无效保存。
6. F386 可配置最近旧版本数，0表示没有用户限制且明确服务端预算。
7. F387 保存设置不立即修改已有历史或当前文件。
8. F388 关闭后文本覆盖不新增历史，已有历史保留。
9. F389 匹配扩展名覆盖会保留旧版本，不匹配不新增。
10. F390 数量上限在成功覆盖时保留最近旧版本，当前内容不被淘汰。
11. F391 数量淘汰与新内容原子提交，失败不丢旧关联。
12. F392 tus上传覆盖遵循同一规则。
13. F393 WebDAV PUT遵循同一规则。
14. F394 WebDAV COPY覆盖遵循同一规则。
15. F395 分享文字修改遵循拥有者规则，访客不能修改设置。
16. F396 逻辑配额根据保留及裁剪结果准确计算，不承诺物理空间立即回收。
17. F397 上传开始与最终保存分别读取当时规则，规则变化后最终配额失败保留可重试候选。
18. F398 多设备修改冲突保留草稿，可明确读取最新；读取/保存失败显示真实错误。
19. F399 账号间隔离；恢复旧版仍保留恢复前内容，不受未来保留开关影响。
20. F400 中英文、深色、320px、键盘及无障碍可用；版本面板说明实际生效规则。

约束：原账号未设置时沿用既有行为；原文件和历史不重置。服务端硬预算仍有效，0不是无限存储。非目标：物理GC、后台批量淘汰、无界版本或远程节点。
