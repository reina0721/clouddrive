# 引用与固定导航

客户场景：用户收到一个公开或密码保护的分享，希望登录后收藏在指定目录，下次快速访问；经常使用的文件夹及共享入口希望固定到侧栏。分享者撤销或文件失效后，收藏不能绕过限制。

| ID | 可验收行为 |
| --- | --- |
| F81 | 侧栏可进入真实“与我共享”，区分加载失败、空列表与已有引用。 |
| F82 | 分享页面可发起保存；未登录时登录后返回保存流程，不保存原分享密码。 |
| F83 | 可导入当前实例标准分享地址，选择自己的文件夹和别名；拒绝外站、无效地址及不存在分享。 |
| F84 | 保存后在自己的相应目录显示为快捷方式，刷新/登录/服务重启后保留。 |
| F85 | 打开引用进入原分享验证流程；密码分享仍需解锁，不借用自己的文件权限读取他人内容。 |
| F86 | 共享列表反映当前可用、密码保护、过期、撤销和目标不可用状态，不泄露锁定目标名称。 |
| F87 | 引用可重命名，命名与版本冲突明确拒绝，失败保留输入。 |
| F88 | 引用可移动至自己的有效目录，保持目标不变并检查冲突。 |
| F89 | 引用及包含引用的目录可复制，不复制原分享内容，仍受引用数量约束。 |
| F90 | 移入回收站只回收自己的引用，不撤销或删除原分享。 |
| F91 | 可恢复引用到原位置或另选有效目录，冲突时不覆盖已有条目。 |
| F92 | 已回收引用可在明确确认后永久移除，只删除引用及其固定入口，原内容保留。 |
| F93 | 可固定自己的有效文件夹到侧栏，并从固定入口打开。 |
| F94 | 可固定“与我共享”视图到侧栏，不创建重复入口。 |
| F95 | 可固定已保存分享引用到侧栏，打开仍验证原分享。 |
| F96 | 固定项可调整顺序并持久保存，过期版本不覆盖最新顺序。 |
| F97 | 可取消固定，不影响文件、目录或分享引用本身。 |
| F98 | 固定项跟随目标改名/移动；回收时明确不可用，恢复后重新可用。 |
| F99 | 共享引用可按自己的别名搜索、按可用状态筛选并分页，不把失败显示成空结果。 |
| F100 | 所有引用和固定操作按账号隔离、执行当前文件权限和数量限制；撤销与字节入口不能泄露目标token或原内容。 |

范围外：跨站抓取、转存分享内容、账号协作写授权、自动保存密码、WebDAV内展开分享、永久对象垃圾回收。删除引用的确认不授权开发代理清理已有用户数据。
