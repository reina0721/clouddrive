# 局部布局与验证

边界：FileWorkspace拥有六页视口分配和顶部工具；ExplorerNavigation拥有展开/收起与移动抽屉；PinnedLinks只缩紧局部间距；FileItem拥有条目布局；FilesPage拥有目录路径、网格与空态。修改上述文件及必要的本地文案和浏览器验收，不改公共组件默认尺寸。

布局：根Shell按dvh建立Flex，桌面侧栏分配品牌、主导航、可滚动固定项和存储；主区域为不可压缩顶部工具及独立可滚动main。使用现有spacing/size/rounding语义utilities，不使用自定义像素或深层CSS。抽屉保留原有焦点归还；短视口允许导航自身滚动，避免内容不可达。

文件页：使用局部语义容器替代带页面动效的整页外壳，防止固定滚动容器被transform干扰；顶部路径保留完整路径菜单和单行溢出处理。根目录不显示无效返回；返回子目录仍有可访问名称。网格按响应断点增加列；条目缩小内边距、两行长名称带title，列表减小纵向留白；所有选择和菜单保持真实且可触达。空态用本地容器居中现有StateSurface，不复制其内部结构。

状态、错误、资源：保留现有loading/error/empty、CAS草稿、上传、剪贴板、菜单与快捷键控制流。无新异步资源，无配置、数据库或历史数据变更。不能影响安全主体与权限判断。六页共享布局引起的回归须定向覆盖；发现公共契约缺口则回到研究，不穿透vendor。

实施：按F301–F320接通后记录wiring，之后才格式/生成/构建/测试。增量基线记录HEAD和路径，不因阶段变化重做研究。原预览继续运行；独立且未被运行进程使用的目录验证后再切换，候选不覆盖正在运行目录；空间有限时允许复用已停止的候选目录，当前主预览保持不动。

验证：范围格式、Surface类型/lint、架构/基础/依赖/生成、675既有单测、真实浏览器关键文件与六页工作区/导航/权限/浮层回归；新增视觉流程覆盖独立滚动、可见存储、网格密度、长路径与长名称、空态、手机、英文深色、键盘与Axe。人工看图后才判断布局成功；不以scrollWidth单一条件替代视觉判断。最终双生产构建及原预算，不放宽49152字节CSS上限。磁盘仅约180MB，构建前再查空间，失败如实记录，不绕过已拒绝的清理动作。
