# 文件工作区密度与导航

目标：在相同桌面面积看到更多文件并持续访问导航、创建、搜索与账户工具；窄屏和键盘使用者仍能完成原有操作。适用于真实文件、分享管理、连接、传输和离线页面；不新增后端能力，不修改文件或账户权限。

- F301：桌面工作区约束在可用视口内，避免页面与内容双重滚动。
- F302：滚动文件时顶部创建、搜索与账户工具保持可用。
- F303：文件内容独立滚动且键盘焦点进入时可见。
- F304：导航行紧凑呈现分类与各真实文件入口。
- F305：展开导航完整显示项目品牌，收起仍保留可识别标志。
- F306：存储空间独立呈现，常规桌面高度下无需滚到底部寻找。
- F307：固定项可在独立区域滚动，不挤走常用导航与存储。
- F308：收起导航的图标轨道居中并保留名称提示。
- F309：窄屏导航与工作区工具组合不产生横向溢出。
- F310：桌面搜索限制合理宽度，保留队列与账户位置。
- F311：紧凑搜索提交仍具完整可访问名称与Enter操作。
- F312：新建入口以小尺寸组合保留所有真实创建与上传动作。
- F313：上传队列采用紧凑布局且仍显示活动数量。
- F314：根目录不再显示无效上级按钮，子目录保留可访问的返回入口。
- F315：长目录路径保持单行可滚动，完整路径菜单继续可用。
- F316：网格随可用宽度提供更多列，同时窄屏保持可操作宽度。
- F317：网格项目缩小留白并保留类型、容量、时间与所有动作。
- F318：长文件名可显示两行，并能查看完整名称。
- F319：列表降低行留白，保留列、选择、排序与键盘焦点。
- F320：空目录采用居中的上传引导，搜索/回收空态保留各自语义。

验收：1280×720、超宽屏、320px/390px、深色英文和长名称/路径均无意外横向裁切；实际文件创建、选择、打开、菜单、搜索、上传与各入口可用。保留明确错误与加载反馈，不更新无关截图或放宽预算。
