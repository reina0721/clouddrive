# R162-001 文件列表分页

参考站 `/home` 的视图菜单显示分页大小滑块。`/admin/filesystem` 参数设置的文件系统段提供列表分页方式和最大分页大小，说明搜索强制使用游标。菜单说明传统分页可跳页，游标模式在滚动到底端时自动加载。该实例显示游标分页及每页 2000 项上限，未修改远端设置。本批先交付可定位的显式上一页与下一页，自动追加和页码跳转另行设计。

本地 `internal/module/files/service/query.go` 对 10000 项以内的快照校验可见性、筛选、排序后切片，页大小硬上限 200；`files-page.tsx` 只有页码导航。R154-001 的 JSON 覆盖和应用代机制仍有效。共享列表、文件选择器、树、配额及画廊复用查询入口，切换它们将影响原行为。

可复用 Go 标准库的比较、SHA-256 和 URL 安全 Base64，以及 Next 路由和既有设置机制。当前边界可表达同一排序中的条目位置，采用同一快照查询模型即可支持游标。SQL 键集需要迁移本地标签、祖先可见性及排序语义，超出本批，当前方案没有数据库扫描性能承诺。参考站数值不构成本地安全预算。排序与作用域变化需重新验证游标。研究门禁通过。
