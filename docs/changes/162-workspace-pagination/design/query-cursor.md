# 排序锚点及工作区集成

复用文件系统设置 JSON 及修订锁，无迁移。页大小上限仍受 200 的硬边界保护。旧设置继承页码模式，覆盖值在新的应用代生效。仅本人工作区声明使用活动设置，显式旧页码链接兼容，搜索首批和继续操作使用游标，画廊仍走有界快照。

在授权后的快照内按现有顺序找到游标锚点，截取锚点之前或之后的页大小。游标只保存方向、条目标识以及绑定账户、查询与排序值的摘要；提交游标仍走全部原可见性与过滤。游标是翻页定位数据。锚点被删除、离开结果或排序值改变时返回可恢复的过期结果。它不会固定并发快照。UI 以 URL 保存游标，翻页复用请求取消，参数变化回首批，旧页码仍可继续。

用单元及 HTTP 验证边界、倒序、插入、失效和旧请求，隔离浏览器覆盖管理员表单及分页操作。保留已有预览数据库。
