# 文件引用的关系投影

文件模块增加 `files:blob:read`，复用 IAM 及 GET 操作门禁。使用数据库原生 JSON 表函数将文件历史按版本展开，和当前文件组成统一引用关系。按物理对象键分组；每页及计数在一个 SQL 语句读取。关联条目创建时间只描述引用时间证据，无法推断 Blob 本身创建时间。对象 ID 复用发布 UUID，响应隐藏路径、摘要及凭据。

详情在数据库租约内读取该对象及有界引用分页，随后通过当前主存储租约执行只读 Exists。文件引用和探测分别是瞬时观察。不存在对象显示缺失，存储连接或权限失败保留原始原因并返回错误。无迁移、表写入、资源后台扫描或物理删除。现有窗口调度与内容发布路径不变。

后台系统菜单按独立权限呈现入口，复用数据表、表单、弹窗与分页。验收用真实副本、覆盖、恢复与回收，包含其他账号拒绝及窄屏详情。

维持现有前端体积预算。API 工作台运行时只在已登录应用布局装配，生命周期覆盖该布局内的全部页面切换。
