# 查询已引用 Blob

管理端提供独立授权的“文件 Blob”清单，按存储对象计一行，显示对象大小、主存储、总引用数、关联所有者数以及最早关联文件的创建时间。当前内容、已回收条目和历史版本的引用仍然计数。不同内容对象保持独立；多个副本引用同一对象时合并显示。

可以按引用所有者、当前或历史引用及主存储筛选。所有者筛选保留对象的全局引用数。结果可按 ID、大小、引用数和最早关联文件时间排序，支持分页、刷新和重置。详情显示引用条目及版本并检查对象存在性，缺失时明确显示。清单只读取已有引用及对象存在性。孤立对象扫描、物理回收、Blob 导入及跨账号下载独立规划。

## F621–F640

1. F621 管理面板显示“文件 Blob”入口。
2. F622 普通文件账号看不到该入口。
3. F623 直接访问页面及接口执行独立授权。
4. F624 同一对象的多个副本归并为一行。
5. F625 相同字节的不同对象仍独立显示。
6. F626 展示真实关联大小和主存储。
7. F627 当前版本与历史版本分别计数。
8. F628 回收条目的引用继续计数。
9. F629 恢复历史时统计实时反映新引用状态。
10. F630 按所有者过滤并保留对象全局统计。
11. F631 支持当前、历史及仅历史引用筛选。
12. F632 支持主存储策略筛选。
13. F633 支持确定性的排序及分页。
14. F634 空结果明确提示。
15. F635 刷新保留条件，重置还原初始筛选。
16. F636 详情显示引用文件、所有者、版本与回收标记。
17. F637 引用分页保留完整引用总数。
18. F638 对象存在或缺失时分别展示真实状态。
19. F639 无有效引用的对象不再列出，接口不输出路径和凭据。
20. F640 320px 窄屏可查看只读引用详情。
