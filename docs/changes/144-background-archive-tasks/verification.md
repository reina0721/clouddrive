# 144 后台解压验收

运行环境为 Windows、Go 1.26.10、Next.js 16.4.5 和本机 SQLite。20 项用户行为接通后集中验证。测试使用隔离 QA 账号与合成归档。

| 验收项 | 证据 |
| --- | --- |
| F461–F464 | 浏览器核对侧栏入口、手动刷新和自动刷新切换。桌面主预览确认没有记录的居中空态。共享刷新计时器的可见性、卸载和账号围栏由现有 Host 单测覆盖。 |
| F465–F469 | 真实 ZIP 全部提取、选择提取、普通 7Z、选择本人目标和可选包裹目录。 |
| F470–F472 | 拒绝同名后原文件保留，跳过与改名均显示实际计数；通过目标目录列表校验内容。 |
| F473–F475 | 提交后跳转，刷新保留同一记录，成功计数和结果目录与真实文件一致。 |
| F476–F478 | 第二账号不能列出、读取、取消或清理首账号任务。同一提交键重复请求返回同一任务。实际取消排队任务后目标目录没有取消项。 |
| F479 | 停止并重启隔离 QA 后端，确认进程 ID 改变，同一任务从排队进入完成并读出结果字节。可控时钟的 SQLite 测试验证过期领取、中断状态、旧领取拒绝发布和候选清理。 |
| F480 | 普通 7Z 后台入口和加密 7Z 同步入口均经真实浏览器验证，后台 JSON 输入拒绝密码字段。 |

- Go 全量测试通过。SQLite 测试验证新增 v18 表前的旧目录保留、未清空任务拒绝回退、记录清除保留真实文件。
- 前端单元测试、类型检查、架构及基础规范检查通过。压缩包浏览器回归套件 10 项全部通过，包含原同步流程和新后台任务。主预览与 QA 的生产构建通过原预算，CSS gzip 为 49,148 字节。浏览器宽度 375 像素时文档没有横向溢出。
- 对照参考站的侧栏任务入口、标题旁刷新、右侧开关及中央空态。截图和独立进程重启回执保存在仓库忽略的 `.data` 目录，回执文件为 `144-restart-receipt.json`。
- 主预览、开发和 QA 三个数据库均备份至 `.data/backups` 后迁移到 v18。每库 19 张既有文件表的列、行数和内容摘要一致。主预览、开发和 QA 服务均已重启。

本轮直接运行 SQLite。MySQL、PostgreSQL 提供同版本迁移和校验和，尚未连接实例验证。全站浏览器套件未作为本批验收范围。实际参考页没有任务记录，已填充的任务状态以本项目真实操作和回执验证。

仓库文档守卫在干净的暂存快照中仍报告 `frontend/docs/quality-evidence.md` 的两个历史日志链接，影响清单和本批链接未报告错误。
