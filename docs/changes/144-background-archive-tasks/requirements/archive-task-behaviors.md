# 后台解压行为

1. F461 文件区提供独立后台任务入口。
2. F462 空账号看到居中的空态及可用刷新操作。
3. F463 手动刷新能重新读取实际任务。
4. F464 自动刷新可开启与关闭，离开页面结束刷新。
5. F465 普通 ZIP 可提交全部后台解压。
6. F466 ZIP 可后台提取部分成员或子目录。
7. F467 无密码 7Z 可提交后台解压。
8. F468 可选本人目标目录。
9. F469 可选新包裹目录或直接解压。
10. F470 拒绝同名时保留既有文件并展示失败。
11. F471 跳过同名时结果显示跳过数量。
12. F472 改名时结果显示改名数量。
13. F473 提交后可直接打开任务页，看到真实排队、处理中或终态。
14. F474 页面重新打开后仍能查到同一任务。
15. F475 成功回执展示实际创建数并可打开目标。
16. F476 账号隔离适用于列表、读取和修改任务。
17. F477 重复提交同一请求不会重复提取。
18. F478 尚未领取的任务可以取消，且不会产生文件。
19. F479 服务重启后排队任务仍可执行；中断任务有明确结果，部分文件不会出现。
20. F480 加密包可继续在当前请求内解压，后台入口不会接收或保存密码。

补充边界包括目录变化、空间不足、当前写权限撤销、手机布局和保留容量。下载及上传原页面各自保持当前用途。
