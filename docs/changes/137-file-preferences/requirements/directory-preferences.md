# 目录偏好使用行为

用户在视图选项中选择同步模式、是否记住各目录及文件夹点击方式。已有本机设置保留；同步失败明确提示并可重试，不显示虚假已保存。

本批20项验收行为：

1. F321：显式开启同步，将当前本机设置保存到本人服务器空间。
2. F322：关闭同步后继续使用当前设置，本机后续变更不改服务器。
3. F323：同账号另一浏览器开启同步后读取真实服务器偏好。
4. F324：不同账号的设置相互隔离。
5. F325：开启按目录记忆后，两个目录可保留不同视图。
6. F326：根目录拥有独立设置。
7. F327：未保存过的目录使用全局默认。
8. F328：关闭目录记忆后所有目录使用统一默认。
9. F329：重新开启记忆保留原有目录覆盖。
10. F330：可将当前视图设为全局默认。
11. F331：可重置当前目录覆盖而保留其他目录。
12. F332：可清除全部目录覆盖而保留全局默认。
13. F333：网格、列表、画廊及其排序、分页、列、缩略图设置一起保存。
14. F334：旧本机偏好可迁移，不静默丢失。
15. F335：选择单击打开文件夹。
16. F336：选择单击选中文件夹。
17. F337：选中模式下双击进入文件夹。
18. F338：键盘确认仍可进入文件夹，修饰键选择保持可用。
19. F339：多设备修改冲突明确提示，可重载最新设置后再修改。
20. F340：服务器读取或保存失败可重试，本机模式不依赖网络；待处理时阻止重复保存。

最多保存200个目录，超过时明确报错，不自动淘汰其他目录。清除仅删除偏好覆盖，不删除文件、历史版本、分享或上传任务。当前原有数据库及存储文件必须保留。
