# R155-001 Cloudreve 全局属性和本项目现有属性

Cloudreve 4.19.1 的文件系统自定义属性页按名称和类型列出定义。添加菜单提供文本、数字、勾选、单选、多选、链接、评分和用户 Pro。文本及数字表单包含稳定标识、展示名、可选约束与默认值。参考站仅浏览表单，未保存变更。官方 API 以配置定义标识关联每文件的字符串值。[元数据协议](https://docs.cloudreve.org/zh/api/metadata)

本项目 `model/annotations.go` 持有键值、预算与旧属性校验，`service/annotations.go` 负责访问与归一化，`repo/repository.go` 的条目修改与存储/所有者锁覆盖私有属性保存。按同一锁读取全局定义可保持管理员配置与属性保存的一致性，无需新存储、依赖或第二份文件值。旧值不自动改写，复制和搜索仍读现有键值。使用 Go 标准库解析数值、JSON、URL，复用现有表单组件。

属性类型在本版本定义公开规则。多选以有序 JSON 数组字符串持久化，链接仅允许 HTTP/HTTPS。图标目录接入、用户 Pro、值的跨文件批量修改和全局全文索引独立规划。参考菜单及表单不能证明这些扩展已实现。
