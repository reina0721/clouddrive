# 定义和填写文件属性

管理人员可以定义可重复使用的属性。用户在本人文件或目录的属性编辑器中使用这些定义，也可以继续编辑自有普通属性。定义删除后已存值保留。安装现有数据不会发生隐式转换。

1. F681 文件系统提供自定义属性标签。
2. F682 清单显示稳定标识、名称和类型。
3. F683 管理读取和编辑权限分离。
4. F684 文本定义支持字符长度范围。
5. F685 数字定义支持小数和数值范围。
6. F686 勾选定义支持真值和假值。
7. F687 单选定义限制为配置选项。
8. F688 多选定义接受多个独立选项。
9. F689 链接定义拒绝危险协议。
10. F690 评分定义支持有界整数。
11. F691 属性标识格式、唯一性和定义数量有界。
12. F692 默认值经过相同类型校验。
13. F693 管理员能修改展示名或规则。
14. F694 管理员能移除定义并保留已存值。
15. F695 过期修订无法覆盖其他管理员的保存。
16. F696 文件属性编辑器可添加已定义的属性。
17. F697 对应控件写回现有文件属性表示。
18. F698 文件写入拒绝不合规则的新值。
19. F699 旧值、普通属性、复制和属性检索继续可用。
20. F700 定义重启后仍可用，桌面和窄屏可完成流程。
