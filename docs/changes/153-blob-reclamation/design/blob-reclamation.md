# 持久候选与实际回收

增量迁移 v22 新建候选表。通用条目写入、传输覆盖和永久移除均在原事务中登记被解除的规范已发布键。迁移无回填。候选在最后一次解除后等待 24 小时，仍被引用的对象从候选列表排除。操作使用现有存储身份锁，在同一短事务重查候选和全局引用，验证转存状态，通过现有主存储删除，随后移除候选。外部删除与数据库提交分离的故障窗口由对象不可重新引用及幂等删除覆盖。主存储切换拒绝存在未处理候选的数据库。

管理 GET 使用 Blob 读取权限，清理 POST 使用独立高风险权限及写请求保护，输入只允许公开 UUID。自动回收复用调度器，默认关闭，间隔受配置约束。单对象设置请求超时，后台按到期顺序有界处理，失败对象保留并退避。清单不披露存储路径，不直接调用第三方 API，保留旧数据及未知孤立对象。
