# 管理无引用的文件内容

文件 Blob 页面显示待回收的已发布对象。管理人员可区分等待保护期和可回收对象，有专门权限的人可确认清理。运维可选择打开后台扫描。回收永远保留仍被任何文件或历史版本引用的对象。

- F641 手动永久删除登记内容。
- F642 到期永久删除登记内容。
- F643 删除历史版本登记内容。
- F644 覆盖导致旧引用淘汰时登记内容。
- F645 内容仍被副本引用时保留。
- F646 内容仍被历史引用时保留。
- F647 对象重复解除引用只保留一条候选。
- F648 回收条目恢复后内容仍可读取。
- F649 迁移前未登记的孤立对象保留。
- F650 候选跨进程重启保留。
- F651 管理页面提供待回收入口和空态。
- F652 显示大小、登记时间及可回收时间。
- F653 候选分页和刷新。
- F654 保护期内拒绝回收。
- F655 查看权限与永久清理权限分离。
- F656 页面二次确认后清理单一对象。
- F657 主存储已缺失时清除候选并可安全重试。
- F658 存储错误保留候选。
- F659 后台回收默认关闭并支持明确开启。
- F660 后台按受控批量回收，独立处理失败项。
