# 导入并打开 WOPI 阅读器

- F1001–F1010 从管理页进入 WOPI 导入，填写、校验和取消发现地址，查看导入错误与可用格式，过滤非浏览动作和重复格式，可应用到草稿并统一保存。
- F1011–F1015 按格式分派到对应阅读器，允许改名、限制平台、指定默认应用或停用和移除。导入需要管理写权限并复用并发保护。
- F1016–F1020 所有者确认站点后，以 WOPI 表单打开相应格式。第三方能读取正确文件的只读属性和内容。无效或过期授权、错误文件标识、被替换文件和未授权写请求不会修改文件。

覆盖同源 HTTPS 自托管阅读器的 view。协作编辑、保存回写、自动定时刷新和 CSPP 证明密钥按独立协议能力继续对齐。
