# 发现与只读链路

管理接口要求 settings:write、CSRF 和 HTTPS 发现地址。通过已装配安全下载客户端短时读取有上限的 XML，筛出同源 HTTPS、无额外协议能力要求的 view 动作，合并重复后缀。发现只生成草稿。应用策略原记录追加协议标记、发现地址和每个后缀的动作 URL，原内置和网页配置仍按已有规则读取。统一保存使用修订保护，活动策略隐藏完整动作表。

沿用所有者选择和站点确认。当前版本及策略修订绑定在短期加密票据内，票据区分网页和 WOPI，匿名回调同时校验文件标识。前端向发现的动作地址 POST access_token 和过期时间，WOPISrc 只含回调路径。公开 CheckFileInfo 返回只读属性，GetFile 复用内容租约、Range 及传输预算。替换、回收、策略变化及失去读取权限时拒绝。部署需提供阅读器可访问的回调域名。

采用受控 XML 和 WOPI 客户端验收管理与真实文件回调。验证重复格式、恶意 URL、权限隔离、字段、范围读取、凭据不能跨协议使用和已有网页应用回归。
