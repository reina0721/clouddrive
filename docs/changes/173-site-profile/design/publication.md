# 站点信息发布

Console v2 增加单行持久化数据，已有表、账号、文件及部署配置保持原值。管理 GET 需要现有设置读权限，PUT 需要写权限及来源和 CSRF 验证。PUT 以修订号进行单语句条件写入。公开 GET 只发布用于呈现的字段。

字段按字符上限校验。URL 可为安全站内根路径或绝对 HTTPS，无用户信息及控制字符。Go 不下载图片。React 将文本作为文本节点，图片禁用来源引用，外部法律链接打开独立标签且不传来源。无配置或图像无法加载时使用原来的产品标志。公开加载失败保留默认展示，管理端提供明确失败与重试。

Host 在静态页面加载后读取公开配置，同一个上下文交给登录、控制台、文件区与分享。设置成功后立即同步当前页面，其他页面下次加载时读取当前值。浏览器标题与图标在 Host 统一应用。

验收覆盖权限、数据边界、修订争用、重启，浏览器覆盖窄屏表单、公开页面和保存后的品牌。升级预览前保留原数据库备份。
