# R173-001 站点公开信息与参数设置

在参考站 1280×720 实测「管理面板 → 参数设置」。默认进入「站点信息」，页面按基本信息、图标、客户端引导分组，名称、描述、条款与隐私链接是独立字段，标志按浅色和深色分别填写。官方使用手册同样将 LOGO 配置放在此处。仅观察表单，未保存参考站配置。

`970ca36` 的 Console 已拥有管理设置权限、CSRF、操作审计和 GORM 事务。其系统设置插件目前只负责注册策略。当前名称分别写在文件导航、公开分享、控制台和登录页，浏览器标题由静态布局固定。运行时仍须支持静态前端，不能依赖 Next.js 请求期渲染。

保留 Go 标准库 URL 解析、既有 Console 持久化、权限和前端静态 Host。项目特有站点字段使用窄契约，不增加新的通用设置框架或图像代理。图像作为图片加载，浏览器不发送 Referer。服务器不请求配置的 URL。主站/备选回调源会影响签名访问、反代和外部服务，因此应与实际回调、Origin 策略一起验收。原始页脚 HTML、客户端分发和其他参数标签均独立对齐。
