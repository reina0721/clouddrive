# 锁屏解锁行为

客户目标：暂离文件工作区后用当前账号密码回到原位置，输错一次无需退出重新登录。

范围：已登录本地账号、手动/空闲/后台锁屏、本人密码、中文英文、键盘及移动界面。限制：锁屏为当前标签页遮挡；普通HTTP活动仍按现有规则续空闲期限，绝对到期不延长。不是账号安全锁、不是新登录或高风险操作再认证；不包含外部身份、BT或Office。

以下20项使用行为组成整批验收：

1. F421 文件账户菜单可手动锁定。
2. F422 正确本人密码解除真实部署锁屏。
3. F423 错误密码保留遮挡。
4. F424 错误一次保留原登录会话。
5. F425 改正密码可重试成功。
6. F426 空密码在本地提示，不发校验请求。
7. F427 后端拒绝空或超长密码。
8. F428 Enter提交可解锁，背景不可操作。
9. F429 正在校验时防止重复提交并显示忙碌状态。
10. F430 校验后清空输入，不在本地保存密码。
11. F431 刷新锁屏仍保持当前标签页遮挡。
12. F432 后台与空闲锁定沿用同一密码入口。
13. F433 连续错误触发持久账号失败预算。
14. F434 锁定期正确密码也不能提前解除。
15. F435 无有效会话不能校验或替别人校验。
16. F436 已撤销/过期/安全版本失效的会话不能解锁。
17. F437 未通过来源与CSRF检查的请求被拒绝。
18. F438 网络异常可见并允许恢复后重试。
19. F439 切换账号或重新锁定后旧响应不得解除新遮挡。
20. F440 中文及英文深色窄屏可用，退出登录仍可离开。

成功不创建会话、不改变权限或MFA状态、不延长绝对期限。未完成的批次不宣称验收通过。
