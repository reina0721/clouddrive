# 大文件与传输管理

用户需要上传超过当前32MiB的文件，在网络中断、页面导航或服务重启后继续已有进度，并通过独立传输页面处理失败和完成下载。已有文件、账号和分享必须保留。

|ID|可验收行为|
|---|---|
|F41|上传大于32MiB文件，默认上限512MiB，最终大小和内容一致；超额提前明确拒绝。|
|F42|大文件分块传输；中断后只重传尚未确认部分，不从头重传全部文件。|
|F43|上传显示真实已传字节与百分比，哈希准备阶段明确区分；未确认进度不伪报完成。|
|F44|暂停单个上传，停止继续发送，保留已确认的服务端进度。|
|F45|继续已暂停上传，从服务器确认位置接续。|
|F46|网络失败可重试；次数有界，最终失败明确显示并保留续传入口。|
|F47|正常服务重启后，未完成文件仍可续传，已完成条目不重复创建。|
|F48|刷新或重新登录后列出未完成传输，重选同内容源文件可续传，错误文件被拒绝。|
|F49|在文件目录、分享管理和其他应用页之间导航时，已经开始的传输继续且可查看。|
|F50|独立传输中心列出本账号真实传输记录及目标目录，刷新后仍存在；不显示他人任务。|
|F51|传输中心可筛选进行中、等待处理和已完成记录，空态与请求失败分开。|
|F52|取消未完成上传，释放其暂存和预留预算；已发布文件不能被取消操作删除。|
|F53|批量暂停当前活动上传，逐项反馈结果，不影响已完成文件。|
|F54|批量继续有源文件的暂停项；需要重选源的项明确提示，不假装开始。|
|F55|队列按配置并发上传多个文件，有空位后继续等待项，单项失败不阻断其他项。|
|F56|显示当前速率和预计剩余时间，暂停、重试和等待源时不显示虚构速度。|
|F57|私有大文件直接下载，由浏览器保存；不先将整个文件加载为页面内存对象。|
|F58|下载支持合法字节范围与条件请求，中断后可从原内容位置继续，非法范围明确拒绝。|
|F59|公开只读分享的大文件也可下载并支持范围访问，口令、到期和撤销检查仍生效。|
|F60|完成时若名称冲突或目标目录失效，保留上传内容并允许改名/重选本账号有效目录后完成，无需重传。|

范围和约束：默认每文件512MiB、每账号逻辑配额1GiB；管理员可在已验证边界内调整更小值。上传摘要用于识别源与校验完整性，不将其当登录凭据。刷新后重新选择文件是浏览器权限边界，没有未经许可读取本地路径。跨路由继续限同一打开的浏览器应用；关闭浏览器不会后台继续传输。

非目标：本批不引入离线下载、WebDAV、Office、多人可写分享或任意容量承诺，不删除历史文件，也不把传输记录自动清理成审计缺失。未完成暂存有明确有效期和预算，超时后提示重新上传。
