# 关联和分派契约

应用规则追加可选 `extensions`。字段缺失表示继承，空数组表示该应用无扩展名关联。有效策略返回归一后的列表和覆盖标记，管理视图提供内置列表。现有文件设置事务原子保存关联和默认项，复用 revision、权限及 CSRF。已有记录的字段缺失继续继承。扩展名匹配前去除一个前导点和首尾空白、转小写，每项最多 24 字符，每应用最多 48 项。跨应用重叠可用，同一应用重复无效。

有明确覆盖的文件后缀由有效关联筛选应用，其余文件沿用继承应用既有 MIME 判断。平台及启停约束继续应用。明确选择文本或 Markdown 走有上限、版本围栏和 UTF-8 校验的读取。PDF 和 EPUB 继续验证格式，媒体与归档继续要求既有候选能力。配置不改变底层文件权限和编辑限制。

管理员通过行操作编辑列表或恢复内置，应用草稿后才统一保存。关联变化使默认项无效时同步移除并告知。服务拒绝矛盾规则和过期修订，浏览器回归覆盖真文件、拒绝场景及恢复。不新增依赖、表或迁移。
