# R168-001 扩展名关联

运行站 `/admin/filesystem?tab=fileApp` 的扩展名列显示可编辑的逐行输入，例如 Markdown 的 `md`、压缩包的 `zip,7z`。默认规则从重叠扩展名选择。参考站仅查看，未修改配置。官方文件应用手册区分内置渲染器和外部应用。

本地 `4ca222c` 的应用服务有固定扩展名、平台、启停、默认规则及持久修订。浏览器由文件类型与签名预判候选，PDF、EPUB、媒体、归档与文本已有读取保护。Markdown 关联别名需要让现有编辑器入口识别显式选择，继续走私有、受限且带 revision 的字节读取。Go 标准库和现有文件设置、Huma、React 表单可完成任务，无需引入解析库、迁移或外部进程。单独定义关联语义以区分继承和空配置，避免把旧记录误认为禁用。

显式关联决定候选应用，继承时保留既有 MIME/扩展名分派。外部应用、创建模板和额外编解码器继续独立处理。研究门禁通过。
