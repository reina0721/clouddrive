# 保存与预览刷新

Surface 将当前可编辑本人文件、目录选择组件和版本发布后的刷新契约提供给 Host。Host 只编码应用后的编辑快照，保留源文件名和格式，并以打开时的内容修订排队替换。传输队列持有文件、摘要、限额、锁与重试责任；编辑器等待有界发布结果，不绕过任何账户、版本、目录或事务校验。

成功以队列完成和目标 ID 一致为准；随后读取当前条目并更新正在查看的图片及相册对应位置。刷新失败单独呈现已发布结果，并在该编辑器内停用重复写回。冲突保持草稿，提示另存；不自动换成当前修订重试。状态持久化和源文件生命周期沿用传输中心。无新接口或迁移。

另存复用本人文件夹选择，保持原文件夹默认值、使用选中的目录和名称排队。在所有编辑工具中共用导出表单，暂未应用的草稿仍阻止发布。
