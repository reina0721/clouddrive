# R157-001 管理任务与安全清理

参考站「管理面板 → 后台任务」显示任务号、内容、状态、创建者、处理节点及创建时间。筛选包含用户、请求 ID、类型和状态。清理对话框按截止日期、类型与终态选取，行操作有删除确认。本次只打开并取消对话框。参考数据包含定时 Blob 扫描。[上游任务契约](https://raw.githubusercontent.com/cloudreve/frontend/master/src/api/dashboard.ts)

`repo/background_tasks.go` 的本人列表使用现有归档与下载表，下载持久模型另有 BT 节点标识。当前四类任务有真实任务 ID，没有持久请求关联字段。调度运行状态不等于可按历史查询的系统任务。`RemoveArchiveTask` 要求终态且候选已清理。`OfflineDownloads.Remove` 按类型委派清理，使用版本和维护租约，负责暂存或节点资源并保留已发布文件。直接删下载表会绕过清理。

保留 GORM、既有锁、IAM 和 UI Adapter。管理端以固定 SQL 投影和数据库分页提供跨账号查询，复用既有删除状态机。归档删除追加预览版本核对。仅确认过的有界任务集合进入清理，允许明确的逐项结果，后续批次继续处理长清单。无需额外通用框架、数据表或外部依赖。
