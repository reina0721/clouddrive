1. F721 管理区提供后台任务入口，保留个人任务入口。
2. F722 经过独立授权后可跨账号查询。
3. F723 统一查询 ZIP、解压、HTTP 与 BitTorrent。
4. F724 按创建者 ID 精确筛选。
5. F725 按任务 ID 精确筛选。
6. F726 按任务类型筛选。
7. F727 按运行中或具体终态筛选。
8. F728 支持稳定的创建时间排序。
9. F729 支持任务 ID 排序和服务端分页。
10. F730 行内展示内容、创建者、真实状态和时间。
11. F731 有实际处理节点时显示节点标识。
12. F732 详情提供状态、更新时间及安全故障代码。
13. F733 不向管理端披露下载来源或凭据。
14. F734 清理与读取权限分离。
15. F735 单条和本页多选清理需确认范围。
16. F736 按日期、类型与终态预览可清理项。
17. F737 活跃或已变化的任务不能误清理。
18. F738 清理保留已发布的文件和目录。
19. F739 每批最多 20 条，逐项反馈结果。
20. F740 桌面与窄屏可完成查询、确认和清理。

日期预览覆盖截止时间之前已创建的终态任务。普通用户仍通过本人入口管理任务。本批限现有持久文件任务，系统扫描历史和请求关联独立规划。
