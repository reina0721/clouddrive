# 接口与清理

文件模块新增 `GET /files/admin-tasks`、`GET /files/admin-tasks/{kind}/{id}`、`GET /files/admin-tasks/cleanup-preview`、`POST /files/admin-tasks/cleanup`。查询和清理分别授权，变更需要 CSRF。列表以数据库查询归档、下载和 BT 节点固定字段，排序只允许 ID 和创建时间。预览返回前 20 条及匹配总数，提交只携带已确认任务的类别、ID、更新时间和下载修订号。无新依赖或迁移。

清理逐项核对快照和状态。归档在原事务内再次比较更新时间，下载委托原有版本和租约保护的清理。任务已不满足条件时返回冲突或缺失，其他已处理项保留明确结果。后台进程和个人入口继续使用现有策略。日志按稳定结果记录，响应不带来源地址、密钥、请求输入或节点凭据。
