# R127-001 研究

## 事实

基线a993983，Git干净。参考站只读首页截图：240px左右侧栏、主区从顶部两行开始，白色文件面板占剩余高度。实际目录更多菜单有固定、全选、取消、反选；视图入口集中网格/列表/画廊及缩略图。参考账号无文件，未伪称观察到剪切粘贴；后者由文件管理目标及当前copy/update接口推出。没有提交参考站表单或修改偏好。

当前files-page内移动端aside直接显示全部导航，文件区排在其后；桌面使用1/5宽。三个视图按钮、排序下拉和方向按钮分散。已有右键控制MenuButton、checkbox/快捷键选择、复制/移动dialog；缺跨目录待处理剪贴板、上级按钮和目录反选。已有FilesRuntime按账号创建，dispose取消I/O并释放源文件；Host调用前后核验owner。copy建立独立副本且不覆盖同名，update移动保留ID，后端拒绝祖先循环与名称冲突。多条既有操作逐条提交，不提供批量原子事务。

## 候选与决定

保留React useSyncExternalStore模式、现有HeroUI DrawerSurface/MenuButton和Host JSON客户端；复用既有标准浏览器键盘事件、导航与逻辑路径文本复制。系统navigator.clipboard面向文本/真实文件，不能作为内部owner授权或目录项引用存储；localStorage会跨登录长期留存条目且非需求，不使用。无需新增通用状态框架。合理自研的是单账号、单页面运行域的有限条目待处理列表，不扩建通用剪贴板平台。资源归属为既有Host runtime，Surface仅通过窄port订阅和操作。

## 推断、限制与基线

移动导航抽屉、紧凑操作菜单和待处理剪贴板可缩小实际差距，但不是Cloudreve全部功能或视觉一致声明。本批只更改文件页面交互；分享/连接等独立页不强行重构。上限100项，内存存储，刷新与退出丢弃；只处理自有file/folder，shortcut继续现有引用操作。粘贴使用当前源名称，冲突不覆盖；逐项成功与失败显示，移动成功从队列移除，复制列表保留便于再次粘贴，失败保留，不冒称事务原子。账号切换或dispose后的旧port写入拒绝、订阅读取返回稳定空快照，输入框/菜单/浮层内快捷键不抢占。

研究门禁通过：现有组件和接口能够承载；没有新依赖、接口、数据迁移或对外副作用。刷新触发器见metadata，仅命中时定向复核。
