# R165-001 EPUB 本地阅读

Cloudreve 的 `/admin/filesystem?tab=fileApp` 列出全平台内置 ePub 阅读器。参考账号目录为空，未在参考站上传或更改文件。本地 `f4aa255` 没有 EPUB 正文入口，PDF 已有版本围栏，归档服务能隔离 ZIP 处理但每个请求重新读取归档。

按 W3C 的 OCF、OPF、spine 和导航语义读取普通 EPUB。现有 Go ZIP 进程适合归档写入和提取，章节和图片反复经服务端传输成本较高。epub.js 侧重沙盒文档渲染及样式，当前方案希望把未信任文档转换为明确类型的章节节点。选 zip.js 2.24.0，npm 与官方发布一致，BSD-3-Clause，无运行时依赖，有浏览器流式输出、CRC、取消和文件名验证。库隔离于宿主，可替换而不改变文件页。应用继续使用浏览器 XML 解析与 React 安全文本渲染。

校验范围包括同版私有读取、限制 ZIP 实际解压输出、重复条目和包内路径、关闭释放与原预览回归。外部资源、样式和脚本不属于阅读内容契约。研究门禁通过。
