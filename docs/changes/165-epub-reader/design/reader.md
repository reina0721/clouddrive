# 章节和资源边界

文件点击沿用本人工作区预览入口。宿主复用 PDF 的私有文件读取与版本校验，按书籍大小和超时限制加载。懒加载 zip.js，逐项枚举中央目录，检查大小、文件名和重复路径。每次读取成员检查实际输出上限及 CRC。阅读会话持有 ZIP 读取器，章节持有独立图片 URL，取消或关闭负责释放。

OCF 容器定位 OPF，OPF manifest 及 spine 给出章节和图片。EPUB 3 nav 与 EPUB 2 NCX 映射至可读章节，缺失则按 spine 显示章节。仅包内相对链接可用于章内或跨章跳转。把 XHTML 转为有限节点集合，图片使用签名验证后的包内栅格内容。样式、脚本、表单及外部请求不参与解析结果。复用下载及服务端权限，无存储迁移。

用真实 EPUB 上传和浏览器阅读验证，以恶意章节和损坏 ZIP 覆盖失败边界。保持现有 PDF、归档和媒体入口。
