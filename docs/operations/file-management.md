# 私有文件管理

浏览器默认进入 `/home`，管理工作区位于 `/workspace`。文件属于当前 IAM 账号；管理员账号也只能通过文件 API 操作自己的内容，不能凭其他账号文件 ID 越权读取。普通账号需要被分配 `files:read` / `files:write` 权限。公开注册沿用已有注册策略，不自动扩大默认角色权限。

## 当前能力

当前提供目录和面包屑、创建目录、文件/目录上传队列、拖拽/剪贴板文件、取消和重试、下载/ZIP 打包、重命名/移动/文件与目录复制、多选、回收恢复、名称搜索/类型分类/排序、网格/列表/画廊、属性/逻辑占用、文本/Markdown 创建、带版本冲突保护的文本编辑、栅格图片及浏览器原生音视频预览，以及文件/目录的分享链接权限与协作。新增大文件分块续传、暂停/继续、刷新重选源文件、跨应用路由传输和 `/home/transfers` 持久传输中心。HTML 和脚本按文字展示，不执行。

文件内容与元数据持久化；刷新、重新登录或正常服务重启后仍可访问。目录进入回收站后，子项不能通过搜索、文件 ID 或下载链接绕过祖先状态。回收站继续占用账户配额，直到永久移除。

回收站工具栏可清空本人整个回收站，包含分页和被筛选隐藏的项目。菜单及选择栏可永久删除已选项，包含目录中的后代。确认会列出实际条目数和可释放配额；范围变化后需要重新核对。完成后条目及自身历史不能恢复，固定项同步移除。底层内容对象保留，仍可被副本或其他版本引用；配额变化不代表磁盘空间同时回收。详见[148变更](../changes/148-trash-permanent-removal/README.md)。

“保留规则”接受 0 至 365 天。0 表示今后仍由本人手动清理，正数只给以后移入的项目记录期限。恢复会取消该期限，重新移入时按当时规则计算。后台任务 `files.trash.expire` 启用时每分钟扫描最多 32 个候选；独立回收且应继续保留的后代会延迟其上级目录的自动清理。超出完整树预算或遇到事务失败会延迟尝试。已到期的项目可在后台处理前手动恢复。详见[149变更](../changes/149-trash-retention/README.md)。

“获取直链”接受单个文件或最多 10 个选中文件，默认每个文件复用一个地址，每个账号最多保存 200 条。持有直链者可免登录读取。默认可预览明确安全的纯文本、栅格图及音视频，其余内容按附件返回，复制下载链接可强制附件。直链跟随文件 ID 读取当前内容，改名和移动不改地址。文件或祖先进入回收站时暂停，恢复后继续可用。“我的分享 → 管理直链”可以撤销，重新生成使用新地址。永久移除文件同时清理该直链。详见[150变更](../changes/150-file-direct-links/README.md)。

管理面板的“文件清单”需要 `files:inventory:read`，可按所有者 ID、文件名、类型、直接回收标记和分享或直链关联过滤已发布条目。关联分享包含未撤销的暂停和到期链接。每页 20 项，最多可请求第 10000 页。逻辑占用为此条目当前及历史内容合计。详情仅显示文件元数据及关联状态。详见[151变更](../changes/151-admin-file-inventory/README.md)。

管理面板的“文件 Blob”需要 `files:blob:read`。每个已引用的主存储对象只显示一行，当前文件、回收条目和历史版本的关联分别计数。所有者过滤选中有该账号引用的对象，引用数仍按全局计算。详情分页显示引用和对象存在性，表中时间为最早关联文件的创建时间。详见[152变更](../changes/152-admin-blob-catalog/README.md)。

“待回收”显示永久移除、删除版本或覆盖后失去所有引用的已发布对象。最后一次解除后等待 24 小时，确认永久清理需要 `files:blob:reclaim`。每次删除均重新检查全局文件、历史和传输引用。已经缺失的对象也可清除候选。自动任务默认关闭，可通过 `files.blobReclamation.automatic` 开启，`files.blobReclamation.interval` 默认 15 分钟，支持 1 分钟至 24 小时。自动任务每轮最多处理 16 项，失败项保留并延后一小时。迁移前已孤立的对象不会自动加入。详见[153变更](../changes/153-blob-reclamation/README.md)。

管理区“文件系统”需要 `files:settings:read`，保存另需 `files:settings:write`。可设置在线文本大小、批量文件上限、后续版本保留及每文件版本上限、回收站与 Blob 扫描间隔、自动 Blob 回收。空值继承部署参数，间隔以秒设置。保存只改动持久化覆盖，在服务重启后应用；状态页分别显示部署、已保存和当前值。部署硬上限和任务禁用优先。降低版本上限不会清除现有历史，达到新上限后的新增保留仍受版本预算限制。详见[154变更](../changes/154-filesystem-settings/README.md)。

本机支持 WebDAV 独占写锁、受信共享目录 BT 节点与归档及离线下载任务汇总。直接账号挂载共享、无需共享目录的远程节点、Office 协作和媒体转码仍有待接入。

本人视频预览会自动加载同目录、同基本名的 VTT、SRT 或 ASS 外挂字幕。匹配忽略大小写，有多个同名文件时依次优先 VTT、SRT、ASS。可以从播放器上方手动选择同目录的其他字幕，或关闭字幕。字幕使用 UTF-8，单份最多 256 KiB 和 5000 条提示，目录最多 200 个字幕候选。ASS 只显示时间和纯文本，现有视频播放位置在字幕切换时保留。详见[147变更](../changes/147-external-video-subtitles/README.md)。

## 文件工作区与全局操作

文件列表、网格提示、回收时间、属性、版本历史、分享、WebDAV连接及离线任务统一按“语言与地区”的时区、日期顺序、小时制和秒设置显示。系统跟随使用当前浏览器时区；固定时区不随浏览器变化。设置页可搜索当前环境支持的时区，既有有效别名保留；这些显示设置不会改写文件时间或后端到期判断。保存范围沿用现有区域偏好：界面设置保存在当前浏览器，跨设备账户偏好由账户页面单独保存，不等同于文件视图同步。

分享自定义日期和时间以窗口中明确显示的实际时区输入，显示转换后的到期预览。打开后的草稿固定该时区，更改显示设置不会重解释输入。夏令时跳过的时刻拒绝提交，重复的时刻必须选第一次或第二次；保留当前到期时间不丢失秒或毫秒。相对小时仍按真实经过时间计算；服务端继续执行当前30天上限，显示或转换不能绕过此限制。

“我的文件”旁可展开真实目录树，只列出本人未回收的目录。各层按名称排序、每页50项，需要时展开或载入更多；读取失败保留已有内容并可重试。点击、Enter或Space进入目录，方向键及Home/End浏览树焦点，不触发主列表快捷键。自动跟随当前目录可关闭；此开关与侧栏折叠仅按账号保存在当前设备，独立于服务器视图偏好，旧折叠记录安全迁移。

目录树在文件工作区各页共用同一缓存，移动端抽屉与桌面共用读取和上传运行域。创建、改名、移动、回收及上传完成后会刷新；外部改动可手动刷新。缓存最多1000个目录，自动补全最多20层祖先分支；超预算明确提示，不默默截断或伪造空目录。树不提供拖拽移动或公开分享导航。

`/home`、共享入口、分享管理、连接、传输、离线下载和后台任务共用文件导航与工具栏。任意页面可访问分类、回收站及固定项；链接保留新标签页打开方式，并显示当前位置。桌面导航可以收起，选择按账号保存在本地，独立于文件视图偏好；移动端使用可关闭的抽屉，关闭后回到文件内容焦点。文件工作区约束在当前视口，顶部创建/搜索/账户保持可用，内容独立滚动；固定项单独滚动，常规桌面高度下存储区持续可见。网格在窄屏两列、较宽屏三列、桌面六列；名称最多两行，可用提示查看完整名称和时间。窄屏路径独占一行，完整路径菜单继续可用；空目录引导在内容区居中。

新建文件夹、文本、Markdown，以及文件和目录上传均先确认自有保存位置。文件列表默认当前实际目录，其他页面默认自己的根目录；分类、分享链接和回收站不是写入目标。目录分页读取，失效目标可重新选择根目录，失败保留输入，取消释放尚未入队的源文件句柄。搜索栏在文件列表保留目录、分类、回收站和高级条件，切到其他页面后搜索自己的全部文件；`/`聚焦搜索，不抢占表单、输入法或菜单按键。

存储区读取现有真实占用与配额，失败显示未知并允许重试。工具栏徽标只统计当前已载入的活动上传，不表示服务端全部任务数；全局面板复用同一个上传队列，保留本标签刚完成的回执，未载入时读取活动任务，完整历史可进入传输中心。暂停、继续、取消和刷新重选沿用已有边界；离开文件页面不会另建上传运行域。

账户菜单复用个人账户、个人偏好、主题、语言与退出入口。客户端锁屏在文件和管理页面由同一处拥有，遮挡内容并禁止背景焦点；真实后端通过当前Cookie会话复核本人密码，输错一次不注销，可改正重试；失败共享IAM持久次数与锁定时间，不能靠刷新绕过账号预算。会话过期、撤销或要求改密时须退出重登。不创建新会话、不提高MFA等级或延长绝对期限；普通HTTP活动仍沿用既有空闲续期。密码不写入本地偏好或日志，关闭/重锁/切换账号取消旧请求。此遮罩仅属于当前标签页，清除本地状态或新开标签页仍可绕过，不改变服务端授权；本批范围与验证见[142变更](../changes/142-session-password-unlock/README.md)。

## 配置和传输限制

HTTP/HTTPS离线任务位于 `/home/downloads`，支持单链接、最多20行逐项批量创建、自有目录与自动/自定义名称、进行中/已完成记录、真实字节与速率、暂停/可靠断点继续、失败重试、从头下载、修改暂停或失败任务目标，以及逐项/批量取消和记录清理。已保存的文件不会随任务记录删除。总量未知时显示实际字节，不伪造百分比；来源不支持可靠续传时要求显式从头下载。详情仅在本人主动复制时返回原始链接，普通列表和日志不展示签名参数。

`files.offline` 由既有Scheduler驱动，关闭Scheduler或该任务后仍可读记录、取消和清理，新建/继续明确不可用。默认每账号200条、全局2000条、每批20条、并发1、1秒调度、20秒租约/5秒续租、单次15分钟、最多20次自动领取（下载与清理共用）、每次64个逻辑来源请求；硬预算只能调小。清理耗尽自动预算会保留待办，显式取消/移除仍能维护清理；从头下载重新建立预算。内容和暂存仍使用原文件配额及单文件上限，不创建第二套存储。

HTTP来源默认仅公网HTTP(S)，逐跳验证全部DNS结果并钉住实际连接IP，不使用环境代理，不转发网页登录Cookie、Authorization或Referer，HTTPS不降级。`files.offline.source.allowedNetworks` 仅供明确受信网络的受控部署；云元数据地址始终拒绝。浏览器夹具必须使用隔离数据库并显式设置 `CLOUDDRIVE_FILE_TEST_OFFLINE_SOURCE_ALLOWED=1`，普通预览不放开回环来源。超过 `files.search.treeEntries` 时任务列表标记目录信息受限，保存相关操作拒绝使用截断树，取消和记录清理保持可用。

### BT任务与受信节点

在 `/home/downloads` 新建任务时，选择磁力链接或 `.torrent` 文件及实例提供的节点和目标目录。磁力先解析元数据；种子解析成功后直接进入文件选择。选择后才下载所选内容，保留目录层次。暂停保留可校验的部分数据，继续时重新校验并复用；转存完成才显示可打开的结果。任务删除不删除已保存的文件。

启用 `files.offline.enabled` 和调度任务 `files.bittorrent.dispatch`，由运维在私有配置的 `files.offline.torrentNodes` 中定义最多4个节点：`id`、`name`、`endpoint`、`secret`、`workspaceRoot`。默认无节点，BT创建不可用。远端RPC使用可验证的HTTPS；字面回环地址可用HTTP。节点运行aria2 1.37.0，RPC不对公众开放。设置绝对 `save-session` 与同一文件的 `input-file`，`deferred-input=false`、`check-certificate=true`，并保证节点和服务可读写同一私有绝对目录。独立数据库实例使用独立节点及目录。凭据不写进仓库；有未清理任务时不能直接移除节点或更换端点、目录。

支持BT v1 infohash和种子，元数据最多1 MiB、200个文件，整个种子的内容上限512 MiB，单个所选文件还受本实例文件上限与本人配额约束。默认每节点1个活动任务（最多2个），同一节点的相同hash串行，账号之间仍使用独立任务、文件选择和暂存路径。`torrentNodeReservedBytes` 默认2 GiB，预留覆盖完整种子范围、控制文件及恢复期间的旧目录；运维仍需给节点暂存配置真实磁盘配额。清理未完成时保留任务和预留；停止节点和核对会话后再按任务操作恢复。

Tracker、peer、DHT及Webseed出站由节点网络策略管理，不继承HTTP来源过滤。只连接受信节点，部署时隔离其网络和磁盘。当前支持 BT v1 与共享目录节点。[143验收记录](../changes/143-bittorrent-downloads/verification.md)说明实际验证范围。

模块配置 `files.maxFileBytes` 默认 512 MiB、`files.quotaBytes` 默认每账号 1 GiB、`files.concurrentUploads` 默认 2。可配置为更小的正数预算；文件上限不能超过 512 MiB，并发不能超过 2，配额不能小于单文件上限。修改 files 配置需要重启。并发名额属于当前 Application Generation；切换其他配置排空旧代期间可能同时存在两代有界请求。

Storage 通过租约内的可寻址流读写内容，local/S3-compatible 都有真实实现；原有 bytes 方法继续服务小内容消费者。上传使用 tus 核心 HEAD/PATCH，创建和控制会话使用项目 JSON API；不声明支持 tus Creation、拼接或 IETF 草案。每块默认 4 MiB，Next 同源代理仍限制单请求 32 MiB，不需要把代理预算放大到整个文件。原始分块在认证和准入后限制字节数；普通 JSON 请求仍保留原上限和默认 10 秒超时。精确传输路由使用 `http.transferTimeout`，默认 5 分钟、最高 15 分钟。空文件允许上传。

上传前增量计算完整 SHA-256，校验进度与已接收进度分开显示。断线按 0/1/3 秒有界重试，HEAD 核对服务端偏移；认证失败和到期不会无限重试。暂停保留暂存，刷新或重新登录后需要重新选择同内容文件，名称相同不足以证明内容一致。应用内切换页面不销毁活动队列；退出登录停止本地读取和请求。浏览器关闭后不会自动读取本地文件。

同一上传会话的完成保存及串行媒体内容读取遇到临时繁忙时，最多再尝试三次，等待0/1/3秒；不扩大服务器通道预算。取消、退出或账号变化会终止后续尝试，耗尽后保留明确失败与手动重试。媒体按实际错误区分繁忙、网络、权限和格式，缩略图也可重试；内容版本变更后不沿用旧错误或旧图片。

`files.transfers` 的 `stagingPath` 默认 `.data/file-transfers`，`chunkBytes` 默认 4 MiB，`stagingBytes` 默认 2 GiB，`ownerCount` 默认 20，`globalCount` 默认 100，`lifetime` 默认 24h，`lockTimeout` 默认 5s，`lockRetryInterval` 默认 100ms，`networkTimeout` 默认 30s，`completionTimeout` 默认 5s。容量和期限有严格上界，具体可用键见 `config.example.yaml`。暂存为单机持久目录，不能把无共享暂存的多主机部署视为已支持。过期和清理待办由请求驱动，每次最多处理两项，不启动无限扫描或后台清理线程。

会话创建在事务中预留容量；取消或过期释放预留，清理失败保留待办且导出错误。复制和小文本仍可使用逻辑配额，最终发布重新核验实际占用。发布时名称冲突、目标失效或配额不足保留完整暂存，可在传输中心修正目标再完成；取消不会删除已发布文件。

`files.maxTextBytes` 默认 1 MiB、`maxArchiveBytes` 默认 64 MiB、`maxBatchEntries` 默认 500、`maxThumbnailBytes` 默认 2 MiB、`maxGalleryEntries` 默认每屏 12、`maxMediaBytes` 默认 32 MiB。各值必须为正且不得超过默认上界；均经列表响应提供给 Host，不在读取失败时退回隐藏预算。目录上传最多选择 500 个文件与非空目录的合计条目，不创建空目录；已建立会话的文件可刷新重选续传。画廊按屏加载，超过缩略图或媒体预算显示下载提示；栅格图像核验签名，SVG/HTML 不作为媒体执行。音视频的解码能力取决于浏览器，没有生成字幕或服务器转码。

上传、文本替换、ZIP 和原始内容响应共用传输准入名额；Host 媒体请求按序读取，避免一屏图片同时占满内存。关闭、切换和卸载会取消请求、停止播放器并释放 Blob URL。快捷键包含 `/` 搜索、F5 刷新、F2 重命名、Ctrl/⌘+A 全选、Escape 清除选择、Delete 移入回收站、Ctrl/⌘+Shift+N 新建目录及 Enter 打开单选项；输入框和浮层内不会触发文件操作。

复制在单次数据库事务内保存整个有效子树，逻辑配额按副本目录项重复计费；不可变对象可由多个副本引用。文本替换使用 `contentRevision` 比较并交换，冲突保留当前编辑而不覆盖已提交内容；旧对象不自动删除，因此当前逻辑占用不等于物理磁盘占用，历史快照另按下文版本保留预算计费。

续传先持久化会话并锁定其暂存，完整校验后写入按会话 ID 固定的不可变对象，最后在数据库事务中复核配额、名称和目标，成功提交才可见。发布中断后重试复用该会话与候选对象；清理暂存失败保留已完成事实和清理待办。小文本创建/替换仍有独立的补偿错误记录 `files_pending_cleanup`；不存在全对象垃圾回收或历史版本清理承诺。

`files_storage` 持久化内容位置摘要；存在文件、活动传输或待清理记录时，禁止无迁移更换 Storage root/driver/bucket。`files_transfer_staging` 同样绑定暂存位置，活动或待清理会话存在时不能换根。提交元数据时再次核验位置，避免旧代继续写入已改变的位置。更换凭据不改变内容位置摘要。迁移内容到新位置需要单独设计和验证。

## 分享链接权限与协作

文件菜单创建分享，默认只读，可选择仅上传、可编辑或自定义能力。权限分别控制浏览目录、预览、下载/ZIP、新建目录与文字、上传、修改文字、改名、移动、复制和回收子项；修改文字要求预览，结构整理要求浏览。链接只授予当前分享根内的能力，可按本实例IAM账号与角色设置受众及子项策略；不提供脱离链接的共享盘或Office共同编辑。预览需要读取字节，不能保证阻止浏览器保存。

### 受众与子项权限

创建分享及修改设置可分别选择匿名访客、已登录用户默认、精确账号和角色的能力。默认项未设置表示沿用本层默认，明确拒绝表示没有能力；每份策略合计最多32条账号/角色规则。精确账号优先于角色，多个角色的允许合并，任一明确拒绝角色优先；其后使用登录/匿名默认或本层默认。当前活跃系统管理员和分享拥有者在有效分享内具有全部能力，链接、密码、到期和撤销仍然检查。角色是本实例IAM角色，不是外部组同步。

文件和目录菜单的“权限设置”显示独立或继承、最近独立祖先，以及相关有效分享。可恢复本项继承，保留后代独立策略。作为分享子项时使用最近一份独立策略；分享根使用链接策略，忽略根自身的子项策略。复制深复制独立规则，移动后没有独立策略的条目随新祖先继承。单文件策略不显示仅目录有效的创建/上传。

“查看已保存的最终权限”按实际分享与匿名或精确选择的账号计算来源和命中规则，不包含未保存草稿。保存采用独立策略revision；冲突保留草稿，用户可明确读取最新版本后再决定保存。

访客目录及子项各有实际能力，浏览和搜索在分页前隐藏不可见子树，不能越过缺少浏览能力的祖先。目录递归下载、复制、移动及回收检查后代权限，目的地同时检查创建能力；内容、ZIP和原生下载均重新授权。分享上传绑定当前访问账号，在最终保存时再次检查策略、账号及当前角色。退出/换账号不能重用他人下载票据或上传候选；角色变动撤销会话时需要重新登录。历史匿名下载票据保留匿名语义，登录访问可重新点击下载取得新票据。

匿名被拒绝时可登录后重试，分享凭据仍留在浏览器片段。有Cookie但会话无效时要求重新登录，不把认证错误解释为匿名；未授权访客不获得分享根名称或私有受众规则。已获准字节和已下载副本不能远程收回。


`/home/shares` 支持可选标题、有效期、密码保留/设置/移除、详情与真实访客预览、暂停/恢复、撤销，以及标题/原名称检索、生命周期筛选、排序和每页20条。设置和启停携带读取的策略revision，冲突保留输入并要求显式读取最新设置。暂停可恢复，撤销不可恢复。默认有效期由服务端决定、最长30天；过期链接可维护标题与密码，修改有效期时必须选择新的合法未来时间。

共享目录包含当前与未来有效子树，根进入回收站后不可访问。访客可以在实际允许的范围内检索、排序、翻页、预览安全栅格图像和浏览器原生音视频、查看文字/Markdown、新建目录和文字、上传、重命名、移动、复制、回收及最多20项逐项批量整理、ZIP打包。文字保存使用内容CAS，冲突保留草稿，旧内容进入拥有者既有版本历史。文件根允许获准的文字修改；分享根不能改名、移动或回收，没有永久删除入口。HTML/scripts仅显示文字，不执行。

仅上传分享不枚举已有文件；服务端仍验证目标目录。批量操作逐项返回真实结果，失败项保留选择，不把部分成功当作全成功。所有文件操作通过受分享根约束的仓储复用原文件用例；读取不投影私有祖先，写入与分享策略修改共用owner事务锁，最终结果也必须位于根内。目录元数据超出 `files.search.treeEntries` 时拒绝使用截断树，拥有者仍可检索链接、维护策略、暂停和撤销；状态明确标记信息受限。

访客页为 `/share#token=...`，256 bit随机capability只放fragment。Host以同源Session提供可选受众事实并请求公开API，省略IAM Cookie，使用no-referrer/no-store；密码保护且未解锁时不暴露目标名称、权限、策略版本或预算。每次操作重新检查拥有者当前IAM文件权限、链接状态、版本、票据和范围。密码复用IAM公开窄facet的Argon2id，不另造算法。

`files.sharing` 默认 `activeLimit=200`（每账号未撤销且未到期链接，含暂停）、`batchEntries=20`、`maxAge=720h`、`grantTTL=15m`、`attemptWindow=1m`、`attemptLimit=10`、`kdfConcurrency=2`。数量预算只能调小；密码8–128字节，全部KDF尝试计入持久窗口。票据仅存摘要、客户端只存内存并以 `X-Share-Grant` 传递。策略修改和暂停/恢复递增revision，使旧解锁/下载凭据及未完成上传失效，已保存内容保留。

访客上传复用既有tus、SHA-256、空间预留、暂存和最终发布。候选绑定分享、策略版本与原解锁票据；密码访客的独立票据不能互读对方候选。无密码链接的同一capability持有者共享链接权限，不是独立访客账号。公开上传不进入私有传输中心，也不能经私有控制端点操作。UI显示真实散列/上传/保存进度；上传出错或取消后清理已知候选，清理失败保留错误和待办。关闭页面停止本次上传，不提供访客队列持久化或刷新续传；创建响应完全丢失而未知ID的候选按既有有限期限处理，不能承诺立即清除。大小、并发、空间和有效期沿用原传输预算并受链接/票据到期进一步限制。

私有和公开下载使用原生浏览器保存，不先缓存完整大文件。公开下载经POST签发限定单文件、内容版本、策略版本的短期句柄；`downloadTTL=1m`、`downloadLimit=100`，到期不晚于分享或原解锁票据。GET/HEAD支持Range及条件请求并重新检查授权。原始内容有download许可时可读任意文件；只有preview时限制安全类型和字节预算。Host媒体预览始终有界并核验格式，文字默认1MiB、媒体32MiB、ZIP64MiB；关闭释放读取与Blob URL。

分享协作使用v12增量结构，增加分享策略、Grant策略版本与Transfer分享绑定；已有链接显式迁移为启用、只读、revision=1，原票据同版本。v1–v11已应用SQL不变，不重置账号、文件或数据库。新策略或分享候选存在时down guard拒绝有损回滚；只在合成SQLite库验证回滚，绝不在用户库清理数据以通过guard。MySQL/PostgreSQL脚本已提供，实际迁移验收限于SQLite。

## WebDAV 连接与挂载

`/home/connections` 可创建具名独立凭据，选择自己的有效目录作为根，设置只读和阻止点文件写入，并管理备注、策略、停用/启用、撤销及密码轮换。修改有版本冲突保护，失败保留输入。密码只在创建或轮换成功时显示一次，普通读取不能取回；连接用户名为独立ID，不使用网页登录密码。撤销不可恢复，停用可重新启用。到期、根目录回收、账号禁用或IAM文件权限撤回后，旧凭据不能继续访问。

协议提供 PROPFIND 目录属性、GET/HEAD 范围及条件下载、MKCOL、流式PUT、事务COPY/MOVE和进入同一回收站的DELETE。PUT最大512MiB，遵守现有空间与暂存预算，未知长度流超过上限即失败；覆盖保存原条目ID并递增内容版本，条件或最终CAS不符不破坏旧内容。复制按副本目录项计费。目录复制/移动也受点文件策略约束。LOCK/UNLOCK提供持久独占写锁，PROPFIND可读取supportedlock与lockdiscovery；快捷方式不提供写锁且supportedlock为空；共享锁、任意扩展属性及Office服务仍不支持。PROPPATCH对受保护属性返回失败明细。Windows/iOS指南不等同于实际系统驱动验收。

“文件锁”位于连接页，显示本人当前有效占用的规范路径、来源连接、范围及到期时间；可刷新并确认解除，操作使用记录版本避免误解续期后的锁。时间跟随账号区域偏好。解除不会修改内容，但应先停止编辑器保存，避免未保存的修改冲突。网页、分享、版本恢复/清理及上传最终发布在同一文件事务内检查占用，缺少有效授权返回423；If条件不成立返回412。普通上传接收完成不代表能绕过后来取得的锁。

客户端使用连接认证及If令牌写入，令牌本身不授予权限。支持Depth0与Infinity；Depth0文件夹保护自身及直接成员名称，Infinity覆盖后代。COPY不复制源锁，MOVE不搬走源URL锁，目标已有锁仍有效。未映射文件LOCK原子创建真实空文件；解锁后该文件保留。刷新使用空请求体和单个If状态令牌；锁随服务重启保留，到期及连接停用/撤销/轮换/只读后失效。连接根外的继承锁发现属性返回403，不泄漏外部路径。

`files.connections.writeLockAge`默认5m、`writeLockMaxAge`最大1h，期限不超过连接到期；`writeLockOwnerLimit`默认及硬上限100、`writeLockGlobalLimit`默认及硬上限5000，可调小。If头、规范化条件和持久文档各受8KiB预算，最多32列表/64条件，owner XML最多8KiB/32层/512节点，仍受原64KiB XML和1MiB响应预算约束。锁按需读取和清理，没有新的后台循环。v16仅新增锁表及传输条件列，旧列数据保留；有锁或持久条件记录时down guard拒绝有损回滚，不在用户库删除记录以通过guard。验收与客户端适用边界见[141记录](../changes/141-webdav-write-locks/README.md)。

`files.connections` 默认每账号最多20个未撤销连接、有效期720h/最大8760h、元数据树10000项、目录查询500项、XML64KiB、响应1MiB、相对路径4096字节/64层。预算可调小，不允许超出默认硬上界。超出元数据扫描预算会拒绝文件访问，仍允许停用/撤销。`publicOrigin` 默认空：地址采用当前API请求看到的scheme/Host；HTTPS反向代理应显式配置可达的HTTP(S) origin，不含路径、凭据或query。不会信任任意Forwarded头推测公网地址。

请使用凭据弹窗提供的实际服务器地址。Next开发代理保留32MiB克隆预算，只转发小JSON管理请求；WebDAV客户端直接连接展示的Go API端点，分端口开发时该地址与网页不同。生产应提供HTTPS和支持流式传输的网关，不通过提高整文件内存预算模拟流式传输。

## 与我共享和侧栏固定

`/home/shared` 汇总保存在自己目录中的分享快捷方式。可以从公开分享页选择“保存分享快捷方式”，未登录时先登录并返回确认；也可以粘贴本实例的 `/share#token=...` 链接，自行选择目录和别名。它保存引用，不复制原文件、密码或解锁票据，也不授予直接账号协作权限。当前状态区分可访问、需要密码、已撤销、已到期和不可访问。名称搜索、状态筛选与游标翻页可以组合。

快捷方式在普通目录中使用独立图标。可改名、移动、复制，随整个目录复制时仍保存独立引用；改名和移动携带读取版本，冲突不覆盖。回收和恢复沿用目录可见性规则。仅已回收的单条快捷方式有“永久移除快捷方式”确认，删除引用与对应固定项，不改动原分享及原文件。普通文件、目录和父目录回收的隐含子项不能借此接口删除。

打开引用时使用受当前 IAM 会话保护的 303 跳转，原分享标识只在浏览器片段中。原分享密码、到期、撤销及根目录可见性仍独立检查；公开分享里的嵌套快捷方式不会递归展开权限。引用不支持文件字节下载、文本编辑、新建分享根或 ZIP；选择包含引用的目录打包会明确拒绝，不生成假的空文件。

目录（含根目录）、与我共享视图及快捷方式可以固定到侧边栏。名称取自当前条目，回收或原分享失效后显示不可用，恢复后重新可用。管理固定项可上移、下移或取消固定；每次写入携带整个账号集合版本，并发冲突需要刷新确认，不能静默覆盖。

`files.navigation` 默认 `shortcutLimit=100`（含回收站）、`pinLimit=20`、`treeEntries=10000`、`pageSize=20`，均只能调小为正数。创建及目录复制都计算新增引用数量。读取自身与原分享owner的元数据各受同一树预算限制；超预算明确失败，固定列表仍允许取消固定。快捷方式逻辑字节为零，不扣原文件大小，也不持有内容对象。

v8 仅新增引用字段与固定集合表，已应用的 v1–v7 SQL 不变。回滚前若仍存在快捷方式或固定项，数据库 guard 会拒绝 down，不能靠回滚丢弃引用。当前验收使用 SQLite；MySQL/PostgreSQL只验证脚本完整性与校验摘要，没有外部实例实测。

## 高级搜索与文件视图

文件页“高级搜索”支持最多8个文件名关键词，选择全部或任一匹配、忽略或区分大小写。匹配采用 NFC Unicode 规范化和子串语义，逗号是关键词内容，不是分隔符。可选择当前目录、当前目录及后代、全部自有文件，以及普通文件、目录、分享快捷方式；不能借条件访问其他账号或已回收祖先下的内容。

最多16个扩展名条件忽略大小写及前导点，仅匹配普通文件。最小/最大大小同样仅作用于普通文件，包含边界，零匹配空文件，留空不设限；单位为 B/KiB/MiB/GiB，必须换算为整数个字节。网页日期按 UTC 整日，结束日包含当天；API 时间使用 RFC3339，起点包含、终点排除。日期范围需起点早于终点。取消不改变结果，活动条件可逐项移除或全部清除。

条件编码保存在 URL，可刷新、前进和后退；非法条件或页码明确显示错误，不自动执行无条件搜索。网页仅接受可无损编辑的 UTC 零点日期，原生 API 可表达任意时刻。条件最多8192字符且 URL 编码后不超过4096字节，过长保留弹窗输入并要求缩减，不提高代理请求头预算。标签与自定义字符串属性按下节提供私有筛选；媒体分析提取和外部全文索引尚未实现。

`files.search.treeEntries` 默认10000，只能调小为正数，采用 RestartRequired；每次查询通过 LIMIT+1 读取账号元数据，超预算明确拒绝，不把部分数据当作完整结果。查询中的树可见性采用请求局部迭代索引，支持深层目录，环或缺失祖先不会暴露条目；无独立全文索引或扫描后台任务。空间占用仍是整个账号文件的逻辑总量，不随搜索条件或页码变化。

普通网格和列表每页50/100/200项，服务端先过滤排序再分页；目录优先独立于升降序，稳定 ID 作为同值排序补充。名称、大小、修改和创建时间均可排序。列表拥有对齐列，可选择大小、类型、修改和创建日期；窄屏保留名称及基础信息，次要列隐藏。视图偏好按账号保存，可选择当前浏览器或服务器同步；损坏偏好明确提示，账号变更后旧 Host 不可继续读写。

视图选项中可开启各目录记忆，根目录也有独立覆盖；未保存的目录使用全局默认。关闭记忆不删除覆盖，重新开启可继续使用；可将当前视图设为默认、重置当前目录或清除全部覆盖，仅删除设置，不删除文件。分类、搜索和回收范围使用全局默认。最多保存200个目录，超限明确失败，不静默淘汰其他目录。

“同步到服务器”会显式发布本机当前设置；另一设备可选择“读取并使用服务器设置”，不发布该设备草稿。关闭同步后，后续变更只保存到本机。同步包含视图、排序、方向、目录优先、缩略图、分页、列表列、目录记忆和文件夹点击行为；多设备写入使用整个文档revision，冲突不自动覆盖。失败保留弹窗并可读取最新设置重试；服务器故障不隐藏回退成本机成功。旧v1本机偏好在新文档成功保存后才移除。

文件夹可选单击打开，或单击选中、双击打开；键盘确认仍进入目录，修饰键选择规则不变。此偏好不改变普通文件和分享快捷方式的打开行为。服务器偏好归files模块，复用当前会话、文件权限、CSRF与数据库租约，不需要IAM通用偏好权限；它不授予目录访问权。迁移v14仅新增偏好表，使用与边界见[137验收](../changes/137-file-preferences/verification.md)。

缩略图可关闭；开启时仍遵守单文件图片字节预算及每页 `maxGalleryEntries` 数量预算，其余显示图标，不为200项一页保留200个内容 Blob。画廊继续使用原有服务器每屏预算与客户端分屏，不冒称普通服务端分页。

名称上 Ctrl/⌘ 点击切换选择，Shift 点击从当前页锚点选择连续范围，Ctrl/⌘+Shift 将范围并入原选择。方向键、Home/End 在文件名之间移动焦点，配合 Shift 扩展范围；Enter 打开焦点项目，普通点击仍打开项目。全选仅作用于本页，翻页、过滤、排序和目录变化清除选择及锚点；输入框和浮层不会触发文件快捷键。

## 私有标签、属性与个性化

文件菜单的“属性”打开侧栏，读取当前名称、逻辑路径、日期、大小及有效后代统计，并可复制完整名称或逻辑路径。目录统计不包含自身、回收后代或不可见分支，快捷方式单独计数且不累计目标字节。逻辑路径最多4096个UTF-8字节，超限明确拒绝，不截断为错误位置。

同一侧栏可添加、改名、着色和移除标签；添加、修改和删除自定义字符串属性；设置Emoji图标和目录颜色，或恢复默认。空属性值与属性缺失不同。标签使用NFC及忽略大小写去重，属性键大小写敏感；值支持换行，按文字显示，不执行HTML/脚本。Emoji优先于普通图标和图片缩略图。颜色只接受六位RGB十六进制值；标签文字仍使用可读主题颜色。

标签显示在网格、列表和画廊，点击标签检索全部自有有效条目。高级搜索可组合全部/任一标签与单个属性存在、完全相等或包含条件；空字符串相等合法。条件随URL恢复并可逐项移除。画廊另以一次有界请求读取本屏摘要；失败明确显示错误并禁用依赖缺失版本的批量整理，刷新成功后恢复，不把读取失败视为空标签。

多选后可批量添加或移除标签。单条保存及批量保存均比较独立注解版本；任一目标冲突时整批不写入，输入保留供用户检查，不自动覆盖其他窗口结果。无变化保存不递增版本；注解版本不影响文件内容版本。副本继承整理信息但后续独立；文本、分块及WebDAV覆盖保留原条目注解，回收/恢复亦保留。

注解仅在本人认证API可读写，不包含在普通Entry、公开分享或WebDAV属性中；不是跨账号标签协作，也不提供Cloudreve管理员属性模板和媒体提取。注解使用4个私有原生operation；原生接口当前总数见[API文档](../../api/README.md)。操作完成日志只记录稳定事件，失败沿用现有错误边界；标签、属性、名称及请求内容不写入日志。

配置`files.annotations.maxBytes`默认2048、`batchEntries`默认100，只能调小为正数，RestartRequired。每条最多8标签/8属性，标签32字符、键64字符、值256字符、Emoji16字符；整体按Go标准JSON含HTML转义后的UTF-8字节核验。属性键仅Unicode字母/数字及`_-.`。每次注解读写受`files.search.treeEntries`账号树预算限制；普通分页随列表返回摘要，画廊单次至多200个显式ID，实际沿用原每屏12项。不存在独立索引、第二套连接或无限后台任务。

v9为三方言添加列，SQLite已验收v8旧行升级、重启持久化与回滚保护；有非空注解或使用过的注解版本时down拒绝，不能靠回滚丢弃整理信息。MySQL/PostgreSQL仍只有脚本与校验摘要检查，没有实例升级验收。第七批研究、20项明细与集中证据见[126变更](../changes/126-file-annotations/README.md)。

## 文件浏览与待处理操作

桌面文件页采用固定宽度、独立滚动的侧栏，主文件区占剩余空间；移动端通过“文件导航”打开左侧抽屉，选择分类或目录后自动收起，关闭后焦点回到文件区。保留主应用已有的跳到内容入口，没有重复入口。空的普通目录提供直接上传文件按钮，仍进入同一传输队列；搜索无结果和回收站不提供误导的空目录上传入口。

视图菜单集中网格、列表、画廊与视图选项；排序菜单集中名称、大小、日期及升降序，偏好按账号及所选同步模式保存。上级目录按钮和Alt+Up返回当前目录父级；根目录、回收站、分类和加载中禁用。完整目录路径菜单列出祖先，可跳到任一级；目录更多菜单可复制逻辑路径，以及全选、取消和反选本页。结果行显示当前范围和过滤后的总数；选择栏汇总所选文件字节，不冒充目录递归大小。搜索框Escape丢弃未提交草稿并回到文件区，“清空搜索”更新URL并重新查询，保留其他明确筛选。

文件/目录右键和多选栏可“加入复制待处理”或“加入剪切待处理”，随后进入目标目录粘贴。Ctrl/⌘+C、X、V使用同一待处理列表；输入框、可编辑区、菜单和浮层内保留文本操作。剪切源项标记为待移动，尚未修改文件；取消待处理不删除或移动内容。快捷方式继续使用原引用操作，不加入文件剪贴板。

列表只在当前账号、当前标签页运行域的内存中存在，最多100个文件或目录；刷新、退出或账号切换即清空，不读取/写入操作系统文件剪贴板或持久化源名称。复制成功保留列表以便再次粘贴，移动成功移除该项；失败项保留。粘贴前重新读取源文件名称和可见性，并检查目标和祖先关系；真实写入继续由已有后端权限、配额、循环和同名规则判断。不会覆盖同名项；如果其他窗口已改名，按当前名称创建副本。源已回收或失效会明确失败。

多项写入依次提交，界面分别显示已完成数量和失败项目，不能把部分成功称为整批事务。正在提交时禁止再次粘贴、替换或清空列表；失败不自动重试。只有进入普通有效目录且没有搜索、分类或附加过滤时允许粘贴，避免将检索结果误作目的地。跨标签页粘贴、跨账号移动、原子多文件操作和系统文件剪贴板仍未提供。

浏览交互本身不修改后端operation、迁移或依赖；能力与集中验收记录见[127变更](../changes/127-explorer-interactions/README.md)。

## 私有文件版本历史

文件工作区顶部的“版本保留设置”独立保存账号规则：启停、扩展名（空为全部，最多32项，大小写及单个前导点会规范化）、最近旧版本数（0–20）。0仅表示不另设账号数量限制，仍受服务端预算。设置保存跨设备生效，有独立revision冲突保护；失败保留草稿，冲突须明确读取最新设置，不回退本机默认。

保存规则不立即改动已有文件或历史。关闭或扩展名不匹配只影响未来新增历史，已有旧版仍可查看和恢复。选择数量上限后，未来成功覆盖在同一事务保留最近旧版本，超出的最早关联被移除；失败覆盖不裁剪。逻辑占用相应调整，不删除副本引用或物理对象，不承诺立即释放磁盘。上传admission与最终保存分别读取当时规则；最终规则变化导致配额不足时保留完整候选，调整后可重试。没有规则记录的原账号沿用原行为。

v15追加独立策略表，不修改v1–v14或原文件；使用与验证见[140变更](../changes/140-history-preferences/README.md)。

文件菜单和已保存的属性面板提供“版本历史”。新文本编辑、上传新版本、WebDAV PUT及COPY覆盖按账号规则保留旧内容；历史从保留启用后的覆盖开始，不追溯升级前未记录的文件对象。只对本人普通文件开放，公开分享和WebDAV目录属性不公开历史。版本历史使用6个原生operation；原生接口当前总数见[API文档](../../api/README.md)。

历史面板每页5个版本，可切换顺序、查看原名称/类型/字节数/记录的修改时间、下载和预览；当前版本单独标识且不能删除。文本以纯文本预览，可与打开面板时的明确当前版本并排比较，不提供自动差异算法。图片和音视频沿原媒体预算、签名检查、浏览器解码和资源释放规则；旧扩展名与替换内容不同的情况优先识别可确定的内容类型。下载支持HEAD、Range和条件请求，账号/祖先/旧关联当前状态仍会检查。

“恢复此版本”将所选旧内容提升为新的当前内容编号，恢复前当前内容退入历史，文件名、位置及整理信息保持当前值；所选旧关联编号从历史移出，总占用不增加，满配额/数量上限仍可恢复。同一对象恢复为无变化操作。恢复和删除均比较读取到的内容及历史两套版本；冲突保留确认，需显式刷新，不自动覆盖其他窗口修改。旧版另存为在原目录创建独立新文件，仅保存所选内容。

单条、跨页所选或全部历史可明确确认清理。只移除逻辑引用，不删除当前、不影响副本，不保证物理空间立即回收；未增加垃圾回收后台任务。副本继承独立历史，目录复制同样如此；改名、移动和回收恢复保留历史。历史日期是当时记录的文件修改时间，不承诺能还原内容最初生成时间。

上传新版本复用同一持久tus队列，可暂停、刷新后重选及完整摘要校验，保留目标ID/内容版本与目标名称；不能改投其他目录。目标已更新则发布冲突，不偷偷变成普通新建或覆盖后来内容。队列不会持久化源文件字节或账号凭据。

配置 `files.history.enabled=true`、`perFile=20`、`perOwner=1000`，RestartRequired；数量仅允许调小为正数。每文件最多20个旧关联、每账号1000个，每条编码不超过65535字节。未选择账号数量限制时，到硬上限拒绝继续保留；关闭自动保留仅影响未来覆盖，已有历史仍可管理，恢复始终保留恢复前内容。账号逻辑占用包含当前及全部历史关联，回收站也计入，相同对象的独立关联分别计费。覆盖预留、发布和目录复制遵守同一规则。

v10为三方言新增历史列；v1–v9 SQL保持不变。默认[]/0，不制造旧历史；有非空历史或使用过的历史版本时数据库guard拒绝down。SQLite已验证合成v9旧行升级、失败回滚不丢数据及重启持久化。MySQL回滚保护使用显式CHECK ENFORCED，要求8.0.16或以上，较早版本会拒绝该down语法而非忽略保护；TEXT表达式默认值另要求8.0.13或以上；MySQL/PostgreSQL只有脚本/摘要验证，未做外部实例升级验收。研究、20项及集中结果见[128变更](../changes/128-file-version-history/README.md)。

## 本人压缩包浏览与提取

本人普通ZIP或7Z文件可从文件名称或“浏览压缩包”菜单打开。窗口提供包内目录、根和上级导航、全路径搜索、名称/大小正反排序及文件/目录选择；搜索覆盖整个压缩包。目录选择包含后代，重复祖先只处理一次。UTF-8文本以纯文本呈现，图片只接受受控栅格签名并由浏览器解码，不执行HTML/SVG。可以下载单个成员，或将所选成员保持层级重新打包成ZIP下载。

“全部解压”或“解压所选”选择本人目标目录，可翻页、返回根和上级，也可填写新的包裹文件夹。拒绝同名会拒绝整次操作；跳过同名可复用同名目录，同名类型不同则跳过整个子树；自动改名保留文件扩展名并明确列出改名结果，不覆盖现有内容。创建内容后一次事务发布所有目录项，重新检查源内容版本、目标/复用目录、同名和配额；冲突不会自动重试。回执包含真实创建、跳过、改名及结果目录入口。网络结果未知时先查看目标目录，避免重复解压。

7Z密码只在当前窗口内存及本次请求中使用，关闭即丢弃，不进入URL、日志或持久存储。加密数据可能直到读取成员时才能验证密码；校验失败也可能表示文件损坏。ZIP加密、分卷、自解压、公开分享内浏览和远端Range索引缓存尚未提供。

压缩源和展开总量沿用 `files.maxArchiveBytes`，默认64MiB；每包最多500项（包括隐式目录，沿用批量预算），路径4096 UTF-8字节、深度32，密码1024字节。文本预览1MiB、图像预览2MiB，账号树读取沿用 `files.search.treeEntries`。超预算明确失败，不返回伪造空包或部分成功。

`files.archive.timeout` 默认30秒，只允许正值且不超过30秒；`workerMemoryBytes` 默认536870912字节，只允许134217728至536870912，均为RestartRequired。标准ZIP与sevenzip解码运行在同一程序的独立受限子进程，Windows Job Object限制内存且关闭时终止，Linux在读取请求前设置RLIMIT_DATA（要求支持其mmap约束的内核）；其他平台明确不支持。复杂压缩包即使展开小于64MiB，也可能因解码字典资源预算失败。取消/超时必终止并等待解析进程；无无保护回退。Windows已有真实进程验证，Linux仅交叉构建，尚无Linux运行态验收。

解析器来源、同步解压的原子发布和集中验证见[133变更](../changes/133-archive-browser/README.md)。

### 后台解压

无密码 ZIP/7Z 可在解压选项勾选“在后台解压”。提交后可继续浏览，在 `/home/tasks` 查看本人任务、手动刷新或开启自动刷新。成功回执包含实际创建、跳过和改名数量及结果目录链接。排队任务可以取消，完成或取消的记录可以清除。失败记录在候选对象清理后可移除。清除任务记录会保留已发布的内容。

数据库 v18 新增任务表。排队任务重启后继续执行，过期的运行领取变为中断失败。持久输入只接受无密码请求，选择等提交数据限制在 64 KiB，归档解析和文件配额沿用上文。每个数据库同时执行一个后台解压任务，单次执行上限 90 秒，领取租期 2 分钟。每账号最多保留 50 条记录，全库 2000 条。同一账号的请求键在记录保留期间可安全重放。

启用调度器及 `files.archive.dispatch` 可接收新任务。账号当前写入权限在执行及发布前检查，成功回执与文件记录一次提交。候选内容的清理失败会保留任务证据并重试。解压任务设计和证据见[144变更](../changes/144-background-archive-tasks/README.md)。

### 后台创建 ZIP

在本人文件或目录菜单中选择“创建 ZIP 压缩包”，也可以在多选工具栏同时压缩多个来源。填写文件名和保存目录。省略扩展名时补齐 `.zip`；同名文件受保护。完成后可从后台任务打开目录、定位文件或直接下载。直接打包下载继续在文件区使用。

后台创建使用标准 Deflate，并保留 Unicode 路径和空目录。目录选择覆盖可见后代；重复选中的子项只收录一次，快捷方式和冲突的包内路径明确拒绝。来源在排队后变化会失败。输入和输出受归档预算限制，输出同时受单文件上限和本人配额限制。v19 向原任务表增加三列，既有记录按解压显示。范围和运行证据见[145变更](../changes/145-background-zip-creation/README.md)。

### 后台任务汇总

从文件侧栏打开“后台任务”，可以按创建时间查看本人的 ZIP、解压、HTTP 和 BitTorrent 记录。每页最多 20 条，可按类型、状态和任务名称组合筛选。列表支持手动刷新和仅在页面可见时的自动刷新。归档卡片保留结果、排队取消与清除入口，下载卡片显示字节进度及失败原因，并可打开已保存的结果或跳转到离线下载中的对应任务。暂停、重试及种子文件选择在下载详情或管理卡片中使用。上传记录位于“传输”。详见[146变更](../changes/146-unified-background-tasks/README.md)。

## 本人 PDF 阅读与临时批注

本人PDF可从文件名打开；历史版本面板中的PDF也进入同一阅读窗口，使用所选内容编号。提供上下页、合法页码、首页/末页、缩放、适合整页/宽度、100%实际大小和双向旋转。工具栏在窄屏横向滚动，保持完整文字；页面随可用阅读区域调整，不把浏览器缩放当成文档缩放。

真实文字层可选择复制，并使用全文文字查找、前后匹配、匹配计数、大小写和完整单词条件。扫描件没有文字层时不提供OCR。侧栏按组读取真实缩略图，支持文档大纲和PDF内部链接，并保留本阅读窗口内有界的位置历史；不会自动打开文档中的外部链接。加密PDF按需填写临时密码，错误可重试，不将密码写入URL、偏好、日志或服务器。

文字、高亮和手绘使用PDF.js实际编辑器，支持撤销/重做。“导出标注副本”生成含批注的新PDF下载，不覆盖或上传原文件。未导出的变更会在关闭时提示继续阅读或明确丢弃；导出后继续修改或撤销，也会重新进入未导出状态。批注仅属于当前窗口，不承诺刷新/退出后的恢复、多人共同编辑或原地保存。

`files.pdfReader` 归files模块管理，严格校验并使用RestartRequired；下列正值只能收紧到不超过默认值。普通列表和版本页返回同一typed预算，时间以毫秒传递。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `maxPages` | 500 | 文档页数上限 |
| `maxCanvasPixels` | 4194304 | 单个页面画布像素上限 |
| `maxImagePixels` | 8388608 | 允许解码的文档图像像素上限 |
| `maxOutlineEntries` / `maxOutlineDepth` | 500 / 16 | 大纲条目和深度 |
| `maxThumbnailPixels` / `maxThumbnailBytes` | 65536 / 524288 | 单缩略图像素及PNG字节数 |
| `workTimeout` | 30s | 受控读取和解析/查找/导出操作期限 |
| `workerReadyTimeout` | 10s | 独立阅读组件及Worker启动期限 |

源文件和导出沿用 `files.maxMediaBytes`，默认32MiB；侧栏每组至多8个缩略图、依次渲染。图像超额由SDK省略，阅读窗口明示像素预算及下载原件查看完整内容；预览不承诺所有图像完整还原。复杂、损坏、源字节或页数超限PDF可明确失败，仍可从文件操作下载原件。源版本/长度/签名、账号归属和HTTP实际流量均会检查；同长度覆盖也不能作为旧版本交付。

Host在明确拥有的同源frame中装配固定本地pdfjs-dist，独立module Worker解析，不创建或传入PDFScriptingManager，不装载sandbox执行文件，关闭XFA和自动外联。组件仅获取有界字节和语言/主题/策略，不获得会话、内部路径或下载URL。关闭时取消读取，销毁SDK/Worker，移除frame并释放临时URL；Worker启动失败不回退主线程假Worker。浏览器Worker没有OS硬堆内存上限；期限依赖浏览器事件循环及SDK让出执行，不承诺强制中断单个同步绘制指令，页数/像素/期限不等同进程级隔离。

本批验证使用Next server同源部署，`/file-viewers/pdf/`前缀的CSP等安全头必须由部署保留；静态导出、外部CDN与其他平台浏览器未作为本批验收承诺。SDK资源在dev/build前由固定依赖可复现生成，普通文件/登录页面不加载解析器；原主应用预算和独立PDF资产摘要/预算分别检查。当前证据及限制见[134变更](../changes/134-pdf-reader/README.md)。
